## 三、怎么用

**第一遍（按章过）**
只看每章的「知识框架」和「知识点详解」，建立骨架。看不懂的地方点「对应分P」回去看视频原话。

**第二遍（抓分）**
只看「老师强调的考点」+「快速技巧与口诀」+「易错点与坑」三节。这三节是提分密度最高的部分。

**考前（查漏）**
翻各科总纲里的**高频考点 Top 15** 和**课程缺口表**，缺口部分单独补。

**每科总纲里都有**：分值结构、章节性价比评级、跨章高频考点、课程缺口、三阶段复习顺序。

## 六、整理方法

字幕导出 → 按教材章节分组（单块 ≤ 8 万字）→ 统一模板逐章精读提炼 → 补写各科总纲（跨章视角）→ 合并成册 → 渲染为离线 HTML。

按分P 分别总结会碎成一地，按教材章节合并才能看出知识结构 —— 这是这套笔记和"AI 速读视频"最大的区别。
