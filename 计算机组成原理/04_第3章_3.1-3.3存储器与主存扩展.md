## 知识点详解

### 一、3.1.1 存储器概述

**1. 四种存取方式（必须能对号入座）**

| 方式 | 特点 | 典型 |
|---|---|---|
| 随机存取 RAM | 存取时间与存储位置无关 | 主存、Cache |
| 顺序存取 SAM | 存取时间取决于位置，越靠后越慢 | 磁带 |
| 直接存取 DAM | 先随机定位到区域，再在区域内顺序找 | 磁盘（柱面号→盘面号→扇区号） |
| 相联存取 | 按内容访问，不是按地址 | 快表 TLB、相联存储器 |

RAM 与 ROM 都是"随机存取"——即访问任一单元时间相同，与位置无关。这是常被拿来设选项的点。

**2. 易失性与破坏性读出（两组概念不要混）**

- 易失性：断电后信息丢失。RAM 易失；ROM、Flash、磁盘、U 盘非易失。
- 破坏性读出：读操作会破坏原存信息，读完必须**立即再生**。DRAM 属此类；SRAM 为非破坏性读出，无需再生。
- ROM 名为"只读"，但 PROM/EPROM/EEPROM/Flash 在特定条件下可重写，只是写比读慢、次数有限。

**3. 存储元 / 存储单元 / 存储字长**

- 存储元（记忆单元）：存 1 位二进制。
- 存储单元：一组存储元，是一个地址对应的全部位。
- 存储字长：一个存储单元存放的二进制位数 = MDR 位数 = 数据总线位数。
- 编址：给存储单元编号。现代计算机**按字节编址**，一个地址对应 1 字节（8 位）。

**4. 访存流程（读/写方向相反）**

地址 → MAR → 地址总线 → 主存地址寄存器 → 地址译码器 → 选中单元；
控制总线发读/写命令；
读：单元内容 → 数据总线 → MDR；写：MDR → 数据总线 → 单元。

与"地址"打交道走 MAR + 地址线；与"数据"打交道走 MDR + 数据线。MAR、MDR 都集成在 CPU 内。

**5. 两个核心等式**

- MAR 位数 = 地址线位数 = 存储单元地址位数
- MDR 位数 = 数据线位数 = 存储字长
- **存储容量 = 2^(MAR位数) × MDR位数**

课上例子：MAR 3 位、MDR 8 位 → 2³=8 个单元，容量 8×8=64 位。地址 5 写作 101，需 3 根地址线；数据 11010011 需 8 根数据线。
若数据线 64 位，则一次读出 64 位 = 8 字节。
若地址线 36 位、按字节编址 → 2³⁶ 个地址 × 1B = 2³⁶ B = 64 GB，地址编号 0 ~ 2³⁶−1。

**6. 存储层次**

寄存器 → Cache → 主存 → 磁盘（→ 磁带/光盘）。越往上：越快、容量越小、价格越高。
CPU 能直接访问 Cache 和主存，**不能直接访问外存**；外存数据必须先调入主存。
Cache-主存层由硬件完成（解决速度）；主存-辅存层由硬件 + 操作系统完成（缺页中断/缺页处理程序，解决容量）。

**7. 存取时间、存取周期、带宽**

- 存取时间 Ta：一次读或写所花时间（收到地址到数据读出/写入完成）。
- 存取周期 Tm：连续两次独立读/写的最小时间间隔，**Tm = Ta + 复原时间**，故 Tm > Ta。
- 复原时间存在的原因：DRAM 破坏性读出后要把数据重新写回（再生）。
- 带宽 = 每个存储周期传送的数据量 ÷ 存储周期。

课上例子：Tm = 50 ns，每周期传 64 位 →
64 bit / 50×10⁻⁹ s = 1.28×10⁹ bit/s = 1.28 Gbit/s = 160 MB/s。

### 二、3.2.1 SRAM 与 DRAM

**1. 特性对比（选择题主战场）**

| 项目 | SRAM | DRAM |
|---|---|---|
| 存储原理 | 触发器（双稳态） | 电容电荷 |
| 速度 | 快 | 慢 |
| 集成度 | 低 | 高 |
| 成本 | 高 | 低 |
| 破坏性读出 | 否，无需再生 | 是，读完需再生 |
| 刷新 | 不需要 | 需要，按行刷新 |
| 行列地址复用 | 否 | 是（引脚减半） |
| 用途 | Cache、TLB（快表） | 主存 |

DRAM 电容会漏电，故必须周期性刷新；刷新的本质是"按行读出并再生"，因此刷新以**行**为单位，一次刷新一整行。

**2. 单译码与双译码**

- 单译码：N 位地址进译码器 → 2^N 根输出线，每根线对应一个单元。16 个单元需 4 位地址、16 根输出线，**输出线过多**。
- 双译码：把单元排成矩阵，X 译码器管行、Y 译码器管列，行与列唯一确定一个单元。16 个单元排成 4 行×4 列，行号 2 位、列号 2 位。

**3. 地址拆分原理（后面所有引脚题的基础）**

地址 ÷ 每行单元数，**商 = 行号，余 = 列号**。因每行 4 个即除以 2²，二进制直接拆：高 2 位行号、低 2 位列号。
例：地址 13 = 1101 → 13÷4 = 3 余 1 → 第 3 行第 1 列（图上行 3 列 1）。
二进制除以 2^k 不用算，直接截断：低 k 位是余数，高位是商。

**4. 图 3.5（64×64×8 的 DRAM）**

- 单元数 64×64 = 2¹²，地址 12 位 A0~A11。
- 每行 64 个 → 除以 64 = 2⁶ → **低 6 位 A6~A11 为列地址，高 6 位 A0~A5 为行地址**。
- 行地址送行地址寄存器 → X 译码器；列地址送列地址寄存器 → Y 译码器。
- 其余部件：存储矩阵、I/O 电路（数据缓冲）、读写控制线 WE、片选 CS。

**5. 图 3.6（2048×2048×4 的 DRAM）与行列地址复用**

- 单元数 2¹¹×2¹¹ = 2²²，本应 22 位地址；行 11 位、列 11 位。
- 地址引脚只有 11 根：先送行地址（RAS 行选通有效）进行缓冲译码，再送列地址（CAS 列选通有效），**分时复用**，引脚数减半。
- 读/写控制 WE；数据引脚 4 位（等于单元位数）。
- 刷新计数器位数 = 行地址位数（此例 11 位）；计数器经多路选择器 MUX 与行地址缓冲器二选一进译码器：选计数器 → 刷新；选行地址 → 正常访存。

**6. 行列设计原则（课后选择题考过）**

1. DRAM 按行刷新 → **行数越少，刷新开销越低**。
2. 地址引脚数由行、列地址位数的**较大者**决定（因复用同一组引脚）→ 行、列应尽量接近，使引脚最少。

例：2²² 个单元 → 2¹¹×2¹¹，引脚 11 根（最优）。
若拆成 2⁸ 行×2¹⁴ 列，引脚需 14 根（取大者）。
若 2⁹ 个单元 → 只能拆 2⁴×2⁵ 或 2⁵×2⁴，两种都是 5 根引脚；要刷新开销低就选**行少**的 2⁴ 行×2⁵ 列（16 行 32 列）。

**7. 行缓冲器与突发传送**

- DRAM 芯片内的行缓冲器由 **SRAM** 实现，容量 = 一行所有单元的数据总量。
- 某行被选中时整行数据装入行缓冲器，后续每个时钟周期输出一个单元，支持**突发传送**：只给首地址，连续读相邻单元，无需每个数据都重新译码。

**8. SDRAM（同步 DRAM）**

传统异步 DRAM：CPU 发出地址和控制信号后必须等待，并不断轮询存储器是否完成，期间不能做别的事。
SDRAM：约定若干时钟后数据必到，CPU 发出命令后去执行其他指令，到点再回来取数，**无需等待**。

### 三、3.2.2 习题提炼：引脚与刷新的算法

- 地址引脚：SRAM **不减半**；DRAM **减半**（题干不写"地址复用"也要自己减）。
- 数据引脚 = 存储单元位数（芯片位宽）。
- 地址引脚还可直接由"总单元数取 log₂ 后减半"，或"行、列位数取最大值"两种算法，结果一致。

课上核对过的数据：
- 1024×8 的 SRAM：地址引脚 10 + 数据引脚 8 = 18。
- 2¹⁰ 个单元的 DRAM：拆 2⁵×2⁵ → 地址引脚 5 + 数据 8 = 13。
- 4M×4 的 DRAM：2²² 单元，22 位地址减半 → 地址引脚 11，数据引脚 4；刷新计数器 11 位。
- 4M×4 的行缓冲器容量：一行 2¹¹ 个单元 × 4 位 = 2K×4 = 8K 位 = 1 KB（选项若给 8 KB 即错）。
- 2¹¹ 个单元的 DRAM：拆 32 行×64 列 → 地址引脚 = max(5,6) = 6。
- 8192×8192（2²⁶ 单元）：行 13 位、列 13 位 → 地址引脚 13。
- 若行、列各由 2^X 增为 2^(X+1)，则单元数变 4 倍，地址引脚只加 1 根。

### 四、3.2.3 非易失性存储器

| 类型 | 写入特点 |
|---|---|
| 掩膜式 ROM（Mask ROM） | 出厂由厂商写好，用户不可改 |
| PROM | 用户可**一次性**编程，写完不可改 |
| EPROM | 可多次擦除重写，但擦写次数有限、写入慢 |
| EEPROM | 电可擦写 |
| Flash（闪存） | 在 EPROM 基础上发展，支持擦除与重写；读快、写慢，**读写性能不对称** |

- ROM 属非易失性，断电不丢失；RAM 与 ROM 都支持随机访问。
- 主板 BIOS 存放在 Flash 中；SSD 由 Flash 芯片构成（SSD 细节另设小节，操作系统也讲）。

### 五、3.2.4 多模块存储器

目的：多个结构相同的模块并行工作，提高存储器吞吐率。

**1. 高位交叉（连续方式 / 顺序方式）**

地址分配：先把 0 号模块的 0~N−1 编完，再编 1 号模块的 N~2N−1……

- 体号 = 地址 ÷ 模块容量 的**商**（高位）
- 体内地址 = 余数（低位）
- 译码只用体内地址（低位）；体号用于选模块。

例：4 个模块、每模块 8 单元，共 32 个地址。
11 ÷ 8 = 1 余 3 → 1 号模块的 3 号单元；22 ÷ 8 = 2 余 6 → 2 号模块的 6 号单元。
二进制：模块容量 8 = 2³，故低 3 位体内地址、高 2 位体号，11 = 01011 → 体号 01、体内 011。

**2. 低位交叉（交叉方式）**

地址分配：0、1、2、3 依次分给 M0、M1、M2、M3，再 4、5、6、7……

- 体号 = 地址 ÷ **模块个数** 的余数（低位）
- 体内地址 = 商（高位）

例：11 ÷ 4 = 2 余 3 → **3 号模块的 2 号单元**；22 ÷ 4 = 5 余 2 → 2 号模块的 5 号单元。
二进制：模块数 4 = 2²，低 2 位体号、高 3 位体内地址，11 = 01011 → 体号 11(3)、体内 010(2)。

**两种编址的除法对象不同，这是最容易记反的地方：高位交叉除"模块容量"，低位交叉除"模块个数"。**

**3. 为什么要交叉：流水与带宽**

- 高位交叉：连续地址都在同一模块，同一模块两次访问必须间隔一个存取周期 T，**不能并行**，总时间 = mT。
- 低位交叉：连续地址分布在不同的 m 个模块，可流水访问。

轮流启动（每模块位宽 = 数据总线宽度）：
- 模块数 **m = T / r**（T 为存取周期，r 为总线周期）
- 每隔 **r = T / m** 启动一个模块（即每个模块推迟一个总线周期启动）
- 连续读 m 个地址总时间 ≈ T + (m−1)r；理想情况带宽提高约 m 倍。

同时启动（数据总线宽度 = m × 单模块位宽）：
- m 个模块同一时刻启动，一个存取周期送出 m 个单元的数据。
- 限制：一次读出的 m 个数据必须**地址对齐**，即各模块的体内地址相同（如 0~3、4~7、8~11）。

**4. 冲突判定**

- 规则：**相邻 m 次访问若落在同一模块，就会冲突**；同一模块连续两次访问之间至少间隔 m 次（等价于间隔一个存取周期 T）。
- 只要相邻 m 次访问分布在不同模块，就不冲突。

### 六、3.3.1 主存容量扩展

三个方向：

1. **位扩展**：只增加每单元位数，地址数不变。
   8K×1 → 8K×8 需 8 片；1K×8 → 1K×32 需 4 片。
   所有芯片地址线全部并联，同一地址同时访问，数据拼接后送数据总线。
2. **字扩展**：只增加单元数（地址数），位数不变。
   16K×8 → 64K×8 需 4 片；1K×8 → 4K×8 需 4 片。
   高位地址译码产生片选，低位地址接各芯片。
3. **字位同时扩展**：先位扩展成一组，再字扩展叠地址。
   16K×4 → 64K×8：地址 16K→64K 需 4 组，位 4→8 每组 2 片 → 共 8 片。

**片数通式：**
所需芯片数 = (目标单元数 / 单片单元数) × (目标字长 / 单片字长)
= 目标总容量 / 单片容量。

例：1K×8 → 2K×32：组数 2K/1K = 2，每组 32/8 = 4 片 → 共 8 片。

### 七、3.3.2 主存储器与 CPU 的连接

**1. 三总线的分工**

- 地址总线位数决定 CPU 可寻址的**最大空间**：N 根 → 2^N 个地址，编号 0 ~ 2^N−1。
- 数据总线位数 = 存储字长 = MDR 位数。
- 控制总线传读/写信号（可一根，0/1 表示读写；也可两根）。

**2. 位扩展连接**

CPU 数据线 8 位、用 8 片 8K×1：地址线 A0~A12（13 位）**并联到所有芯片**，每片贡献 1 位，8 片拼成 8 位。CPU 发一个地址，8 片同时被选中同一单元。

**3. 字扩展连接**

芯片 16K×8 四片组成 64K×8：
- CPU 地址 16 位 A0~A15；每片只需 14 位 A0~A13。
- **低位 A0~A13 直连各芯片地址引脚；高位 A14、A15 送译码器产生 4 个片选信号**。
- 数据线 8 位直连（字扩展不拼数据）。

存储器视角：每片只看到自己的 14 位地址（全 0 ~ 全 1）；CPU 视角：看到合并后的 16 位地址，高 2 位即片号。

**4. 字位同时扩展连接**

16K×4 八片组成 64K×8：
- 每 2 片并联成一组（位扩展，拼成 8 位），共 4 组（字扩展）。
- 低位地址接组内所有芯片；高位译码产生 4 个片选，同时选中一组内的 2 片。
- **片选只需 2 位（4 组），不是 3 位（8 片）**——片选位数只看组数。

**5. 地址分析的通用步骤**

1. 由"总地址数"定总地址位数；
2. 由"单片地址数"定片内地址位数（低位）；
3. 相减得片选位数（高位）；
4. 从**低位**开始切分，切勿从最高位往低位数（十六进制转换常在高位补 0，会把片选位看错）。

## 老师强调的考点

- 3.1 无真题，但术语是后面各节的地基：随机/顺序/直接/相联存取、易失性、破坏性读出、存储字长、MAR/MDR、层次结构，**选择题爱考概念辨析**。
- "RAM 和 ROM 都支持随机访问"——常考判断。
- "CPU 不能直接访问外存"——常考判断。
- 存取周期 = 存取时间 + 复原时间，**选择题必考**；带宽计算也可能考。
- SRAM/DRAM 对比表："必考选择题"，只要选项能判对错即可，不要求默写。
- DRAM 地址引脚减半：**真题默认你自己知道**，题干常不明说，这是必考计算点。
- 刷新按行、刷新计数器位数 = 行地址位数：常考。
- 行列设计原则（行少刷新省、引脚取较大者）：**课后选择题考过**，老师专门画了。
- 行缓冲器用 SRAM 实现、容量 = 一行数据量：真题选项考过。
- 多模块：**真题选择题 + 大题小问都考过**，属于"特别重理解"的点。
- 冲突判定（相邻 m 次访问落同一模块）：真题 34 题原型，常考。
- 同时启动必须地址对齐：真题 35 题原型，容易算错周期数。
- 芯片数量计算：3.3 最常规的送分题，**几乎每年都能出**。
- 片选位数只看组数不看芯片总数：老师反复强调"做题会用到"。
- MAR 位数取"理论最大地址空间"而非"实际容量"：真题 12 题原型，易错。

## 快速技巧与口诀

1. **芯片数 = 目标总容量 ÷ 单片容量**；拆开写就是"组数 × 每组片数"，组数管地址，每组片数管位数。
2. **地址引脚**：先求总单元数取 log₂ 得地址位数，DRAM 再减半；或拆行、列后取较大者。
3. **数据引脚 = 单元位数**；总引脚 = 地址引脚 + 数据引脚 + 控制（RAS/CAS/WE/CS）。
4. **容量 = 2^MAR × MDR**；按字节编址时地址数 = 字节数。
5. **地址范围算个数：末 − 首 + 1**（闭区间）。例 5FFFH − 4000H + 1 = 2000H = 8K。
6. **十六进制转 2 的幂**：2000H = 2×16³ = 2×2¹² = 2¹³；400000H = 4×16⁵ = 2²²。
7. **片选译码**：片选位数 = log₂(组数)；低位地址位宽 = log₂(单片单元数)。
8. **刷新量估算**：刷新按行，一行刷新一次（读出即再生），故刷新一遍的时间 = 行数 × 存取周期；刷新计数器位数 = 行地址位数，计满回绕。（集中/分散/异步三种刷新方式本段未展开，此处只记"按行"。）
9. **高位交叉**：÷模块容量，商体号、余体内地址；**低位交叉**：÷模块个数，商体内地址、余体号。
10. **低位交叉流水**：m = T/r；总时间 = T + (m−1)r；带宽 ≈ m 倍。
11. **同时启动**：总线宽 = m × 单模块位宽；跨块访问要按"对齐块"数周期。
12. **地址切分从低位切起**，先切片内地址，剩下的才是片选。

## 易错点与坑

1. **SRAM 与 DRAM 都易失**。二者都是 RAM，断电都丢数据；"非易失"是 ROM/Flash/磁盘。别把 SRAM 当成非易失。
2. **DRAM 刷新按行，不按单元、不按列**。刷新一次是一整行；刷新计数器存的是行号，位数 = 行地址位数。
3. **刷新不是"重写整个芯片"**，而是逐行读出再生；刷新不需要列地址，故 RAS 有效、CAS 无效。
4. **Cache 与主存**：Cache 用 SRAM，主存用 DRAM；Cache 对程序员透明，由硬件管理；Cache-主存层解决速度，主存-辅存层解决容量。
5. **存取周期 ≠ 存取时间**。Tm = Ta + 复原时间，Tm > Ta。带宽用 Tm 算，不是用 Ta。
6. **多模块交叉的带宽提升受总线周期限制**：模块数与存取周期、总线周期须满足 m = T/r，带宽约提升 m 倍。
7. **高位交叉不提高带宽**。它只是扩大容量，连续地址仍在同一模块，必须串行等待 T。
8. **同时启动 ≠ 任意 m 个连续地址**。必须地址对齐（各模块体内地址相同），否则要拆成多个周期。35 题 8 字节跨 3 个对齐块 → 3 个存取周期。
9. **片选位数看组数**。8 片但只有 4 组时，片选只要 2 位。
10. **地址范围分析从低位起**。十六进制高位常是补的 0 或预留位，从高位切会切错。例 11 题 13 位地址，前面 3 个 0 是补齐位，真正片选是 01。
11. **"字数"与"字长"**：字数 = 存储单元个数（对应地址数），字长 = 每单元位数。字扩展改字数，位扩展改字长。
12. **DRAM 引脚减半只对地址引脚**，数据引脚不变。
13. **行缓冲器容量按"位"算**：2K×4 = 8K 位 = 1KB，不是 8KB。

## 本章例题

### 例1（3.2.2 引脚计算组）
**题干要点**：1024×8 的 SRAM 求地址/数据引脚；2¹⁰ 单元 DRAM 求引脚；4M×4 DRAM 求地址引脚、数据引脚、刷新计数器位数、行缓冲器容量。
**解**：
- SRAM 不减半：地址 10 根，数据 8 根。
- DRAM 2¹⁰ 单元：拆 2⁵×2⁵，地址引脚 5，数据 8，共 13。
- 4M×4：2²² 单元 → 22 位地址减半 = 11 根地址引脚；数据 4 根；刷新计数器 11 位；行缓冲器 = 2¹¹×4 = 8K 位 = 1KB。
**答案**：10+8；5+8；11、4、11 位、1KB。

### 例2（课后 34 题，四体交叉冲突）
**题干要点**：四体交叉编址，判断哪两个地址会发生访存冲突（8000H、8001H、8002H、8003H、8004H、8005H、8006H、8007H、8008H 中）。
**解**：交叉编址体号 = 地址 mod 4。
- 8004H mod 4 = 0，8008H mod 4 = 0，同模块，但两者间隔 4 次访问，≥ m，不冲突。
- 8002H mod 4 = 2，8007H mod 4 = 3，不同模块，不冲突。
- 8001H 与 8008H：1 与 0，不同模块，不冲突。
- 8000H mod 4 = 0，8004H mod 4 = 0，且相邻访问，间隔 < 4，**冲突**。
**答案**：D（8000H 与 8004H）。

### 例3（课后 35 题，同时启动的周期数）
**题干要点**：四体交叉、同时启动，存储器总线 32 位、每芯片 8 位；double 型变量占 8 字节，按字节编址，首地址 804001AH，求读取该变量需几个存取周期。
**解**：
1. 32 位总线 = 4×8 位 → 同时启动，一次读 4 个模块的同一体内地址（地址对齐块）。
2. 首地址末位 A H = 1010B，mod 4 = 2 → 从 2 号模块起，占 1A~21H 共 8 个地址。
3. 对齐块为 18~1B、1C~1F、20~23，该变量跨 3 个块。
**答案**：3 个存取周期。

### 例4（课后 37 题，内存条综合）
**题干要点**：内存条含 8 片 DRAM，每片 8192×8192×8 位，存储器总线 64 位。
**解**：
- 8×8 位 = 64 位 → 同时启动，且必须是交叉编址。
- 容量 = 8 × 2¹³ × 2¹³ × 8 位 = 2²⁹ B = 512 MB。
- 行缓冲器 = 8192×8 位 = 64K 位 = 8 KB，由 **SRAM** 构成。
- 地址引脚：8192 行、8192 列各 13 位，取大者 = 13 根（不是 26 根，因地址复用）。
**答案**：容量 512MB；行缓冲 8KB、SRAM 实现；地址引脚 13。

### 例5（扩展片数，64KB 含 ROM）
**题干要点**：存储容量 64KB，按字节编址；其中 ROM 4KB 用 2K×8 芯片，RAM 60KB 用 4K×4 芯片，各需多少片。
**解**：
- ROM：2K → 4K，字扩展，4K/2K = 2 片。
- RAM：4K×4 → 60K×8，字位同时扩展；组数 60K/4K = 15，每组 8/4 = 2 片 → 30 片。
**答案**：ROM 2 片，RAM 30 片。

### 例6（课后 13 题，按字节编址 + 地址范围）
**题干要点**：64KB 空间，4000H~5FFFH 为 ROM 区，其余为 RAM；ROM 用 8K×4 SRAM，求片数。
**解**：
1. 地址个数 = 5FFFH − 4000H + 1 = 2000H = 2×16³ = 2¹³ = 8K → ROM 8KB。
2. RAM = 64KB − 8KB = 56KB = 56K×8。
3. 8K×4 → 56K×8：组数 56K/8K = 7，每组 2 片。
**答案**：14 片。

### 例7（课后 14 题，按字编址）
**题干要点**：RAM 区 000000H~3FFFFFH，按字编址、字长 32 位；用 512K×8 芯片，求片数；另给地址线 24 位。
**解**：
1. 地址数 = 3FFFFFH + 1 = 400000H = 4×16⁵ = 2²²。
2. 目标 2²²×32 位；芯片 512K×8 = 2¹⁹×8。
3. 组数 2²²/2¹⁹ = 8，每组 32/8 = 4 片。
4. 24 位地址线 → 总空间 2²⁴ 个地址，减去 RAM 的 2²²，余下即 ROM 空间（本题未问）。
**答案**：32 片；按字编址必须由题干给字长，否则无法计算。

### 例8（课后 12 题，MAR 位数）
**题干要点**：存储地址空间 64MB，实际主存容量 32MB，芯片 4M×8，求 MAR 位数。
**解**：三个数分别是 2²⁶（理论最大地址空间）、2²⁵（实际容量）、2²²（扩展前芯片）。MAR 是硬件，必须按**理论最大地址空间**设计，否则以后扩容无法寻址。
**答案**：26 位。

### 例9（课后 11 题，片内首末地址）
**题干要点**：2K×4 芯片组成 8K×8 存储器，求片选为 01 的那组芯片的最小、最大地址。
**解**：
1. 8K×8 / (2K×4)：组数 8K/2K = 4，每组 2 片，共 8 片。
2. 总地址 8K = 2¹³ → 13 位；片内 2K = 2¹¹ → 低 11 位；片选 2 位。
3. 片选 01 + 11 个 0 → 01 000 0000 0000 = 0800H；片选 01 + 11 个 1 → 0FFF H。
**答案**：最小 0800H，最大 0FFF H（选 D）。

### 例10（课后 9 题，片选地址反推）
**题干要点**：片选地址为 111，芯片 32K×16，求该芯片在存储器中的首地址与末地址。
**解**：
1. 32K = 2¹⁵ → 片内 15 位；片选 3 位 → 总 18 位。
2. 首地址 = 111 + 15 个 0 → 0011 1000 0000 0000 0000 = 38000H。
3. 末地址 = 111 + 15 个 1 → 0011 1111 1111 1111 1111 = 3FFFFH。
**答案**：38000H ~ 3FFFFH（选 B）。注意这是 CPU 视角的地址，单看芯片只有 15 位。

### 例11（课后 6 题，A0 为高位）
**题干要点**：A0~A15 中 A0 为高位，4K×4 芯片组成 16K×8，求片选所用地址线。
**解**：
1. 4K → 16K，组数 4，片选 2 位。
2. 片内 4K = 2¹² → 12 位（A4~A15，因 A0 是高位，顺序反置）。
3. 剩余 A2、A3 作片选。
**答案**：A2、A3（选 A）。此类题务必先按题目声明的高低位置排，不能默认 A0 是最低位。
