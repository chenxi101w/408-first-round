## 三、跨章高频考点 Top 15（按真题出现频率排序）

1. **补码与真值互转**（含快速求法：符号位不变、其余取反加一）
2. **IEEE754 单精度/双精度的位划分、真值计算、特殊阶码四情况**
3. **判溢出**：Cn ⊕ Cn−1、双符号位、标志位 OF/CF 的区别
4. **Cache 地址拆分**：块内地址 → 行号/组号 → 标记，三字段位数计算
5. **Cache 总容量**：行数 ×（标记 + 有效位 + 脏位 + 替换位 + 数据位）
6. **主存芯片扩展**：芯片数 = 目标容量 / 单片容量；地址线、数据线、片选译码
7. **多模块交叉存储**：m 体低位交叉的带宽与流水条件 m = T/r
8. **寻址方式的 EA 与访存次数**（十种方式对比表）
9. **扩展操作码分配**（短操作码不能是长操作码前缀）
10. **数据通路微操作序列**（单总线一个时钟只能有一个 out 信号）
11. **流水线三条公式**：T=(k+n−1)Δt、S=nk/(k+n−1)、E=n/(k+n−1)
12. **三类流水线冒险的判定与解决**（结构/数据/控制）
13. **三种 I/O 方式对比**：CPU 干预程度、数据传送单位、适用场景
14. **中断响应三步（中断隐指令、硬件完成）与处理流程**
15. **存储器性能指标**：存取时间/存取周期、刷新开销、命中率与平均访问时间

## 五、三阶段复习与刷题顺序

**第一阶段：按章过 + 只做课后题（约 3 周）**
顺序不要按教材，按「计算密集度」排：**第 3 章 Cache → 第 2 章 → 第 5 章 → 第 4 章 → 第 7 章 → 第 1、6 章**。
理由：Cache 是全书最抽象的一块，早啃早消化；第 2 章规则最密，趁热刷；第 5 章和第 3 章的数据通路/存储层次有联动。

**第二阶段：真题按题型切片（约 2 周）**
不按年份做整套，按题型做：先把「补码+IEEE754」20 道一次性做完，再做「Cache 地址拆分」15 道，再做「芯片扩展」10 道。同类题集中做才能看出套路。

**第三阶段：整卷 + 错题回炉（考前 5 周）**
每周 2 套完整 408（严格 3 小时），错题只记「错因分类」：概念错 / 计算错 / 审题错 / 时间不够。计算错要在错题旁写出完整的中间步骤，不能只写答案。

**每日时间建议**：组成原理每天 1.5~2 小时，其中 60% 做计算题、40% 背表格（寻址方式、特殊阶码、I/O 方式对比），不要用大块时间看视频。
