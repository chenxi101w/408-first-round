### 1.2.1 计算机系统层次结构

**学科特点（决定复习策略）**：组成原理一多半知识点以计算题形式考，一小半以概念题形式考。计算题直来直去；概念题需要专门记，但不会挖太深，不必纠结底层原理。第一章会提前牵扯后面章节（运算器/控制器在第五章、存储器在第三章、I/O 在第七章、总线在第六章），第一轮看不懂正常，学完后续章节回看即可。带星号的“计算机发展历程”大纲已删除，直接跳过。第一轮只抓真题常考的重点，边角知识留到二轮查漏补缺。

#### 1. 计算机系统 = 硬件 + 软件

- 硬件：CPU（运算器 + 控制器）、存储器（内存 + 外存）、输入设备、输出设备、总线。
- 软件：系统软件（操作系统 Windows/macOS、数据库管理系统 DBMS）、应用软件（QQ、微信、浏览器、WPS）。
- 存储器分内存与外存：内存 16G/32G 量级，外存 512G/1T 量级。
- 外设（I/O 设备，第七章、7.2 节 I/O 接口）：由**物理功能部件**（负责真正的输入输出）和**设备控制器**（负责与主机通信、控制前者工作）组成。键盘接口、显示控制器、网卡、磁盘控制器、USB 控制器都属设备控制器，统称 I/O 控制器 / I/O 接口。

#### 2. 冯·诺依曼机（重点，真题考过选择题）

**存储程序**：把编好的程序和数据提前存入存储器，计算机启动后自动、连续地取指令并执行。

五条要点：

1. 五大部件：运算器、控制器、存储器、输入设备、输出设备；运算器 + 控制器 = CPU（今也可划分为数据通路 + 控制单元）。
2. 指令和数据都以**二进制**形式存放，且**形式相同**——仅凭内容无法区分谁是指令谁是数据，计算机靠“当前处于取指阶段还是取数阶段”来区分（PC 指向取出的必是指令）。
3. 指令由**操作码 + 地址码**组成：操作码指明操作类型（加/减/乘/除），地址码给出操作数所在地址。一条指令的地址码个数可以是 0、1、2、3 个（第四章展开）。
4. 程序一般**顺序执行**：执行完一条，接着执行下一条地址的指令；遇到 if-else 等会**跳转执行**。
5. 操作码的具体编码不需要记，考试一定给出“某编码代表什么操作”。

**内存模型与实例**：内存由一个个存储单元组成，每个单元有唯一地址（类比一栋楼、每间房有房号）。设 0～3 号单元存数据：`35、162、81、192`；5、6 号单元存两条指令。

| 指令 | 操作码 | 地址码 | 实际动作 |
|---|---|---|---|
| 指令1（5 号单元） | 0110 = 加法 | 1 号、3 号 | 162 + 192 |
| 指令2（6 号单元） | 0101 = 减法 | 2 号、0 号 | 81 − 35 |

两条指令在内存里同样是一串 0/1，外观与数据无差别，可见“形式相同、内容不可区分”。（原文举例前后操作码取值不一致，0110/0101 与 0001/0010 混用，属口播示意，不必对齐。）

#### 3. 功能部件

- **ALU（算术逻辑单元）**：完成所有算术运算（加减乘除）与逻辑运算（与或非）。
- **通用寄存器组**：为 ALU 提供数据、暂存运算结果，实现高速数据访问（寄存器访问速度极快）。
- **多路选择器**：第五章 5.3 数据通路中的硬件，后续大题会用。
- **控制单元**：从存储器取出指令 → **译码**（把操作码翻译成具体操作）→ 生成控制信号。译码就是“拿到一串二进制，判断它是加法还是减法”。

#### 4. 总线结构（图1.1，了解即可）

CPU 经**处理器总线**连北桥（IO 桥接器）；存储器经**存储器总线**连北桥；鼠标键盘经 USB 控制器、显示器经显卡适配器、磁盘经磁盘控制器，统一经**IO 总线**接到 IO 桥接器。磁盘数据送 CPU 的路径：磁盘 → 磁盘控制器 → IO 总线 → IO 桥接器 → 处理器总线 → CPU；内存数据则经存储器总线 → 北桥 → 处理器总线 → CPU。该图真题频率不高，认识名词即可。

#### 5. 三种语言（重点，靠记忆）

| 语言 | 形态 | 特点 |
|---|---|---|
| 机器语言 | 0/1 指令序列 | **计算机唯一能识别并直接执行**的语言 |
| 汇编语言 | 英文助记符（mov、add） | 提高程序可读性；**必须经汇编程序**转成机器语言才能运行 |
| 高级语言 | C、C++、Java、Python | 可经编译程序→汇编→机器语言，也可直接编译成机器语言 |

转换关系：一条高级语言语句 → **多条**汇编语句；一条汇编语句 ↔ **一般一条**机器指令（一一对应）。

**实例**：`sum = 100 + 200;`（高级语言 1 行）

```
mov 100, R1      ; 100 → R1
mov 200, R2      ; 200 → R2
add R1, R2, R1   ; R1 + R2 → R1
mov R1, sum      ; 结果 → sum
```

四条汇编对应四条机器指令：操作码 `0001` 表示 mov、`0010` 表示 add，寄存器号 `01` 表示 R1、`10` 表示 R2，立即数 100、200 以二进制形式出现在指令中。讲义里机器指令末尾写成 `sum` 只是便于理解，真实机器码全为二进制。

汇编存在的意义：直接看机器码 `0001 0110 0100` 无法一眼看出在干什么，转成助记符后可读性大幅提升。

#### 6. 三种翻译程序（易混，必考选择题）

- **汇编程序**：汇编语言 → 机器语言。
- **编译程序**：高级语言 → 汇编语言，**或**高级语言 → 机器级目标代码（一步到位也行）。
- **解释程序**：**逐条**翻译并**立即执行**，**不生成独立的目标程序**；下次运行要重新逐条翻译。Python 是典型解释型，C/C++ 是编译型（Windows 下编译后生成 .exe，下次直接运行 .exe）。
- 比喻：编译像把整本英文书一次译成中文，以后直接读译本；解释像每次读书都现场逐句翻译。

#### 7. ISA 与程序员分类

- **ISA（Instruction Set Architecture，指令集体系结构）**：缩写要记，4.1 节详讲。
- **应用程序员**：用高级语言开发应用软件（WPS、浏览器、QQ）。
- **系统程序员**：开发操作系统、编译器、数据库管理系统等系统软件。
- 微体系结构：真题基本不涉及，第一轮不看。

#### 8. 存储程序的工作原理

程序运行前，把**第一条指令的地址**送入 **PC（程序计数器）**。每条指令的经典流程：

1. **取指**：按 PC 内容从主存取出指令（PC=5 就取 5 号单元的指令）。
2. **PC 自增**：PC+1（5→6），从而自动指向下一条指令，这是“自动连续执行”的硬件保障。
3. **译码**：解析操作码，确定做加法还是减法。
4. **取操作数**：按地址码去对应单元取数（如 1 号、3 号单元的 162 和 192）。
5. **执行**：完成运算。
6. **写回**：必要时把结果写回存储器。

顺序执行是常态，跳转由程序逻辑（if-else）决定。可执行文件中的代码段就是一条条机器指令，其执行就是反复“取指—译码—执行”。

#### 9. 从源程序到可执行文件（重点，真题考过）

以 UNIX 下 `hello.c` 为例（Windows 下最终产物是 .exe，格式不同）：

1. **预处理**：处理 `#include <stdio.h>` 等头文件，把头文件内容**原样展开替换**；同时**删除注释**。注意头文件只引入 printf 等函数的**声明**，不引入实现。
2. **编译**：高级语言 → **汇编程序**（.s）。
3. **汇编**：汇编程序 → **机器语言**，生成**目标文件**（.o，一堆二进制）。此时**还不能运行**。
4. **链接**：把 printf 等**库函数的具体实现**加载进来，并把一个项目里多个源文件（A.cpp、B.cpp、C.cpp）各自生成的目标文件合并，最终生成**可执行目标文件**。

关键区别：目标文件 ≠ 可执行目标文件；汇编结束只是“机器码就位”，缺库函数实现、缺多文件合并，必须链接后才能运行。

### 1.3.1 计算机的性能指标（四星，计算题高频）

吞吐量、响应时间：课程明确说**没考过**，可暂不管。重点是下面几个。

#### 1. 时钟周期与主频

- **时钟周期 T**：CPU 工作的**最小时间单位**。一条指令分 4 个阶段，每阶段至少占 1 个时钟周期。第五章流水线中，每个流水段的最大时间就设为 1 个时钟周期。
- **主频 f（CPU 时钟频率）**：$f = 1/T$，直观含义是**每秒包含的时钟周期数**，单位 Hz。
- 例：T = 0.2 s → f = 1/0.2 = 5 Hz，即 1 秒含 5 个时钟周期。
- 时间换算（做题高频）：$1\,s = 10^3\,ms = 10^6\,\mu s = 10^9\,ns$。

#### 2. CPI

**CPI（Cycles Per Instruction）**：执行**一条指令**平均需要的时钟周期数。

$$\text{平均CPI}=\frac{\text{时钟周期总数}}{\text{指令条数}}$$

例：5 条指令共耗 10 个时钟周期 → 平均 CPI = 10/5 = 2。

分类指令混合时，设总条数为 N，各类占比 $p_i$、CPI 为 $CPI_i$：

$$\text{平均CPI}=\sum_i p_i \cdot CPI_i$$

因为分子分母的 N 会约掉，**直接用比例加权，不必假设 N**。

#### 3. IPS / MIPS

$$\text{IPS}=\frac{f}{\text{CPI}}\quad(\text{条/秒}),\qquad \text{MIPS}=\frac{f}{CPI \times 10^6}$$

理解：主频是“每秒多少个时钟”，CPI 是“一条指令占几个时钟”，一除即“每秒几条指令”。例：f = 10 Hz、CPI = 2 → 5 条/秒。

**MIPS** 全称百万条指令每秒，单位本身已含 $10^6$：20 MIPS 即每秒 $20\times10^6$ 条，**不要再乘 $10^6$**。

**FLOPS**：每秒浮点运算次数（float operations per second）。

#### 4. CPU 执行时间

$$T_{cpu}=\frac{N \times CPI}{f}=\frac{\text{时钟周期总数}}{\text{主频}}=\frac{N}{V}$$

其中 V 为指令执行速度。三种写法可互推：$V=f/CPI$，$T=N/V$，与“路程 = 速度 × 时间”同理。

#### 5. 数量级前缀

频率/速率用十进制：$K=10^3$、$M=10^6$、$G=10^9$、$T=10^{12}$、$P=10^{15}$、$E=10^{18}$、$Z=10^{21}$。这组数**真题直接考过**，必须背。

容量/文件大小用二进制：$1K=2^{10}$、$1M=2^{20}$、$1G=2^{30}$、$1T=2^{40}$。

判断规则：**大写 K 一定是 $2^{10}$，小写 k 一定是 $10^3$**；M/G/T 大小写不区分含义，只能靠场景判断——存储容量、文件大小、操作系统页面大小（4KB = $4\times2^{10}$ B）用 2 的幂；频率、速率、带宽（100M 网 = $100\times10^6$）用 10 的幂。K/M/G 本质是**数字前缀**，`16GB` 的单位是 B，G 只是 $2^{30}$ 这个数。

#### 6. 基准程序

专门用于性能评测的程序：在不同机器上运行**同一个**基准程序，比较执行时间，判断谁快谁慢。

## 易错点与坑

**概念类**

- 指令和数据**形式相同**，靠“取指阶段/执行阶段”区分，不是靠内容或存放位置区分。
- “数据在指令中直接给出”是错的：绝大多数指令给的是**地址码**，要按地址再取数；只有立即寻址才是数据直接在指令中。
- **目标文件 ≠ 可执行目标文件**：汇编后得到 .o，不能运行；链接后才生成可执行文件。
- 预处理只引入库函数的**声明**并删除注释；库函数**实现**在链接阶段才装入。
- 编译程序可高级→汇编，也可高级→机器码；汇编程序是汇编→机器；解释程序**不生成**目标代码文件。
- 链接程序处理的是**已经是机器码的目标文件**，不是高级语言源程序。
- 存储程序是“程序和数据**预先**存入主存，之后自动逐条取指执行”，不是边输入边执行。
- 存储容量 16G 的 G 是 $2^{30}$，主频 1.5G 的 G 是 $10^9$，同一个字母两种含义。
- 大写 K = $2^{10}$，小写 k = $10^3$；M/G/T 只能看场景。

**计算类**

- 平均 CPI 不是各类 CPI 的算术平均，必须按**指令比例加权**：0.8×1 + 0.2×10 = 2.8，而不是 (1+10)/2 = 5.5。
- $T=N\times CPI/f$ 默认算出的是**秒**；选项常给 ms/μs，须再换算（$2.8\times10^{-5}$ s = 28 μs = 0.028 ms）。
- 主频单位 GHz 代入时要写 $10^9$，不要写成 $10^6$ 或 $2^{30}$。
- MIPS 结果已含 $10^6$：算出 $0.4\times10^9$ 条/秒，应表述为 400 MIPS（$400\times10^6$），不是 0.4 MIPS。
- 求时间比值时，同一 ISA + 同一基准程序 ⇒ N 相同，可直接约掉：$T_1/T_2=(CPI_1/CPI_2)\cdot(f_2/f_1)$；注意主频在**分母**，比值方向别写反。
- 指令条数与 CPI 同时变化时，按乘积缩放：条数 ×0.7、CPI ×1.2 ⇒ 时间 ×0.84。
- 单位前缀题先统一成“次/秒”，再对照中文数量级：千万亿 = $10^{15}$，亿亿 = $10^{16}$。
- 把“每秒执行条数多”直接等同于“程序跑得快”是错的：同一高级语言程序在不同机器上编译出的 N 可能不同（10 条 @5 条/秒 = 2 s，6 条 @4 条/秒 = 1.5 s）。

## 本章例题

**例1（概念）** 计算机硬件能直接执行的只有？
答：**机器语言**。汇编、高级语言都必须翻译。

**例2（概念）** 将高级语言程序转换成机器级目标代码文件的是？
A. 汇编程序　B. 链接程序　C. 编译程序　D. 解释程序
答：**C**。汇编程序针对汇编语言；链接程序把目标文件变成可执行目标文件；解释程序不生成目标代码文件。

**例3（概念）** 关于冯·诺依曼机，错误的是？
选项涉及：程序由 CPU 执行指令、指令和数据都是二进制且形式上无区别、程序执行前指令和数据要提前放入主存、数据在指令中直接给出。
答：**“数据在指令中直接给出”错误**。指令中通常给地址码，需按地址访存取数（立即寻址只是少数）。

**例4（概念）** 高级语言程序变为可执行目标文件的正确顺序？
答：**预处理 → 编译 → 汇编 → 链接**。

**例5（16 题）** 程序原执行时间 20 s，指令条数降为原来 70%，CPI 增为原来 1.2 倍，主频不变，求新执行时间。
解：$T=N\cdot CPI/f$，$T'=0.7N\times1.2CPI/f=0.84T=0.84\times20=16.8$ s。答：**16.8 s（D）**。

**例6（17 题）** 两台机器 ISA 相同、运行同一基准程序，CPI₁=2、CPI₂=1，f₁=1.5 GHz、f₂=1.2 GHz，求 $T_1/T_2$。
解：同一基准程序 + 同一 ISA ⇒ $N_1=N_2=N$。
$$\frac{T_1}{T_2}=\frac{N\cdot CPI_1/f_1}{N\cdot CPI_2/f_2}=\frac{CPI_1}{CPI_2}\cdot\frac{f_2}{f_1}=\frac{2}{1}\times\frac{1.2}{1.5}=1.6$$
答：**1.6（C）**。

**例7（18 题，2021 真题）** 浮点运算速度 93.0146 PFLOPS，约为每秒多少次浮点操作？
解：$P=10^{15}$，$93.0146\times10^{15}=9.30146\times10^{16}\approx9.3\times10^{16}$ 次/秒。亿亿 = $10^8\times10^8=10^{16}$，故为 9.3 亿亿次/秒。答：**9.3 亿亿次/秒（D）**（原文口播“9.3E1”存疑，按数量级应为 $9.3\times10^{16}$）。

**例8（15 题）** 基准程序含四类指令：A 占 50%、CPI=2；B 占 20%、CPI=3；C 占 10%、CPI=4；D 占 20%、CPI=5。主频 1.2 GHz，求平均 CPI 与 MIPS。
解：
$$\text{平均CPI}=0.5\times2+0.2\times3+0.1\times4+0.2\times5=1+0.6+0.4+1=3$$
$$\text{IPS}=\frac{1.2\times10^9}{3}=0.4\times10^9=400\times10^6\ \text{条/秒}$$
答：**平均 CPI = 3，400 MIPS**。

**例9（19 题）** 80% 指令 CPI=1，20% 指令 CPI=10；共 $10^4$ 条，主频 1 GHz，求执行时间。
解：平均 CPI = $0.8\times1+0.2\times10=2.8$；
$$T=\frac{10^4\times2.8}{10^9}=2.8\times10^{-5}\ \text{s}=28\ \mu s$$
答：**28 μs（A）**。

**例10（20 题）** 主频 1.5 GHz、CPI=1.2、指令 $5\times10^5$ 条，求指令执行速度与执行时间。
解：$V=f/CPI=1.5\times10^9/1.2=1.25\times10^9$ 条/秒 = **1.25 GIPS**；
$$T=\frac{5\times10^5\times1.2}{1.5\times10^9}=4\times10^{-4}\ \text{s}=0.4\ \text{ms}=400\ \mu s$$
（也可 $T=N/V=5\times10^5/1.25\times10^9=4\times10^{-4}$ s，两法一致。）答：**1.25 GIPS，0.4 ms（C）**。

**例11（非真题第 3 题）** M1、M2 运行同一高级语言程序，平均 CPI 相等，能否由主频高判定“执行速度快”？
解：不能。主频高只能得 $V=f/CPI$ 大（每秒条数多），但两机编译出的指令条数 $N_1、N_2$ 未知。反例：M1 为 10 条指令、5 条/秒 → 2 s；M2 为 6 条指令、4 条/秒 → 1.5 s，M2 反而先跑完。题干“执行速度”实指**整个程序执行时间短**。答：**不能，选 D**。

**例12（非真题第 9 题）** 同类型题：题干“执行速度快 10 ns”，严格表述应为**执行时间**短 10 ns。
