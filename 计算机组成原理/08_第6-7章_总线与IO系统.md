## 知识点详解

### 一、6.1 总线

#### 1. 总线的分类

- **内部总线（片内总线）**：CPU 芯片内部的总线，用于寄存器之间、寄存器与 ALU 之间。
- **系统总线**：系统内各功能部件（CPU、主存、I/O 接口）之间传送信息的总线，是本章重点。
- **I/O 总线**：连接各种 I/O 控制器。

系统总线按传送信息分为三类：

| 总线 | 方向 | 传送内容 |
|---|---|---|
| 数据总线 | 双向 | 指令、数据、状态字、中断类型号 |
| 地址总线 | 单向 | 主存单元地址、I/O 端口地址 |
| 控制总线 | 单向 | 存储器读写、I/O 读写、中断请求/响应、总线请求/应答、仲裁与握手信号 |

两个结论：

1. **寻址能力由地址线位数决定**：16 位地址线可编址 \(2^{16}\) 个单元。
2. **一次能传多少位由总线宽度（数据线位数）决定**，不是"一次传一位"。

**总线复用**：同一组线路分时传不同信息，如地址/数据线复用（初期传地址、后期传数据）。DRAM 行/列地址复用是芯片内地址复用，与此不同。

#### 2. 性能指标与总线带宽（高频计算）

- **总线传输周期（总线周期）**：总线完成一次数据传送所需的时间。
- **总线时钟频率 F**：每秒的时钟周期数。
- **总线工作频率 f**：每秒能传送数据的次数。它与时钟频率的关系取决于"几个时钟传一次"：
  - 1 个时钟传 2 次 → \(f=2F\)；
  - 2 个时钟传 1 次 → \(f=F/2\)。
- **总线宽度 W**：数据线位数，常折成字节（32 位 = 4 B，64 位 = 8 B）。
- **总线带宽**：

\[
B = W \times f
\]

单位是 B/s（宽度取字节）。带宽是**理论峰值（最大数据传输速率）**，只按"数据真正在总线上传"的那段速度折算，**不含传地址、准备数据等开销**；若把全部时间都算进去，得到的是**平均数据传输速率**。

老师比方：10 s 摆 100 个零件、工人 40 s 组装。只问工人速度 = 100/40（带宽）；问全流程 = 100/50（平均速率）。

#### 3. 总线事务与突发传送

一次总线事务（完成一次信息交换）按真题口径分三个阶段：

1. **地址传送阶段**：送出地址及读/写命令；
2. **数据准备阶段**：从主存取数据或向外设准备数据（题目不说耗时就不管，说了按题目算）；
3. **数据传送阶段**：真正在数据线上传送。

- **非突发传送**：每传一个数据都要"传地址 → 准备 → 传数据"。例：地址 100、101、102、103 中存 X、Y、A、B，则传 X、Y、A、B 各走一遍完整流程。
- **突发传送**：只传**一个首地址**，后续地址由硬件自增，不再占用地址线。上例只发 100，随后连续传 X、Y、A、B。

"突发传送"这个术语真题出现频率极高（13、14、16、17、18、19 题反复出现），概念简单但必须重视。

#### 4. 串行/并行与总线定时

- **串行传送**：一根双向线或两根单向线逐位传，**抗干扰能力强**。
- **并行传送**：多根线同时传多个比特。并行不一定比串行快——频率提高后线间干扰严重，高速场合反而用串行提升频率。
- **同步定时**：全系统统一时钟，收发双方在约定时刻发送/接收。
- **异步定时**：无统一时钟，靠**握手信号**。不互锁：请求发出后自动撤销，最快、最不可靠；半互锁：收到回答才撤销请求；全互锁：回答方确认请求方收到回答后才撤销，最慢、最可靠。

半同步、分离式只需知道概念：分离式把地址/数据分开发送，提高总线利用率。

#### 5. 总线结构

- **单总线**：所有部件挂一条系统总线，同一时刻只能一对部件通信，必须分时。
- **南北桥**：北桥接高速设备（CPU、内存、显卡），南桥接低速 I/O。低速设备数据先到南桥再到北桥，最后到内存/CPU。
- **现代结构**：点对点直连，CPU 经片内存储器控制器直接访存；多通道内存并行，带宽接近单通道整数倍；QPI 用于多 CPU 或 CPU 与外设高速互连。

### 二、7.2 I/O 接口

**I/O 接口 = I/O 控制器**，实现主机与外设之间的信息交换。核心功能是**数据缓冲**，解决 CPU 与外设的速度不匹配。

举例：CPU 花 1 s 把数据送到接口，打印机要 100 s 才打完。无接口时 CPU 干等 100 s；有接口时 CPU 放下数据就去干别的，打印机自己慢慢取，接口空出后 CPU 再送下一组。

三个寄存器（本节核心）：

| 寄存器 | 作用 | CPU 操作方向 |
|---|---|---|
| 数据缓冲寄存器 | 暂存 CPU 与外设之间的数据 | 可读可写（双向） |
| 状态寄存器 | 记录接口及外设状态（就绪/忙碌、缺纸等错误） | **只读**（接口→CPU） |
| 控制寄存器 | 保存 CPU 发给外设的控制命令（启动、关闭、暂停） | **只写**（CPU→接口） |

状态寄存器与控制寄存器方向相反、时间错开，因此**常复用同一端口地址**。

三个易错结论：

1. **控制命令也走数据线**，不是控制线；数据线传数据、状态、控制命令、中断类型号，控制线传读写、中断请求/响应、仲裁握手。
2. 地址线传的是**接口内部寄存器的端口地址**。
3. **端口 = 接口中 CPU 可直接访问的寄存器**（数据端口、状态端口、控制端口）。

**端口编址**：

- **独立编址**：I/O 端口有独立地址空间，地址可与主存地址相同（如主存 0~3、端口也 0~3）。区分靠**不同指令**：访存指令访问内存，I/O 指令访问端口；I/O 指令的地址字段指明端口号。I/O 指令通常是**特权指令**。
- **统一编址**：端口与主存共享同一地址空间，按**地址范围**区分，不需要专门 I/O 指令，普通访存指令即可访问端口。

### 三、7.3 I/O 方式

#### 1. 程序查询方式

CPU 通过执行程序，**每次传送前先查状态端口**：忙则循环等待，就绪才传数据。

- **独占查询**：CPU 不干别的，连续不断查状态端口，直到空闲。
- **定时查询**：周期性查询（如每 10 s 一次），两次查询之间 CPU 可执行其他程序。

流程：传参数 → 启动外设 → 取外设状态 → 就绪则传送，忙则继续查。

缺点：CPU 大量时间浪费在查询上。重要程度：程序查询 ★，中断 ★★★，DMA ★★。

#### 2. 程序中断方式

**中断**：CPU 执行 P1 时出现紧急事件，暂停当前程序转去处理，处理完返回断点继续。对 P1 而言"执行一半被打断"，故称中断。

图 7.3 要能读：**现行程序、中断服务程序、外部设备**三条线。外设取走接口数据 → 发中断请求 → 打断现行程序 → 执行服务程序再送/取一组数据 → 中断返回。

**内中断（异常）与外中断（中断）**：

| | 内中断（异常） | 外中断（中断） |
|---|---|---|
| 与当前指令关系 | 由当前指令引发，有关 | 无关，外部事件触发 |
| 响应时机 | 指令执行**过程中** | 当前指令执行**结束后** |
| 返回位置 | 故障返回当前指令；陷阱返回下一条 | 下一条指令 |
| 典型例子 | 缺页、除数为 0、非法指令、地址越界、系统调用、断点 | 键盘/打印机 I/O、时钟、电源掉电 |

**异常三分类**：

1. **故障（Fault）**：可恢复的如缺页（页面调入后**重新执行当前指令**）；不可恢复的如非法指令、整数除 0（程序终止）。缺页**属于异常/内中断**，真题反复考，不能写成外中断。
2. **陷阱（Trap）**：**主动**转入操作系统内核，在一条指令**正常执行完毕后**触发，断点调试、系统调用、条件陷阱均属此类；返**下一条**。
3. **终止（Abort）**：硬件故障（控制器出错、存储器出错），程序被迫终止，不返回。

故障、陷阱属**软件中断**；终止和外中断属**硬件中断**。

外中断分：

- **可屏蔽中断**：关中断（IF=0）时 CPU 不响应；
- **不可屏蔽中断**：电源掉电等紧急事件，不受中断允许影响，关中断也响应。

**中断请求标记寄存器**记录各中断源的请求；响应优先级由**硬件排队器**判优。

**中断响应条件**：有中断请求；中断允许（异常、不可屏蔽中断不受此限）；**当前指令执行完毕**（针对外中断）。

**中断响应三步（中断隐指令，硬件完成）**：

1. **关中断**——防止保存断点时又被中断；
2. **保存断点和 PSW**——故障断点为当前指令地址，中断/陷阱为下一条；有的架构只存 PC；
3. **引出服务程序**——识别中断类型，入口地址送 PC。

**中断隐指令不是一条真正的指令**，是 CPU 响应中断时硬件操作序列的统称。它**不保存通用寄存器**，通用寄存器属于第四步"保护现场"。

**中断向量、中断向量表、中断类型号**：

- **中断向量** = 中断服务程序的入口地址；
- **中断向量表** = 所有中断向量集中存放的表（数组结构）；
- **中断类型号** = 访问该表的索引（数组下标）。

过程：从数据总线取得中断类型号 → 以它为下标查中断向量表 → 取出中断向量 → 送入 PC。此法称**中断向量法**，采用它的中断称**向量中断**。

**中断处理九步（必须背）**：

1. 关中断；
2. 保存断点和程序状态字；
3. 引出中断服务程序；
4. 保护现场和屏蔽字（现场通常指通用寄存器）；
5. 开中断（允许中断嵌套）；
6. 执行中断服务程序；
7. 关中断；
8. 恢复现场和屏蔽字；
9. 开中断、中断返回。

前三步 = 中断响应，由**中断隐指令（硬件）**完成；4~9 步 = 中断处理，由**中断服务程序（软件）**完成。**单重中断**时第 5、7 步可省略。

#### 3. 多重中断与中断屏蔽字

**多重中断**：执行中断服务程序时又被更高处理优先级的中断打断，形成嵌套。

- **响应优先级**：由**硬件排队器**决定，一般不可屏蔽中断高于可屏蔽中断、高速设备高于低速设备。
- **处理优先级**：多重中断的实际处理顺序，由**中断屏蔽字**调整；不用屏蔽技术时与响应优先级一致。

**屏蔽字写法**（只看处理优先级）：能屏蔽"处理优先级比自己低"的中断源，对应位写 1；**自己也写 1**；屏蔽不了的高优先级写 0。

例 7.3：响应优先级 A>B>C>D，处理优先级 A>D>C>B，按 A、B、C、D 位序：

- A：可屏蔽 B、C、D 及自己 → **1111**
- D：可屏蔽 C、B 及自己 → **0111**
- C：可屏蔽 B 及自己 → **0011**
- B：只能屏蔽自己 → **0001**

例 7.3 第二问的时序（看图要点）：

1. 主程序处 A、C、D 同时请求 → **在主程序看响应优先级**，A 最高，执行 A；A 处理优先级也最高，不被打断，A 完返回主程序。
2. 剩 C、D，响应优先级 C>D → 执行 C。
3. C 执行中，早已排队的 D 处理优先级高于 C → D 打断 C；D 完**返回 C**。
4. C 执行中 B 到达 → B 处理优先级低于 C，不打断；C 执行完返回主程序。
5. 最后响应 B，B 完返回主程序。

口诀：**主程序看响应，服务程序看处理；谁打断我，我回谁**。

#### 4. DMA 方式

**DMA**：Direct Memory Access，在主存与外设之间建立**直接数据通路**，传送不经过 CPU，由**硬件**控制。适用磁盘、显卡、声卡、网卡等**高速设备**；中断适合键盘、打印机等低速设备。DMA 本身也会用中断（传送结束中断）。

DMA 控制器就是接口：外设 → DMA 接口 → 系统总线 → 内存。DMA 控制器向 CPU 发 DMA 请求，目的是**取得总线控制权（接管总线）**；传送期间 CPU 不能访存，但可以不访存而执行其他不需要总线的操作。

**两种重点传送方式**：

1. **停止 CPU 访存**：DMA 请求后 CPU 放弃总线控制权并暂停访存，**整块数据**传送完再归还总线。
2. **周期挪用（周期窃取）**：每传完**一个数据字**就释放总线；CPU 正在访存则等一个存储周期；CPU 与 DMA 同时申请时 **DMA 优先**。

**DMA 传送过程**：

1. **预处理**（CPU 参与）：设置主存起始地址、传送方向（读/写）、传送数据个数；
2. **数据传送**（纯硬件）：以**块**为单位（周期挪用则以**字**为单位），不需 CPU 参与；
3. **后处理**（CPU 参与）：DMA 向 CPU 发中断请求，CPU 执行中断服务程序，校验数据。

**DMA 与中断对比**：

| 项目 | 中断 | DMA |
|---|---|---|
| 数据通路 | 经 CPU（服务程序搬） | 外设⇄内存直连 |
| 响应时机 | 每条指令执行结束后 | 总线周期结束后（总线空闲即可），不管指令是否完成 |
| 现场 | 需保存/恢复 | 不需 |
| 实现 | 软件（服务程序） | 硬件 |
| 适用 | 低速设备 | 高速设备 |
| 优先级 | — | DMA 访存优先于 CPU |

#### 5. CPU 用于 I/O 的时间占比

\[
\text{I/O 时间占比}=\frac{\text{每秒 I/O 次数}\times\text{每次 I/O 时钟周期数}}{\text{主频}}
\]

单位统一：速率类 K 用 \(10^3\)，频率类按 \(10^6/10^9\) 换算，时间默认秒再折 ns。

例：每秒 200 次、每次 500 个时钟、主频 50 MHz → \(\frac{200\times500}{50\times10^6}=0.2\%\)。
例：50 KB/s、每次 4 B → 12500 次/s；每次 1000 时钟、主频 1 GHz → \(\frac{12500\times1000}{10^9}=1.25\%\)。

中断开销 = 中断响应（前三步）+ 中断处理（后六步），即九步的总时间。

## 老师强调的考点

- **总线带宽计算：必考级高频**。这一小节真题绝大多数是计算，公式只有"带宽=工作频率×宽度"，但题目只给时钟频率，必须先换算工作频率。
- **突发传送：常考术语**，13、14、16、17、18、19 题连续出现；只传首地址、后续地址硬件自增。
- **总线事务三阶段（传地址→准备数据→传数据）：考过大题**（2013 年、2023 年），教材上没有现成文字，按真题流程记。
- **平均速率 vs 峰值带宽：选择题爱考**，24 题用 7 个时钟算 3.84 GB/s 是经典错项。
- **中断：本章最重要，三颗星**。真题数量最多，选择题、大题都考。
- **中断处理九步：必背**，老师要求"尽早背，不要留到最后"；前三步硬件、后六步软件。
- **中断隐指令：选择题爱考**，只做关中断、保存断点/PSW、引出服务程序三件事，不保存通用寄存器。
- **中断屏蔽字：常考**，只看处理优先级，自己写 1，按位从高到低排列。
- **缺页属于内中断/异常：反复考**，不能写成外中断；缺页返回当前指令重新执行。
- **"当前指令执行完才响应"：反复考**，外中断不能一有请求就立即响应。
- **异常在指令执行中响应、中断在指令执行后响应：选择题爱考**。
- **DMA 适用于高速设备：常考**（2013、2023、2025 年重复出现）。
- **DMA 与中断的响应时机、现场保存：选择题爱考**。
- **CPU 用于 I/O 时间百分比：大题爱考**，课后第 7、10 题就是纯代公式。
- **准备数据时间与中断处理时间的关系：大题小问出现过**，外设准备数据时间应 ≥ 中断处理时间，否则数据被覆盖。

## 快速技巧与口诀

### 三种 I/O 方式对比

| 方式 | CPU 干预程度 | 数据传送方向/路径 | 适用场景 |
|---|---|---|---|
| 程序查询 | 最高，全程忙等查询状态 | 外设⇄接口⇄CPU，CPU 执行程序搬运 | 极低速、简单设备 |
| 程序中断 | 较高，每传一个数据都要响应+服务程序 | 外设⇄接口⇄CPU，CPU 执行服务程序搬运 | 键盘、打印机等低速设备 |
| DMA | 最低，只参与预处理和后处理 | 外设⇄DMA 接口⇄内存，**不经过 CPU** | 磁盘、显卡、网卡等高速设备 |

趋势：程序查询 → 中断 → DMA，**CPU 干预越来越少，并行度越来越高**。

### 三个必背流程

- **中断响应（隐指令，硬件 3 步）**：关中断 → 保存断点和 PSW → 引出服务程序（入口送 PC）。
- **中断处理（软件 6 步）**：保护现场和屏蔽字 → 开中断 → 执行服务程序 → 关中断 → 恢复现场和屏蔽字 → 开中断、中断返回。
- **DMA 过程**：预处理（CPU 设起始地址/方向/个数）→ 数据传送（硬件，块/字）→ 后处理（中断，CPU 校验）。

### 公式与口诀

- **总线带宽 = 宽度（B）× 工作频率**；工作频率 = 时钟频率 × 每时钟传送次数。
- **一个时钟两次就乘 2，两个时钟一次就除以 2**。
- **带宽只算数据段，平均速率才算全程**（"只问工人干活，不算摆零件"）。
- **突发只传首地址，地址时间别忘记加**。
- **断点：故障当前、中断下条、陷阱下条、终止不回**。
- **屏蔽字：低优先级写 1，自己写 1，高优先级写 0**。
- **DMA 传块，周期挪用一个字**。

## 易错点与坑

1. **总线宽度 ≠ 总线带宽**。宽度是数据线位数（bit 或 B），带宽是"宽度×工作频率"（B/s）。题目给"64 位总线"只说明宽度，必须再乘工作频率。
2. **同步定时 ≠ 异步定时**。同步靠全系统统一时钟，不是各设备各自提供时钟；异步靠握手信号，不互锁最快最不可靠，全互锁最慢最可靠。半同步是"统一时钟+握手"的折中。
3. **中断隐指令由硬件完成，不是指令**。它只做前三步；通用寄存器由第四步"保护现场"保存，属中断服务程序（软件）的事，选择题常把通用寄存器塞进隐指令。
4. **中断屏蔽字看处理优先级，不看响应优先级**；位序不能写反（一般从左到右为高级到低级），自己对自己必须写 1。响应优先级由硬件排队器决定，屏蔽字不能改响应顺序，只能改实际处理顺序。
5. **DMA 与中断响应时机不同**。中断在**一条指令执行结束后**响应；DMA 在**总线周期结束后**（总线空闲）响应，不必等当前指令完成。DMA 不保存/恢复现场，因为它不是一个程序被打断。
6. **DMA 传送单位是块**（停止 CPU 访存方式），**周期挪用才以字为单位**。47 题"整个数据块传送期间 CPU 都不能访存"是停止 CPU 访存的特征，不是周期挪用。
7. **中断服务程序与用户程序是两个不同的程序**。用户程序在用户态，中断服务程序在内核态；不是函数调用，靠中断向量跳转、靠中断返回指令返回断点。缺页"发生"在用户态，"处理"在内核态。
8. **控制命令走数据线**，不要因为名字叫"控制"就选控制线；中断类型号也走数据线，中断请求/响应信号才走控制线。
9. **有中断请求 ≠ 立即响应**。要等当前指令执行完；但"检测到中断请求就响应"是对的，因为检测动作本就发生在指令执行完之后。
10. **DMA 没有"DMA 传送程序"**。数据传送阶段纯硬件完成，只有预处理和后处理需要 CPU。

## 本章例题

### 一、总线带宽计算

**例 1（16 题）**：总线时钟频率 10 MHz，总线周期占 2 个时钟，宽度 4 B，求带宽。

- 2 个时钟传 1 次 → 工作频率 \(10/2=5\) MHz；
- 带宽 \(=5\text{ M}\times4\text{ B}=20\) MB/s。

**例 2（21 题）**：时钟频率 66 MHz，每时钟周期传 2 次数据，宽度 32 位，求带宽。

- 工作频率 \(=66\times2=132\) MHz；宽度 \(=32/8=4\) B；
- 带宽 \(=132\text{ M}\times4=528\) MB/s。

**例 3（24 题，易错）**：时钟频率 420 MHz，宽度 64 位，每个时钟传 2 次；突发传送第 1 个时钟传地址和读写命令，第 4~7 个时钟传 8 次数据。求最大数据传输速率。

- 错解：7 个时钟传 8×8=64 B → \(420/7=60\) M，\(60\times64=3840\) MB/s=3.84 GB/s（误选 A）。这是把地址阶段也算进去的**平均速率**。
- 正解：带宽只看数据段。4 个时钟传 8 次 = 每时钟 2 次 → 工作频率 \(420\times2=840\) MHz；
- \(840\text{ M}\times8\text{ B}=6720\) MB/s=**6.72 GB/s**，选 B。

**例 4（25 题）**：已给工作频率 1333 MHz、宽度 64 位，另给"每时钟传 4 次"干扰条件。

- 带宽 \(=1333\text{ M}\times8\text{ B}=10664\) MB/s=**10.664 GB/s**，选 A。工作频率不能再乘 4。

**例 5（13 题）**：宽度 32 位，时钟频率 100 MHz，突发传送，传一个地址或一个数据均占 1 个时钟，求传 120 位的时间。

- 时钟周期 \(=1/100\text{ MHz}=10\) ns；
- \(120/32=3.75\) → 需传 4 次，\(4\times10=40\) ns；
- 加首地址 1 个时钟 10 ns → **50 ns**（不要选 40 ns）。

**例 6（20 题）**：宽度 64 位，时钟频率 1 GHz，不支持突发；每次传地址 1 ns、准备数据 6 ns、传数据 1 ns；传 32 B。

- 每次事务 \(=1+6+1=8\) ns；\(32/8=4\) 次；
- 总时间 \(=4\times8=32\) ns。

### 二、中断与异常概念题

**例 7（10 题）**：异常响应后一定返回发生异常的指令继续执行？

- 错。可恢复故障（缺页）返回当前指令；不可恢复故障（除 0）终止；陷阱返回下一条；终止不返回。

**例 8（11 题）**：缺页、整数除 0、DMA 结束、存储保护错各属什么？

- 缺页：异常中的**故障**，可恢复；整数除 0：**故障**，不可恢复；DMA 结束：**外中断**；存储保护错：**异常**，不可恢复。

**例 9（12、13 题）**：陷阱是内中断还是外中断？谁返回当前指令？

- 陷阱是**内中断（异常）**，主动进内核，返回下一条；只有**缺页**返回当前指令，系统调用、陷阱、DMA、键盘 I/O 均返回下一条。

**例 10（34 题）**：单重中断，问中断服务程序内要做什么。

- 答：保护现场 → （单重可不开中断）→ 中断服务处理 → 恢复现场 → 开中断 → 中断返回。不能把关中断、保存断点、找入口地址算进去，那是中断隐指令。

**例 11（35 题）**：L0~L4，处理优先级中 L1 能屏蔽 L3，求 L1 的屏蔽字。

- 按 L0~L4 位序：0 1 0 1 0 → **01010**，选 D。

**例 12（37 题）**：中断隐指令包括哪些？

- 关中断、保存断点（PC/PSW）、形成中断服务程序入口地址。通用寄存器不属于，属保护现场。

**例 13（41、42、46 题）**：多重中断须在服务程序中开中断；中断排队按响应优先级并综合屏蔽字，不是先来先服务；隐指令保存 PC/PSW，不保存通用寄存器；外设中断一般可屏蔽，不可屏蔽中断优先级更高；屏蔽字改变的是**处理优先级**。

**例 14（48~50 题）**：多重中断在内核态也能响应；"检测到请求就响应"对，"一有请求就响应"错（要等指令执行完）；键盘、打印机适合中断，磁盘适合 DMA；外设准备数据时 CPU 可执行其他程序；准备数据时间应 **≥** 中断处理时间，否则新数据覆盖旧数据；DMA 结束由硬件发中断，服务程序自动返回。

**例 15（52 题）**：中断屏蔽字依据什么确定？

- **处理优先级**，不是响应优先级。

### 三、DMA 概念题

**例 16（47 题）**：DMA 接口数据缓冲寄存器 32 位，磁盘块 512 B，采用周期挪用，判断"整个数据块传送期间 CPU 不能访存"。

- 错。这是**停止 CPU 访存**方式。周期挪用每传完一个 32 位字（4 B）就释放总线，CPU 可在下一个周期访存；每传一个字都要发一次总线请求，DMA 优先级高于 CPU；整块传完发中断。

**例 17（51、53 题）**：

- 三种方式从查询→中断→DMA，CPU 干预递减；
- DMA 没有"DMA 传送程序"，传送靠硬件，"执行 DMA 传送程序"说法错；
- DMA 控制器与**内存**之间传送数据（不是与 CPU）。

### 四、I/O 开销计算

**例 18（36 题）**：每秒 200 次 I/O，每次 500 个时钟，主频 50 MHz。

\[
\frac{200\times500}{50\times10^6}=0.2\%
\]

**例 19（43 题）**：外设速率 50 KB/s，数据缓冲寄存器 32 位（4 B），每次 I/O 1000 个时钟，主频 1 GHz。

- 次数 \(=50000/4=12500\) 次/s；
- 占比 \(=\dfrac{12500\times1000}{10^9}=1.25\%\)。
