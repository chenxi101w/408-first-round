## 知识点详解

### 一、树的基本概念与性质（5.1.1）

**定义（递归）**：树是 n（n≥0）个结点的有限集；n=0 为空树；n>0 时有唯一根，其余结点分成若干**互不相交**的子树。老师强调"树的定义是递归的"：每个孩子本身又是一棵树，所以遍历、求高、转换都用递归写。

**核心结论 1**：n 个结点的树有 **n-1 条边**。推导：除根外，每个结点**向上**恰有一条边连向双亲，根没有，故边数 = n-1 → **顶点比边多 1**。

**核心结论 2（森林）**：森林是 m 棵互不相交的树的集合，**顶点数 - 边数 = m**。因为每棵树贡献 1。
数字例：25 个结点、15 条边 → 25-15 = 10 棵树（真题以这个形式考过，教材没专门写这条）。

**术语表**（对照图：A(B(E(K,L),F), C(G), D(H,I,J(M)))，共 13 个结点、12 条边）

| 术语 | 含义 | 本例 |
|---|---|---|
| 结点的度 | 孩子个数 | D 的度 = 3；K 的度 = 0 |
| 树的度 | 所有结点度的最大值 | 3（D 取到） |
| 叶/终端结点 | 度为 0 | K、L、F、G、H、I、M |
| 分支/非终端/非叶 | 度 > 0 | A、B、C、D、E、J |
| 层次 = 深度 | 从根往下数第几层，根为第 1 层 | A 深度 1，D 深度 2，M 深度 3 |
| 结点高度 | 以该结点为根的**子树**层数，从它往下数 | D 的高度 = 2（D→J→M） |
| 路径长度 | 路径上**边的数目**（不是结点数） | A 到 M 长度 2；B 到 G 长度 3 |
| 堂兄弟 | 双亲互为兄弟 | E 与 G |

**易混**：深度从**根往下**数到该结点；高度从**该结点往下**数子树层数。同一个结点两者一般不相等（A 的深度 1、高度 3）。

**m 叉树 vs 度为 m 的树**（老师专门提醒，选项/题干里出现过）：
- **m 叉树**：每个结点的度 **≤ m**，允许是空树；
- **度为 m 的树**：**至少有一个**结点的度**恰为 m**。
例：一棵最大度为 4 的树，可以叫 4 叉树、5 叉树、6 叉树（只要不超过），但**不能**叫 3 叉树；反过来，叫"度为 4 的树"就必须真有一个结点度 = 4。

**树的性质（5 条，老师只要求记第 1 条，其余会推）**

| 编号 | 结论 | 推导要点 |
|---|---|---|
| ① | 结点数 = 所有结点度之和 + 1 | 度之和 = 边数，再用 n = 边+1。**要记** |
| ② | 度为 m 的树第 i 层至多 m^(i-1) 个结点 | 第 1 层 1 个，之后每个结点最多 m 个孩子，逐层乘 m |
| ③ | 高 h 的 m 叉树至多 (m^h-1)/(m-1) 个结点 | 等比数列 1+m+m²+…+m^(h-1) 求和 |
| ④ | n 个结点的 m 叉树最小高度 | 每层塞满：前 h-1 层最多 (m^(h-1)-1)/(m-1) < n ≤ (m^h-1)/(m-1)，解出 h |
| ⑤ | n 个结点的度为 m 的树最大高度 = **n-m+1** | 必须有一个结点有 m 个孩子（多占 m-1 个结点），其余每层只挂 1 个 |

数字例（m=3，n=13）：
- ③ 高 3：1+3+9 = 13 = (3³-1)/2 ✓
- ④ 前 2 层最多 1+3 = 4 < 13 ≤ 13，故最小高度 = 3
- ⑤ 最大高度 = 13-3+1 = 11（根 + 3 个孩子 = 4 个结点，之后每层 1 个，还能再挂 9 层）

**有序/无序树**：交换左右子树算不同的树 → 有序树；否则无序树。了解即可。

### 二、二叉树的定义、特殊形态与五大性质（5.2.1）

**定义**：每个结点**至多两棵**子树，且**严格区分左右**（即使只有一个孩子，也要分清是左还是右）。

**二叉树 vs 度为 2 的有序树**（了解）：度为 2 的有序树**至少有 3 个结点**（必须有一个结点度恰为 2）；二叉树**可以为空**，也可以只有一个孩子且左右有意义。

**特殊二叉树**

| 类型 | 定义 | 关键结论 |
|---|---|---|
| 满二叉树 | 高 h，含 2^h-1 个结点，每层都满 | 叶全在第 h 层，n0 = 2^(h-1)，非叶 = 2^(h-1)-1 |
| 完全二叉树 | 按"从上到下、从左到右"连续编号 1..n 与满二叉树一一对应 | 叶子只出现在**最后两层**；度 1 结点**至多 1 个**；最后一个分支结点编号 ⌊n/2⌋ |
| 二叉排序树 | 左 < 根 < 右（7.3 讲） | 中序遍历得递增序列 |
| 平衡二叉树 | 任一结点左右子树高度差 ≤ 1（7.3 讲） | 查 O(log n) |
| 正则二叉树 | 只有度 0 和度 2 的结点 | 满足 n0 = n2+1，总结点数必为**奇数** |

**完全二叉树的直观判定**：上一层排满才排下一层，同一层不能留空洞。反例：6 号左孩子空着先填 6 号右孩子、7 号左边空着先填 13 号，都不是完全二叉树。

#### 五大性质（逐条推导 + 数字例子）

**性质 1：非空二叉树 n0 = n2 + 1（叶结点数 = 度为 2 的结点数 + 1）**

推导：设度 0、1、2 的结点数为 n0、n1、n2。
结点总数 n = n0+n1+n2；边数 = n1 + 2n2（度之和）；又 n = 边数 + 1。
→ n0+n1+n2 = n1+2n2+1 → **n0 = n2+1**（n1 自动消掉，与 n1 无关）。
数字例：树 A(B(D,E), C(F,_))：n0 = 3（D、E、F），n2 = 2（A、B），3 = 2+1 ✓。
老师要求："这个直接拿来用，今后**不要再推导**。"

**性质 2：第 i 层至多 2^(i-1) 个结点**

推导：第 1 层 1 = 2⁰；每个结点最多 2 个孩子，故每往下 1 层翻倍。
数字例：第 5 层最多 2⁴ = **16** 个（满二叉树第 5 层就是 16 个叶子）。

**性质 3：高 h 的二叉树至多 2^h - 1 个结点**

推导：1+2+4+…+2^(h-1) = 2^h-1（等比，首项 1、公比 2、h 项）。
数字例：h=5 → 31 个（正是"前 5 层满 = 2⁵-1 = 31"，做题高频）。
**对比记忆**：第 i 层是 `2^(i-1)`（减在**指数**上）；高 h 总共是 `2^h-1`（减在**外面**）。

**性质 4：完全二叉树的编号关系（根从 1 开始编号）**

| 关系 | 公式 | 条件 |
|---|---|---|
| 双亲 | ⌊i/2⌋ | i > 1 |
| 左孩子 | 2i | 2i ≤ n |
| 右孩子 | 2i+1 | 2i+1 ≤ n |
| 最后一个分支结点 | ⌊n/2⌋ | 编号 > ⌊n/2⌋ 的全是叶子 |

推导：按层序连续编号，第 i 个结点的孩子必然排在第 2i、2i+1 位（前面每层都满）。判"有没有这个孩子"就是拿 2i、2i+1 与 **n** 比大小。
数字例（n=12）：⌊12/2⌋ = 6 → 6 是最后一个分支结点，7~12 全为叶；8、9 的双亲 ⌊8/2⌋=⌊9/2⌋=4；6 的左孩子 12 ≤ 12 存在，右孩子 13 > 12 **不存在**；7 的左孩子 14 > 12，**无孩子**。

**根从 0 开始编号时公式全变**（老师特意警告，真题大题考过 0 起编号）：

| 关系 | 0 起编号 |
|---|---|
| 左孩子 | 2i+1 |
| 右孩子 | 2i+2 |
| 双亲 | ⌊(i-1)/2⌋ |

数字例：i=5、i=6 的双亲都是 ⌊4/2⌋ = ⌊5/2⌋ = **2**（若误用 ⌊6/2⌋=3 就错）。

**性质 5：n 个结点的完全二叉树高度 h = ⌈log₂(n+1)⌉ = ⌊log₂ n⌋ + 1**

推导：高 h 的完全二叉树结点数落在 (2^(h-1)-1, 2^h-1]，取对数向上取整即可。
数字例：n=12 → ⌈log₂13⌉ = 4（2³=8 < 12 ≤ 16=2⁴），⌊log₂12⌋+1 = 3+1 = 4 ✓；n=1000 → ⌊log₂1000⌋+1 = 9+1 = **10**（512 < 1000 ≤ 1024）。
老师补充：7.2 折半查找判定树的高度是**同一个公式**，可以放在一起记。

**完全二叉树的推论（老师要求"多打几个星"）**
1. 最后一个分支结点编号 ⌊n/2⌋（第 8 章建堆要用）；
2. 叶子只出现在最后两层；
3. 度 1 的结点个数只能是 **0 或 1**；
4. **n0 + n2 一定是奇数**（= 2n2+1）。推论：n 为偶数 ⇒ n1 = 1；n 为奇数 ⇒ n1 = 0。
   例：n=768（偶）→ n1=1，n0 = (768-1+1)/2 = 384。

### 三、二叉树的存储结构（5.2.2 / 5.2.3）

**顺序存储**：用一组连续单元，**按完全二叉树的层序**存放；不是完全二叉树要先"补空结点"补成完全二叉树，**空结点也占一个单元**（填 0、-1 或 1 之类的特殊值）。

为什么要补空？例：两棵不同的树
- 树甲：A(B(D,E), C) → 层序 A B C D E
- 树乙：A(B(_,D), C(E,_)) → 层序（去掉空）也是 A B C D E
若只存 ABCDE，同一个物理结构会还原出两棵树，**不唯一**。补空后：甲 = `A B C D E`，乙 = `A B C _ D E _`，唯一了。

**下标映射**：数组下标 1..n 与完全二叉树编号一致，双亲/孩子直接用性质 4 算，O(1) 找双亲是它相对链式的唯一优势。缺点：非完全二叉树浪费大量空间（高度 5 的歪树要 31 个单元）。

**链式存储（二叉链表）**：结点 = 数据域 + 左指针 + 右指针，**离散存放**，靠指针链接。

```c
typedef struct BiTNode{
    ElemType data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;
```

这个定义老师要求**背**（大题可能让写），并指出它更像**双链表**的结点（两个方向指针）。

**空链域个数：n 个结点的二叉链表有 n+1 个空指针**
推导：总指针域 2n；每条边对应**恰好一个**非空指针域，边有 n-1 条 → 非空 n-1 → 空 = 2n-(n-1) = **n+1**。
第二种理解：把空链域补成虚拟结点后所有结点度为 2，虚拟结点即叶子，n0 = n2+1，此时 n2 = 原结点数 n → 空链域 = n+1。

**三叉链表**（多一个指向双亲的指针）：总指针 3n，非空 = 孩子指针 (n-1) + 双亲指针 (n-1) = 2n-2，空 = 3n-(2n-2) = **n+2**（根的双亲指针也为空）。

### 四、二叉树的遍历（5.3.1 / 5.3.2）

**定义**：按某种规则**每个结点访问一次**。本质是"把非线性结构线性化"。

| 遍历 | 口诀 | 特征 |
|---|---|---|
| 先序 DLR | 根 → 左 → 右 | 序列首元素必为根；根总在子树序列最前 |
| 中序 LDR | 左 → 根 → 右 | 根把序列切成"左段 | 根 | 右段" |
| 后序 LRD | 左 → 右 → 根 | 序列末元素必为根 |
| 层次 | 逐层从左到右 | 需**队列**，不是递归 |

老师说：先序从**根**出发，中序从**最左下**出发，后序"从下往上看、从左往右看"。

**老师给的例子（务必练到"看完就能写"）**：树 A(B(D(E,_),_), C(F(N,_), H(I,K)))

| 遍历 | 序列 |
|---|---|
| 先序 | A B D E C F N H I K |
| 中序 | E D B A N F C I H K |
| 后序 | E D B N F I K H C A |
| 层次 | A B C D F H E N I K |

**递归代码（教材补充；老师本轮明确说代码留到强化阶段，先跳过）**

```c
void PreOrder(BiTree T){
    if(T){
        visit(T);              // 根
        PreOrder(T->lchild);   // 左
        PreOrder(T->rchild);   // 右
    }
}
```
中序 = 把 visit 挪到两次递归中间；后序 = 挪到最后。三者只是 visit 位置不同，时间 O(n)，递归栈空间 O(h)（最坏 O(n)）。

**非递归（用栈）**——本质是"用栈模拟递归的返回路径"

```c
// 先序：入栈即访问
void PreOrder2(BiTree T){
    InitStack(S); BiTree p = T;
    while(p || !IsEmpty(S)){
        if(p){ visit(p); Push(S,p); p = p->lchild; }
        else { Pop(S,p); p = p->rchild; }
    }
}
// 中序：只有一处不同——visit 放在 Pop 之后
//    if(p){ Push(S,p); p=p->lchild; }
//    else { Pop(S,p); visit(p); p=p->rchild; }
// 后序：需判断右子树是否已访问（r 记录上一个访问的结点）
void PostOrder2(BiTree T){
    InitStack(S); BiTree p = T, r = NULL;
    while(p || !IsEmpty(S)){
        if(p){ Push(S,p); p = p->lchild; }
        else{
            GetTop(S,p);
            if(p->rchild && p->rchild != r) p = p->rchild;   // 右子树没走完
            else { Pop(S,p); visit(p); r = p; p = NULL; }     // 右子树已访问
        }
    }
}
```
要点：栈的最大深度 = 树高 h；先序/中序的栈中元素恰是"当前结点的所有祖先"，中序出栈序列即中序序列。

**层次遍历（用队列）**：根入队 → 出队即访问 → 左右孩子依次入队 → 循环到队空。

```c
void LevelOrder(BiTree T){
    InitQueue(Q); BiTree p;
    if(T) EnQueue(Q,T);
    while(!IsEmpty(Q)){
        DeQueue(Q,p); visit(p);
        if(p->lchild) EnQueue(Q,p->lchild);
        if(p->rchild) EnQueue(Q,p->rchild);
    }
}
```

手算流程（上面的例子）：

| 步骤 | 出队 | 入队后队列 |
|---|---|---|
| 1 | A | B C |
| 2 | B | C D |
| 3 | C | D F H |
| 4 | D | F H E |
| 5 | F | H E N |
| 6 | H | E N I K |
| 7 | E | N I K |
| 8 | N | I K |
| 9 | I | K |
| 10 | K | 空 |

出队序列 = A B C D F H E N I K，正好是层次序列（入队顺序也相同）。

**由遍历序列构造二叉树**

唯一性结论：

| 组合 | 能否唯一确定 |
|---|---|
| 先序 + 中序 | **能** |
| 后序 + 中序 | **能** |
| 层次 + 中序 | **能** |
| 先序 + 后序 | **不能**（只能确定"每层是否只有一个孩子"这类信息） |
| 先序 + 层次 | 不能 |

**手算三步（先序 + 中序）**
1. **找根**：先序序列的**第一个**元素就是当前子树的根（后序则取**最后一个**；层次则取当前段中**最靠前**的）。
2. **切分**：在中序序列里找到这个根，根左边是左子树结点集合，右边是右子树结点集合，并数出**左子树结点个数 k**。
3. **递归**：按 k 把先序序列切成"根 | 左 k 个 | 其余"，对左右两段分别重复 1–2。

**例（王道例题）：先序 ABCDEFGHI，中序 BCAEDGHFI**

| 步 | 当前先序段 | 根 | 中序切分 | 结果 |
|---|---|---|---|---|
| 1 | ABCDEFGHI | A | BC \| A \| EDGHFI | 左 2 个、右 6 个 |
| 2 | BC | B | B \| C | C 是 B 的**右**孩子 |
| 3 | DEFGHI | D | E \| D \| GHFI | 左 E，右 4 个 |
| 4 | FGHI | F | GH \| F \| I | 左 GH，右 I |
| 5 | GH | G | G \| H | H 是 G 的**右**孩子 |

成树：A 左 B（B 右 C），A 右 D（D 左 E，D 右 F；F 左 G（G 右 H），F 右 I）。
验证：中序 = B C A E D G H F I ✓，先序 = A B C D E F G H I ✓。

后序 + 中序做法完全相同，只把"找根"改成取后序段**最后一个**；层次 + 中序则每轮在层次序列中取"落在当前段里最靠前"的那个作根。

### 五、线索二叉树（5.3.5）

**动机**：n 个结点的二叉链表有 n+1 个空链域，浪费。线索化就是把**空左指针改为指向前驱、空右指针改为指向后继**（按某种遍历次序）。

**结点结构**：多了两个标志位

| ltag | lchild 指向 | rtag | rchild 指向 |
|---|---|---|---|
| 0 | 左孩子 | 0 | 右孩子 |
| 1 | **前驱** | 1 | **后继** |

```c
typedef struct ThreadNode{
    ElemType data;
    struct ThreadNode *lchild, *rchild;
    int ltag, rtag;
} ThreadNode, *ThreadTree;
```

**中序线索化的指针规则**（对中序序列中每个结点 p，pre 为 p 的前驱）
- 若 `p->lchild == NULL` → `p->lchild = pre; p->ltag = 1;`
- 若 `pre != NULL && pre->rchild == NULL` → `pre->rchild = p; pre->rtag = 1;`
- 最后 `pre = p;`，继续中序遍历。
- 中序**第一个**结点无线索前驱，lchild 仍为 NULL；**最后一个**结点无线索后继，rchild 仍为 NULL → 线索化后**仍剩 2 个空指针**。

**图 5.17 实例**：树 A(B(_,D), C(E,_))，中序 **B D A E C**，5 个结点应有 6 个空链域。

| 结点 | ltag | lchild | rtag | rchild |
|---|---|---|---|---|
| B | 1 | NULL（中序首结点，无前驱） | 0 | D（右孩子） |
| D | 1 | B（前驱） | 1 | E（后继） |
| A | 0 | B | 0 | C |
| E | 1 | A（前驱） | 1 | C（后继） |
| C | 0 | E | 1 | NULL（中序末结点，无后继） |

6 个空链域中 4 个变成线索，2 个仍为空（首、末）。

**ltag / rtag 组合判定表（找中序前驱/后继，O(1)）**

| ltag | rtag | 结点形态 | 中序前驱 | 中序后继 |
|---|---|---|---|---|
| 0 | 0 | 左右孩子都有 | 左子树中**最右**的结点 | 右子树中**最左**的结点 |
| 0 | 1 | 有左孩子，右为空 | 左子树中最右的结点 | `rchild`（即线索） |
| 1 | 0 | 左为空（线索），有右孩子 | `lchild`（即线索） | 右子树中最左的结点 |
| 1 | 1 | 叶子/双线索 | `lchild`（线索） | `rchild`（线索） |

口诀：**tag=1 直接取指针；tag=0 就往那棵子树里"钻到底"**（找前驱钻左子树的右下角，找后继钻右子树的左下角）。

**三种线索树的能力差异**（老师结论 + 教材补充）

| 线索树 | 找前驱 | 找后继 | 说明 |
|---|---|---|---|
| 中序 | O(1) | O(1) | 最常用，两个方向都能直接走 |
| 先序 | 需栈/三叉链表 | O(1) | 有左孩子时**左孩子就是后继**；否则取 rchild |
| 后序 | O(1) | **不能**（需双亲指针） | 后继可能是双亲或双亲的右孩子，孩子指针**指不回去** |

老师用"后序线索求 E 的后继"说明：E 的后继是 B，但 E 有右孩子 H、右指针无法线索化，孩子指针又是**父→子单向**、回不到 B，故求不出。先序/中序可靠孩子指针往下绕到后继，所以只有后序不成立。

### 六、树的存储与树、森林、二叉树的转换（5.4.1 / 5.4.2）

**三种存储**

| 方法 | 结构 | 特点 |
|---|---|---|
| 双亲表示法 | 一组连续单元，每个结点存 `data + 双亲下标`（根记 -1 或 0） | 找双亲 O(1)，找孩子要遍历全表 |
| 孩子表示法 | 顺序表（每个结点）+ 孩子链表（存**下标**不存值，省空间） | 找孩子方便，找双亲难 |
| 孩子兄弟表示法 | 二叉链表：`firstchild + nextsibling` | **左孩子右兄弟**，可把树/森林转成二叉树 |

**转换口诀：左孩子右兄弟（六个字，本节最重要）**

三步口诀：
1. **第一个孩子放左边**——每个结点的**第一个**孩子作它的左孩子；
2. **其余孩子挂右边**——第二个孩子作第一个孩子的**右兄弟**，第三个作第二个的右兄弟，依次串成一条"兄弟链"；
3. **逐层递归**——对每个结点重复 1、2，直到所有结点处理完。

（教材补充：等价于"加线—抹线—旋转"，老师认为书上这套做法太生硬，只记左孩子右兄弟。）

**树 → 二叉树**例：A(B(E,F), C, D(G))
- A 的孩子 B、C、D → B 是 A 的左孩子，C 是 B 的右孩子，D 是 C 的右孩子；
- B 的孩子 E、F → E 是 B 的左孩子，F 是 E 的右孩子；
- D 的孩子 G → G 是 D 的左孩子。

**二叉树 → 树（反推）**：某结点**左指针**指向的一定是它的**第一个孩子**；沿**右链**走到的结点都是**兄弟**（同一个双亲）。例：G 在 D 的左边 → G 是 D 的孩子；F 在 E 的右边 → F 与 E 是兄弟。

**森林 → 二叉树**：先把每棵树各自转成二叉树（此时每棵的根都没有右子树），再把第 2 棵作为第 1 棵根的**右子树**、第 3 棵作为第 2 棵根的右子树……依次串起来。
**二叉树 → 森林**：根的**右链**上有几个结点（含根）就有几棵树；把根与右链断开，每段各自还原成一棵树。

**判树数**：二叉树根开始一直往右走，经过的结点数 = 森林中树的棵数。

**数字例（真题）**：16 个结点的**完全二叉树**由森林转换而来 → 结构：前 4 层满 15 个，第 5 层 1 个。根右链：1 → 3 → 7 → 15，共 **4 棵树**；第一棵结点最多，含 1、2、4、5、8、9、10、11、16 共 **9 个**。

### 七、树与森林的遍历（5.4.3）

树只有**先根**和**后根**（没有中序：孩子多于 2 个时"中间"无法定义）；森林有**先序**和**后序**（有的教材把后序叫"中序"，本质相同，真题多称后序）。

| 结构 | 遍历 | 规则 |
|---|---|---|
| 树 | 先根 | 访问根 → 依次先根遍历每棵子树 |
| 树 | 后根 | 依次后根遍历每棵子树 → 访问根 |
| 森林 | 先序 | 依次先序遍历每棵树 |
| 森林 | 后序(中序) | 依次后序遍历每棵树 |

**例**：树 A(B(E,F), C, D(G))
- 先根：A B E F C D G
- 后根：E F B C G D A
对应的二叉树（左孩子右兄弟）：先序 = A B E F C D G（**与先根相同**），中序 = E F B C G D A（**与后根相同**）。

**核心对应表（表 5.1，老师要求记）**

| 树/森林的遍历 | 对应二叉树的遍历 |
|---|---|
| 树的先根 | 先序 |
| 树的后根 | **中序** |
| 森林的先序 | 先序 |
| 森林的后序（中序） | **中序** |

一句话：**先对先、后对中**。忘了可以现推：把树转成二叉树，写先序/中序比一比。

### 八、哈夫曼树（5.5.1）

**结点的带权路径长度** = 根到该结点的**路径长度（边数）× 该结点权值**。
**树的带权路径长度 WPL** = **所有叶子结点**的带权路径长度之和（只算叶子！非叶结点不算）。
**哈夫曼树**：WPL 最小的二叉树（也叫最优二叉树）。

同一组权值 7、5、2、4，不同形态的 WPL：
- 全挂在第 2 层：7×2+5×2+2×2+4×2 = 36
- 完全二叉树形态：7×1+5×2+2×3+4×3 = **35**（最小 → 哈夫曼树）
规律：**权值大的往上放、小的往下放**。

**构造法（只记一句：每次选两个权值最小的合并）**
1. 把 n 个权值各看成只有根的树，构成森林 F；
2. 从 F 中选**两棵根权最小**的树，合并成一棵新树，新根权 = 两权之和；
3. 新树放回 F，重复 2，直到只剩一棵树。
约定（非必须，但选项通常这么画）：**小的放左边、大的放右边**。

**WPL 计算过程（例：7、5、2、4）**

| 轮次 | 选出的两个最小 | 新结点 |
|---|---|---|
| 1 | 2、4 | 6 |
| 2 | 5、6 | 11 |
| 3 | 7、11 | 18（根） |

成树：18(7, 11(5, 6(2,4)))，深度：7 在第 1 层，5 在第 2 层，2、4 在第 3 层。
WPL = 7×1 + 5×2 + **2×3 + 4×3** = 7 + 10 + 6 + 12 = **35**。

**WPL 速算公式：WPL = 所有非叶（分支）结点权值之和**
上例：6 + 11 + 18 = **35** ✓。
原理：叶子的权值被逐层加进父、祖父……累加次数正好等于其深度。老师强调这条"**很重要**"，书上没写，但选择题/大题小问会用到，有时比逐项乘更快。

**再例（权 10、12、16、21、30）**

| 轮次 | 选出 | 新结点 |
|---|---|---|
| 1 | 10、12 | 22 |
| 2 | 16、21 | 37 |
| 3 | 22、30 | 52 |
| 4 | 37、52 | 89 |

逐项算：16×2 + 21×2 + 30×2 + 10×3 + 12×3 = 32+42+60+30+36 = **200**；
同层合并算：(16+21+30)×2 + (10+12)×3 = 134 + 66 = **200**；
非叶和：22+37+52+89 = **200** ✓（三种算法互相验证）。

**性质**
1. 初始的 n 个权值最后**全部是叶子**；
2. **不存在度为 1 的结点**（每次都是两两合并）→ 是正则二叉树 → 总结点 = **2n-1**，非叶 = **n-1**；
3. **形态不唯一**（左右可交换、相同权值可换位），但 **WPL 唯一**且最小。

### 九、哈夫曼编码（5.5.2）

**前缀编码**：编码集合中**没有任何一个编码是另一个编码的前缀**。否则无法唯一译码：
- 反例：A=0，B=00 → 收到 00 可译成 AA / AB / BA，有歧义；
- 正例：A=0，B=10，C=11 → 00011… 只能唯一切分成 0|0|0|11。

**编码规则**：左分支记 **0**、右分支记 **1**，从根走到叶，路径上的 0/1 串即该字符编码。字符（权值=频次）都在**叶子**上 —— 这正好保证前缀性质（任一编码都不是另一编码的祖先）。

**例（权值 45、13、12、16、9、5，共 100 个字符）**

构造：

| 轮次 | 选出 | 新结点 |
|---|---|---|
| 1 | 5、9 | 14 |
| 2 | 12、13 | 25 |
| 3 | 14、16 | 30 |
| 4 | 25、30 | 55 |
| 5 | 45、55 | 100 |

编码（左 0 右 1）：

| 字符 | 权值(次数) | 编码 | 码长 | 贡献 = 权值×码长 |
|---|---|---|---|---|
| A | 45 | 0 | 1 | 45 |
| B | 13 | 101 | 3 | 39 |
| C | 12 | 100 | 3 | 36 |
| D | 16 | 111 | 3 | 48 |
| E | 9 | 1101 | 4 | 36 |
| F | 5 | 1100 | 4 | 20 |
| 合计 | 100 | — | — | **224** |

WPL = 45×1 + 13×3 + 12×3 + 16×3 + 9×4 + 5×4 = 45+39+36+48+36+20 = **224**。
校验（非叶和）：14+25+30+55+100 = **224** ✓。

**WPL 的物理意义（老师反复强调）**：WPL = **编码后二进制报文的总位数**。因为"码长"就是该字符占的位数，"权值"是它出现的次数，乘起来正是总位数。上例 100 个字符共占 224 位。

**与定长编码比较（压缩率）**
- 6 种字符，定长需 ⌈log₂6⌉ = **3 位**（2 位只能表示 4 种，不够）；
- 定长总长 = 3×100 = **300 位**；
- 哈夫曼 224 位，节省 300-224 = 76 位，压缩率 ≈ 76/300 ≈ **25%**。
（k 位二进制可表示 2^k 种状态。）

**编码长度与层次**：码长 = 叶结点深度；哈夫曼是**变长编码**，叶子在不同层；**定长编码的叶子全在同一层**。
- 定长编码 ⇔ 叶子同层；变长编码 ⇔ 叶子分布在不同层；
- 前缀关系 ⇔ 一个编码结点是另一个的**祖先**（A=1 是 B=10、C=11 的前缀）。

**加权平均长度**（易与 WPL 混淆，老师专门用 22 题区分）

$$\text{加权平均长度}=\frac{WPL}{\sum w_i}=\frac{\text{报文总位数}}{\text{字符总数}}$$

例（权 3、4、5、6、8、10，共 36 个字符）：构造 3+4=7，5+6=11，7+8=15，10+11=21，15+21=36。
WPL = (8+10)×2 + (3+4+5+6)×3 = 36 + 54 = **90**；加权平均长度 = 90/36 = **2.5 位/字符**，即平均每个字符占 2.5 个二进制位。

7. **由遍历序列构造二叉树是常规题，没有技巧，一步一步来**；只有含**中序**才能唯一确定（第 44 分P，选择题，也可能为大题服务）。

12. **哈夫曼树"每次选两个最小"**；**WPL = 非叶结点权值之和**要当结论记住（第 50 分P）。

| 线索找前驱/后继 | **tag=1 直接取，tag=0 钻到底**（前驱钻左子树最右，后继钻右子树最左） |

| 审题关键词 | 见"任意"→ 按最坏情况；见"至少"→ 求最小够用值 |

## 易错点与坑

1. **深度与高度混用**：深度从根往下数，高度从该结点往下数。D 的深度 2，但 D 的高度可能是 2 或 3，取决于子树。
2. **路径长度数"边"不数"点"**：A→B→C 长度 2，不是 3。
3. **WPL 只算叶子**：把非叶结点也算进去必错；但"WPL = 非叶权值和"这个**等式**可以用（两者数值相等，含义不同）。
4. **加权平均长度 ≠ WPL**：题目问"平均码长/加权平均长度"要除以权值和；只算 WPL 会与选项差十几倍（22 题就是靠这个识破）。
5. **字符总数不是字符种数**：45+13+12+16+9+5=100 才是"100 个字符"，算定长总长要乘 100。
6. **完全二叉树"度 1 结点至多 1 个"**，很多题靠这一点定 n1：n 偶 → n1=1；n 奇 → n1=0。
7. **顺序存储必须补空**，且空结点**占单元**；非完全二叉树按高度 5 存储需要 2^5-1 = 31 个单元，不是 10 个（28 题）。
8. **"任意一棵"要看最坏情况**：28 题问"至少需要多少单元"，答案是 31 而不是 16，因为要覆盖结点全歪在右侧的形态。
9. **0 起编号公式全变**：左 2i+1、右 2i+2、父 ⌊(i-1)/2⌋。用 1 起公式做 0 起题必错。
10. **先序+后序不能唯一确定**：n 个结点每层只有一个孩子时有 2^(n-1) 种（4 个结点 → 8 种）；考试若给四个选项问"中序不可能的是"，逐个用"先序+选项中的中序画树、验后序"最稳。
11. **线索化后仍有 2 个空指针**（中序首结点的 lchild、末结点的 rchild），不要说"没有空指针"。
12. **后序线索树求不出后序后继**：不要以为三种线索树都能 O(1) 找前后驱；后序找后继需要双亲指针。
13. **右兄弟链 ≠ 右孩子**：转换后二叉树中，右指针指向的是**兄弟**，不是右孩子。判断"是否叶子"只看**左指针**是否为空（9 题）。
14. **森林的树的棵数 = 根右链结点数**，不是"根 + 右子树"的结点数；16 个结点的完全二叉树是 4 棵树。
15. **哈夫曼树形态不唯一但码长固定**：自己画的树和选项长得不一样时，用**码长 + 前缀性**排除选项，不要重画。

## 本章例题

**例 1（5.1 课后 9 题）** 一棵度为 4 的树，度 4 的结点 20 个、度 3 的 10 个、度 2 的 1 个、度 1 的 10 个，求叶子数。
解：设叶子 x 个。
① 结点总数 n = 20+10+1+10+x = 41+x；
② 边数 = 20×4+10×3+1×2+10×1 = 80+30+2+10 = 122；
③ n = 边数+1 = 123 → 41+x = 123 → **x = 82**。（老师口播先说 41，随后更正为 82，选 B。）

**例 2、例 3（5.1 课后 7、8 题）**
(1) 度为 3 的树，度 3 的结点 2 个、度 2 的 1 个、度 1 的 T 个、叶子 6 个，求结点总数。
解：n = 2+1+T+6 = 9+T；边 = 6+2+T = 8+T；由 n = 边+1 得 9+T = 9+T，**恒成立** → T 任意 → 结点总数是 ≥9 的任意整数，选 **D**。
(2) m 叉树中有 n1 个度 1、n2 个度 2、…、nm 个度 m 的结点，求叶子数 n0。
解：n = n0+n1+…+nm；边 = n1+2n2+…+m·nm；n = 边+1 → n0 = **1 + Σ(i-1)·ni（i=2..m）**，选 **D**。

**例 4（5.2 课后 12 / 25 题）** 完全二叉树第 6 层有 8 个叶结点，求结点总数的最小值与最大值。
最少：层数尽量少 → 共 6 层，这 8 个叶子在**最左**，前 5 层必须满。
前 5 层 = 2⁵-1 = 31，加 8 → **39（A）**。
最多：让第 6 层当倒数第二层 → 共 7 层；8 个叶子在**最右**，故第 6 层左侧 32-8 = 24 个是非叶，每个再带 2 个孩子 → 第 7 层 48 个。
前 6 层满 = 2⁶-1 = 63，63+48 = **111（C）**。

**例 5（5.2 课后 21 题）** 完全二叉树（根为 1）中 17 与 19 的最近公共祖先。
解：不断取 ⌊i/2⌋：
17 → 8 → 4 → 2 → 1；19 → 9 → 4 → 2 → 1。
第一个公共结点是 **4**。

**例 6（5.2.2 课后 28 题）** 高 5、10 个结点的**任意**二叉树用顺序存储，至少需要多少单元？
解：审"任意" → 按最坏情况（结点全歪向右，第 5 层最右）。
补成完全二叉树后必须 5 层全满 → 2⁵-1 = **31**（A）。
（错解 B=16：只考虑了"10 个结点尽量靠左、前 4 层满 + 第 5 层 1 个"的最好情况。）

**例 7（5.2.2 课后 30 题）** 顺序存储中用 1 表示空结点，哪个不能表示一棵二叉树？
解：把 1 全部删掉后检查"上层无结点、下层有结点"的情形。D 选项删空后 19 的上方没有双亲 → 不合法，选 **D**。

**例 8（5.3.2 课后 40 / 15 / 30 / 31 题）** 遍历序列相同或相反。
- 先序 = 中序 → 若有左子树，先序"根左" vs 中序"左根"必然不同 → **每个结点无左孩子**（只有右孩子）。
- 中序 = 后序 → 同理 **每个结点无右孩子**（只有左孩子）。
- 先序与后序**相反** → 左右子树不可能同时存在（否则都是"左右"顺序），只能每层一个结点 → **高度 = 结点数**。
- 先序与中序**相反** → 只能每个结点只有**左**孩子（无右孩子）。
- **叶子相对次序**：三种序列中完全一致（6 题），因为都是"先左后右"，只是根的位置在变。

**例 9（5.3.3 课后 9 题）** 先序 ABC、后序 CBA，能画出几棵二叉树？
解：先序与后序相反 → 每层一个结点。B、C 各有左右两种放法 → 2² = **4 种**。

**例 10（5.3.3 课后 34 题）** 先序与后序相反、共 4 个结点，选项中哪个中序**不可能**。
解：2、3、4 各有左右两种 → 2³ = **8 种**。考场做法：拿"题干先序 + 选项中的中序"画树、验后序；画全 8 种太费时间，老师不推荐。

**例 11（5.3.4 课后 38 题，2015 真题）** 先序序列为 ABCD 的二叉树有多少棵？
解法一（卡特兰）：先序↔入栈、中序↔出栈，ABCD 固定入栈的出栈序列数 = C(8,4)/5 = 70/5 = **14**。
解法二（递推）：设 F(n) 为 n 个结点、先序固定的二叉树个数，F(0)=1，F(1)=1，F(2)=2。
F(n) = Σ_{k=0}^{n-1} F(k)·F(n-1-k)：
F(3) = F0F2+F1F1+F2F0 = 2+1+2 = 5；
F(4) = F0F3+F1F2+F2F1+F3F0 = 5+2+2+5 = **14**；
（延伸）F(5) = 14+5+4+5+14 = **42**。

**例 12（5.3.5 课后 33 题）** 后序线索二叉树，后序为 DBCA，问 D 的左右指针。
解：D 是后序首结点 → 无前驱，lchild 为空、ltag=1；D 的后继是 B → rchild 指向 **B**、rtag=1。选 **D**。
（顺带核对：C 是叶子，左线索→B、右线索→A。）

**例 13（5.3.5 课后 36 题）** 后序线索树中 X 是叶结点，有左兄弟 Y，X 的右线索指向谁？
解：X 为叶子且是其双亲的**最右**孩子 → 后序中 X 之后立即访问其**双亲**。故右线索指向 X 的**双亲**（A）。

**例 14（5.3.5 课后 27 题）** 线索化不能解决的问题是？
解：选"**后序线索二叉树求后序后继**"。例：E 的后继是 B，但 E 有右孩子 H 无法线索化，且孩子指针不能回指双亲，故求不出；而后序**前驱**、先序/中序的后继都能靠孩子指针绕到。

**例 15（5.4.2 课后 9 题）** 孩子兄弟链表中有 6 个空左指针、7 个空右指针、5 个结点左右皆空，求树的叶子数。
解：树中叶子 ⇔ 无孩子 ⇔ 转换后**左指针为空**，故叶子数 = 空左指针数 = **6**。

**例 16（5.4.2 课后 16 题）** 树有 2011 个结点、116 个叶结点，转为二叉树后，无右孩子的结点有多少个？
解：非叶结点 = 2011-116 = 1895，每个非叶结点对应"一组孩子"，每组**最右**那个孩子在二叉树中无右兄弟 → 1895 个；再加最右那棵树的根（无兄弟）1 个 → **1896**。
（通用法：n 个非终端结点 ⇒ n 组孩子 ⇒ n 个右指针为空，再加根，共 n+1。）
特殊值法：把树画成"1895 个结点单链 + 末端 116 个孩子"，同样得 1895+1。

**例 17（5.5.2 课后 18 题）** 字符 A~F 出现次数 6、3、8、2、10、4，求哈夫曼编码。
解：2+3=5 → 4+5=9 → 6+8=14 → 9+10=19 → 14+19=33。
编码（小左大右）：A(6)=00，C(8)=01，E(10)=11，F(4)=100，D(2)=1010，B(3)=1011 → 对应 **A** 选项。
左右画反时码长不变（A、C、E 为 2，F 为 3，B、D 为 4），可先按长度 2,4,2,4,2,3 排除，再查前缀（C 选项 10 是 1011 的前缀，错）。

**例 18（5.5.2 课后 22 题）** 权值 3、4、5、6、8、10，求加权平均长度。
解：WPL = (8+10)×2+(3+4+5+6)×3 = 36+54 = **90**；字符总数 = 36；
加权平均长度 = 90/36 = **2.5**。
（坑：只算 WPL=90 会与选项差很远，说明问的不是 WPL。）

**例 19（5.5.2 课后 4 题）** 已有编码 1 和 01，哈夫曼编码长度不超过 4，最多还能编多少个字符？
解：1 占右分支、01 占"左-右"，均为**叶子**不能再长。可扩展空间只剩根的左侧 00，向下每层分两叉，最长到第 5 层（码长 4）→ 还能容纳 2×2 = **4** 个字符。
