## 知识点详解

### 一、2.1.1 线性表的定义和基本操作

**定义**：线性表是由 **n 个相同数据类型的元素**组成的**有限序列**，n ≥ 0。

**前驱与后继**：序列 `A B C D` 中，C 的**直接前驱**是 B，**直接后继**是 D，即"前一个/后一个元素"，无更多含义。

**基本操作**（全部定义在**逻辑结构**上）：

| 操作 | 含义 | `ABCDEF` 上的例子 |
|---|---|---|
| 求表长 | 元素个数 | 6 |
| 按位查找 GetElem(i) | 取第 i 个元素 | i=4 → `D` |
| 按值查找 LocateElem(e) | 找值为 e 的元素 | 找 `E` → 第 5 位 |
| 插入 | 在第 i 位放入新元素 | B、C 之间插 `H` |
| 删除 | 删掉第 i 个元素 | 删 `C` |
| 判空 | 表是否为空 | n=0 为空 |

**关键分层**：线性表是**逻辑结构**，顺序表/链表是两种**物理结构**。同一组运算在两种结构下代码完全不同，但"要做什么"一样；这套路后面栈、队列、树、图全部复用。

**暴力解**：指"多开空间"或"多扫几遍"的通用写法。老师强调：**不为最优解花时间**，最优解多为"做过原题才会"的技巧，换题即废；暴力解能拿 11～12 分（满分 15），性价比最高。

### 二、2.2.1 顺序表的定义与实现

**定义**：用**地址连续**的存储单元依次存放元素，使**逻辑上相邻的元素物理位置也相邻**。提到"顺序表"就已默认顺序存储，它是物理结构。

**地址公式（必背）**：

```
LOC(a_i) = LOC(a_1) + (i - 1) × L        // 位序 i 从 1 开始
A[i] 的地址 = A + i × L                  // 数组下标 i 从 0 开始
```

`LOC(a_1)` 是首地址（数组名即首地址），`L` 是每个元素占的字节数（int 为 4）。

**数字例子**：`int A[100]`，求 `A[87]` 地址。按字节编址，一个 int 占 4 个地址，
`A[87] 地址 = A + 87 × 4 = A + 348`。

**随机存取（随机访问）**：任意元素地址都能由首地址一步算出，故访问任一元素都是 O(1)。标准表述——**访问任何一个元素的时间与它的位置无关**。这是顺序表**最大的特点**（组成原理、操作系统中也用这个词）。

**静态分配**：

```c
#define MaxSize 50
typedef struct {
    ElemType data[MaxSize];   // 静态数组，容量固定为 50
    int length;               // 当前实际存放的元素个数
} SqList;
```

`MaxSize` = 最多能放几个（容量）；`length` = 当前放了几个（0 ≤ length ≤ MaxSize）。例：容量 50、实存 4 个 → `MaxSize=50, length=4`。

**动态分配**：

```c
#define InitSize 100
typedef struct {
    ElemType *data;    // 指向动态数组的指针，不是数组本身
    int MaxSize;       // 当前容量
    int length;        // 当前长度
} SeqList;

L.data = (int *)malloc(sizeof(int) * InitSize);   // C
// L.data = new int[InitSize];                     // C++
```

**malloc 语法拆解**：`(目标类型 *)malloc(单个元素字节数 × 元素个数)`。
① 返回 `void *`，必须转成元素指针类型；② 拿到的是**首地址**，故前面加 `int *`；③ **数组大小是变量时绝不能写 `int a[n];`**。

**动态扩容原理**：原空间 100 个放满 → 另开一块 200 个 → `data` 指针改指向新空间 → 把原 100 个**逐个复制**过去。指针是变量，指向可改，这就是"动态"。

**优缺点**：

| | 内容 |
|---|---|
| 优点 | ① 可**随机访问**，按位查找 O(1)；② 存储密度高（无额外指针） |
| 缺点 | ① **插入删除效率低**，要成片移动元素；② 必须分配**连续**空间；③ 扩容要复制 |

例：`ABCDE` 删 B 须把 C、D、E 全前移；A、B 之间插 F 须把 B、C、D、E 全后移。

### 三、2.3.1 指针与结构体语法（链表的语言基础）

**指针**：本质就是**地址**。内存由一个个存储单元构成，每单元有编号（地址），如同楼里每个房间有房间号。

```c
int a = 35;
int *p = &a;       // & 取地址，p 中存放 a 的地址，称 p 为指针变量
printf("%d", p);   // 打印地址（如 4）
printf("%d", *p);  // 打印 35，* 叫解引用：取出 p 所指对象的值
```

- `int *p` 与 `int* p` 都合法；但**一行定义两个指针时 `*` 必须紧跟变量名**：`int *p, *q;`（写成 `int* p, q;` 则 q 只是 int）；
- **指针是变量，指向可以变**：先 `p=&a`，再 `p=&b`，p 就改指 b。链表全程都在用这一点。

**结构体**：把多个不同类型数据打包成一个整体（`int num; char name[20]; double score;`），末尾分号不能丢。

**两种访问运算符（必须分清）**：

| 运算符 | 左边是 | 写法 | 含义 |
|---|---|---|---|
| `.` 点运算符 | **结构体变量** | `stu.num = 2601;` | 直接访问成员 |
| `->` 箭头运算符 | **结构体指针** | `p->num = 2601;` | 通过指针访问成员 |

`p->data` 等价于 `(*p).data`。老师强调：**指针和它指向的东西是两块独立内存**，只是指针里存的地址等于对方地址，二者靠地址建立联系。

### 四、2.3.2 单链表的结点定义（必须会默写）

```c
typedef struct LNode {          // 单链表结点类型
    ElemType data;              // 数据域
    struct LNode *next;         // 指针域，指向下一个结点
} LNode, *LinkList;
```

**要能读出四件事**：
1. `typedef` 起别名，把 `struct LNode` 简写为 `LNode`（否则每次都得写 `struct LNode a;`）；
2. 同时把 `struct LNode *` 起名为 `LinkList`；
3. 因此 **`LinkList` ≡ `LNode *` ≡ `struct LNode *`**，三者同一类型；
4. **`LinkList` 表面看不到星号，本质就是指针**，看到 `LinkList L` 要知道"L 是指向结点的指针"。

**`p->next` 的双重含义**：设 `A(200) → B(300) → C(400) → D(NULL)`，A 的指针域存 200。
- 含义一：**当前结点 p 的指针域**（存放地址的成员）；
- 含义二：**下一个结点整体**（"结点的地址"就能代表该结点，而 `p->next` 里放的正是它的地址）。

所以 `p->next` 既可当"箭头"用，也可当"结点"用，这正是链表代码能写得极短的原因。

**两句核心代码的区别**：

| 语句 | 效果 | 链表结构 |
|---|---|---|
| `p = p->next;` | p 从 A 走到 B（再走 C、D） | **不变**，只改当前指向 |
| `p->next = p->next->next;` | 把 300 写入 A 的指针域 | **变了**，B 被摘掉，A 直连 C |

第一句是"走位"（遍历天天用），第二句是"改结构"（删除用）。

### 五、2.3.3 头指针与头结点

| 概念 | 是什么 | 是否必需 |
|---|---|---|
| **头指针** | 指向链表**最前面那个结点**的指针，是链表的"身份证" | **必须有** |
| **头结点** | 第一个**数据结点**之前额外加的**不存数据**的结点 | **可有可无** |

不带头结点：头指针 → A；带头结点：头指针 → 头结点 → A。

**为什么要有头结点**——比较"删除 A"与"删除 B/C/D"：
- 删 B：让 A 跳过 B 指向 C，**头指针不动**；
- 删 C：让 B 跳过 C 指向 D，**头指针不动**；
- 删 D：让 C 的 next 置空，**头指针不动**；
- 删 A：A 前面没有结点，无前驱可跳过它；且删完**头指针必须改指 B**。动作与上面三个**不统一**。

加上头结点后，删 A 也变成"前驱（头结点）跳过 A 指向 B"，**四个动作统一**，**头指针永不用改**。

**三个好处**：① 首元与其余结点代码一致；② 头指针稳定；③ 空表非空表统一——带头结点时空表 `L->next==NULL`，头指针仍非空。

**注意**：求表长时**头结点不计入**。`h→A→B→C→D` 长度是 4。

**真题现状**：基本都带头结点——选择 32、34、36 题与大题 17、18、20 题都明说，19 题图里画了头结点。

### 六、2.3.4 单链表的插入与删除（指针步骤，可照抄）

#### 6.1 在 p 之后插入 s（后插）

```c
s->next = p->next;   // ① 让 s 接上 p 原来的后继
p->next = s;         // ② 再让 p 指向 s
```

**顺序绝对不能颠倒**。若先执行 ②，`p->next` 已被改成 s，B 的地址彻底丢失，`s->next` 再也填不出正确值——**断链**。②**修改** `p->next`，①**使用** `p->next`，故①必须先完成。

**先暂存则无顺序要求**：`q = p->next; s->next = q; p->next = s;`

**在 Q 与 P 之间插入 S（Q 是 P 的前驱，三个地址全已知）**：

```c
S->next = P;
Q->next = S;
```

三地址都已知，**无先后要求**，写反也对。

#### 6.2 删除 p 的后继

```c
q = p->next;         // ① 先暂存要删的结点
p->next = q->next;   // ② 让 p 跳过 q
free(q);             // ③ 释放 q 占的内存
```

三句缺一不可：不要①，执行②后 q 地址丢失、无法 free，内存泄漏；不要③，q 已下链但仍占内存。
错误写法 `p->next = p->next->next; free(p->next);`——此时 `p->next` 已是 C，**free 掉的是 C**。

#### 6.3 代码段分析题（43 页 36 题）

带头结点链表、头指针 h、P 指向**非首非尾**结点，执行：

```c
q = P->next;
P->next = q->next;
q->next = h->next;
h->next = q;
```

原链 `h→A→B→C→D`，P 指 B：① q 指 C；② B 改指 D，C 被摘出；③ C→A；④ h→C。结果 `h→C→A→B→D`，即**把 q 所指结点移到头结点之后**。

### 七、2.3.5 双链表

每结点**两个指针域**：`prior` 指前驱，`next` 指后继；首结点 prior 为 NULL，尾结点 next 为 NULL。

```c
typedef struct DNode {
    ElemType data;
    struct DNode *prior, *next;   // 一行两个指针，* 必须跟变量名
} DNode, *DLinkList;
```

**在 p 之后插入 s（四步）**：

```c
s->next = p->next;        // ① s 的后继 = p 原来的后继
p->next->prior = s;       // ② 原后继的前驱 = s
s->prior = p;             // ③ s 的前驱 = p
p->next = s;              // ④ p 的后继 = s
```

**顺序要求：①② 必须在 ④ 之前**。①② 都要靠 `p->next` 定位原后继 C，而 ④ 把 `p->next` 改成 s，之后找不到 C。③ 位置随意。**先 `q=p->next;` 暂存则四句任意顺序。**

**在 p 之前插入 s（前插）**：

```c
s->prior = p->prior;        // ① s 的前驱 = p 原来的前驱
p->prior->next = s;         // ② 原前驱的后继 = s
s->next = p;                // ③ s 的后继 = p
p->prior = s;               // ④ p 的前驱 = s
```

同理，①② 必须在 ④ 之前（④ 改 `p->prior`）。

**删除 p 的后继 q**：

```c
q = p->next;                // ① 暂存
p->next = q->next;          // ② 后继指针跳过 q
q->next->prior = p;         // ③ 后继的前驱回指 p
free(q);                    // ④ 释放
```

②③ **无顺序要求**（互不依赖）。

**删除 p 本身（课后 16 题）**：

```c
p->prior->next = p->next;   // ① 前驱的后继 = p 的后继
p->next->prior = p->prior;  // ② 后继的前驱 = p 的前驱
free(p);                    // ③
```

①② 无顺序要求；选择题选项常省略 `free`，按选项判断。

### 八、2.3.6 循环单链表

**定义**：尾结点的 `next` 不再为 NULL，而是**指回头结点**（不带头结点则指回首元），整条链成环，**不存在 next 为空的结点**。

**判空**：

| 情况 | 普通单链表 | 循环单链表 |
|---|---|---|
| 带头结点空表 | `L->next == NULL` | **`L->next == L`** |
| 不带头结点空表 | `L == NULL` | `L == NULL` |

**只设尾指针 R 的技巧（高频）**：尾结点 = `R`；头结点 = `R->next`；首元 = `R->next->next`。因此**表头插入与表尾插入都是 O(1)**。

```c
s->next = R->next;   // ① 新结点接回头结点（必须先做）
R->next = s;         // ② 原尾结点接上新结点
R = s;               // ③ 更新尾指针
```

① 必须在 ② 之前，理由同单链表插入（② 覆盖 `R->next`）。

表头插入 s（成为首元）：

```c
s->next = R->next->next;   // ① s 接上原首元
R->next->next = s;         // ② 头结点指向 s
```

**只设头指针时**：表尾插入必须从头遍历到尾，**O(n)**（要改尾结点的 next 就得先找到尾结点）。

**删除首元（只设尾指针 R）**：`q = R->next->next; R->next->next = q->next; free(q);` → O(1)。

### 九、2.3.7 循环双链表

**定义**：尾结点 next 指向头结点，**头结点 prior 指向尾结点**，前后都成环。

**判空（带头结点）**：只有一个头结点，next 与 prior 都指向自己：

```c
L->next == L && L->prior == L
```

**删除 p（两句通用）**：

```c
p->prior->next = p->next;
p->next->prior = p->prior;
free(p);
```

**这两句对首结点、尾结点、乃至"表中只有一个结点"都成立，无需任何特判**——环状结构保证 `p->prior`、`p->next` 永远存在。验证"只有 A"：两者都是头结点 L，执行后 `L->next = L`、`L->prior = L`，正好回到空表。

**在 p 之后插入 s**：四步与普通双链表完全一样，同样不需要特判。

### 十、2.3.8 静态链表

**定义**：用**数组**模拟链式存储，`next` 存**数组下标**而非地址，用下标充当"指针"。

```c
#define MaxSize 10
typedef struct {
    ElemType data;
    int next;        // 下一个元素在数组中的下标，不是地址
} SLinkList[MaxSize];
```

**对照例子（必须能把图和表对上）**：

| 下标 | data | next | 含义 |
|---|---|---|---|
| 2 | A | 1 | A 后面是下标 1（B） |
| 1 | B | 6 | B 后面是下标 6（C） |
| 6 | C | 3 | C 后面是下标 3（D） |
| 3 | D | 0（或 -1） | 到头，无后继 |

逻辑顺序 `A→B→C→D`，但四个元素下标是 2、1、6、3，**物理上并不相邻**——外观是数组，本质仍是链表。（结束标志 0 或 -1 以题目为准。）

**插入删除照抄（与单链表同构，地址换下标）**：设 A 的下标为 i、新结点下标为 j。

```c
a[j].next = a[i].next;   // ① 新结点接上 A 原来的后继
a[i].next = j;           // ② A 指向新结点（顺序同单链表，不能颠倒）

a[i].next = a[j].next;   // 删除 A 的后继 j：直接跳过
```

**三个特点（选择就考这些）**：① 需**预先分配一整块连续空间**（同顺序表）；② **插删不移动元素**，只改 next 下标（同链表）；③ **不支持随机访问**——访问第 3 个只能从表头顺 next 一个个走，时间与 i 有关。

### 十一、2.3.9 顺序表 vs 链表（专设对比）

| 维度 | 顺序表 | 链表 |
|---|---|---|
| 存储结构 | 顺序存储，逻辑相邻 ⟹ 物理相邻 | 链式存储，逻辑相邻 ≠ 物理相邻，靠指针维护 |
| **存储密度** | **= 1**（只存数据） | **< 1**（每结点多 1～2 个指针域）。32 位机 int+指针：4/8 = 50% |
| **随机访问** | **支持**，按位查找 O(1) | **不支持**，只能顺序存取，按位查找 O(n) |
| 顺序存取 | 也支持（从前往后遍历） | 支持（唯一方式） |
| **按值查找** | O(n) | O(n) |
| **插入 / 删除** | 平均移动约 **n/2** 个元素，O(n) | **改指针 O(1)**，但**定位前驱 O(n)** |
| **空间分配** | 静态：容量固定易溢出；动态：可扩容但要整体复制 | 随时 malloc，**不需连续空间**，动态性好 |
| 空间利用率 | 高（无指针开销），但可能预留浪费 | 低（指针占空间），但不预留 |
| 适用 | 表长可预估、查多改少、需随机访问 | 表长不定、频繁插删 |

**最容易漏的一句**：链表"插入删除 O(1)"**只在已定位到前驱时成立**。删第 i 个仍要先走 i-1 步，**总时间 O(n)**。

**怎么选**：长度无法预估选链表，长度稳定选顺序表；常用按位访问选顺序表，常用插删选链表（别忘定位开销）。

### 十二、2.3.10 选取最合适的链表

题目："删除第一个、删除最后一个、在第一个之前插入、在最后一个之后插入"四种运算都尽量快。

| 选项 | 结构 | 删首 | 删尾 | 首前插 | 尾后插 |
|---|---|---|---|---|---|
| A | 只有**尾指针**的**循环单**链表 | O(1) | **O(n)** | O(1) | O(1) |
| B | 只有**尾指针**的**非循环双**链表 | **O(n)** | O(1) | **O(n)** | O(1) |
| C | 只有**头指针**的**循环双**链表 | **O(1)** | **O(1)** | **O(1)** | **O(1)** |
| D | **头尾指针都有**的循环单链表 | O(1) | **O(n)** | O(1) | O(1) |

**答案 C，四项全 O(1)**。循环双链表 + 头指针时，`L->prior` 一步到尾、`L->next` 一步到首元，故"删尾""尾后插"不用遍历；循环单链表**删尾必须找尾的前驱**，只能绕一圈；非循环双链表只有尾指针时，删首 / 首前插都要从尾往前 O(n) 找。

**判定法**：问"要改的指针能否 O(1) 拿到"——删 x 要拿 **x 的前驱**，在 x 后插要拿 **x**。

### 十三、算法题模板（一）：顺序表

> C 语言，`SqList` 见 2.2.1，`ElemType` 按题目换成 `int`。

**13.1 插入（第 i 个位置，1 ≤ i ≤ length+1）**

```c
bool ListInsert(SqList *L, int i, ElemType e) {
    if (i < 1 || i > L->length + 1) return false;   // 位序非法
    if (L->length >= MaxSize) return false;         // 表满
    for (int j = L->length; j >= i; j--)            // 从尾往前逐个后移
        L->data[j] = L->data[j - 1];
    L->data[i - 1] = e;                             // 位序 i 对应下标 i-1
    L->length++;
    return true;
}
```
**时间 O(n)**（平均移动 n/2 个）；**空间 O(1)**。

**13.2 删除第 i 个**

```c
bool ListDelete(SqList *L, int i, ElemType *e) {
    if (i < 1 || i > L->length) return false;
    *e = L->data[i - 1];                            // 先保存被删元素
    for (int j = i; j < L->length; j++)             // 从 i 起逐个前移
        L->data[j - 1] = L->data[j];
    L->length--;
    return true;
}
```
**时间 O(n)**（平均移动 (n-1)/2 个）；**空间 O(1)**。

**13.3 就地逆置（课后第 2 题）**

```c
void Reverse(SqList *L) {
    ElemType t;
    for (int i = 0, j = L->length - 1; i < j; i++, j--) {  // 首尾指针向中间夹
        t = L->data[i]; L->data[i] = L->data[j]; L->data[j] = t;
    }
}
```
**时间 O(n)**；**空间 O(1)**。这是"双指针交换"原型，循环左移最优解就靠它。

**13.4 合并两个有序顺序表（归并）**

```c
void Merge(SqList A, SqList B, SqList *C) {
    int i = 0, j = 0, k = 0;
    while (i < A.length && j < B.length) {
        if (A.data[i] <= B.data[j]) C->data[k++] = A.data[i++];  // 取小者
        else                        C->data[k++] = B.data[j++];
    }
    while (i < A.length) C->data[k++] = A.data[i++];   // 扫尾
    while (j < B.length) C->data[k++] = B.data[j++];
    C->length = k;
}
```
**时间 O(m+n)**；**空间 O(1)**（不计结果表）。

**13.5 循环左移 p 位（2010 真题，课后第 10 题）**

暴力解：

```c
void LeftMove(int R[], int n, int p) {
    int *temp = (int *)malloc(sizeof(int) * p);   // 大小是变量，必须 malloc
    for (int i = 0; i < p; i++) temp[i] = R[i];          // ① 前 p 个暂存
    for (int i = 0; i < n - p; i++) R[i] = R[p + i];     // ② 后 n-p 个前移
    for (int i = 0; i < p; i++) R[n - p + i] = temp[i];  // ③ 暂存的接回末尾
    free(temp);
}
```
**时间 O(n+p)**（p<n，即 O(n)）；**空间 O(p)**。

最优解（三次反转）：

```c
void Reverse(int R[], int from, int to) {
    int i, temp;
    for (i = 0; i < (to - from + 1) / 2; i++) {
        temp = R[from + i]; R[from + i] = R[to - i]; R[to - i] = temp;
    }
}
void Converse(int R[], int n, int p) {
    Reverse(R, 0, p - 1);      // ① 反转前 p 个
    Reverse(R, p, n - 1);      // ② 反转后 n-p 个
    Reverse(R, 0, n - 1);      // ③ 整体反转
}
```
**时间 O(n)**（2n 忽略系数）；**空间 O(1)**。

**13.6 两个等长升序序列的中位数（教材补充，2011 真题）**

```c
int M_Search(int A[], int B[], int n) {
    int s1 = 0, d1 = n - 1, m1, s2 = 0, d2 = n - 1, m2;
    while (s1 != d1 || s2 != d2) {
        m1 = (s1 + d1) / 2;  m2 = (s2 + d2) / 2;
        if (A[m1] == B[m2]) return A[m1];          // 相等即中位数
        if (A[m1] < B[m2]) {                       // 舍 A 小半、B 大半
            if ((s1 + d1) % 2 == 0) { s1 = m1; d2 = m2; }   // 奇数个，保留中点
            else { s1 = m1 + 1; d2 = m2; }                  // 偶数个，不保留
        } else {
            if ((s1 + d1) % 2 == 0) { d1 = m1; s2 = m2; }
            else { d1 = m1 - 1; s2 = m2; }
        }
    }
    return A[s1] < B[s2] ? A[s1] : B[s2];
}
```
**时间 O(log n)**；**空间 O(1)**。要点：每次严格砍一半，且**两边砍掉的数量必须相同**，否则中位数位置漂移。

### 十四、算法题模板（二）：链表

> 默认**带头结点**，`LNode`/`LinkList` 见 2.3.2。

**14.1 求表长**

```c
int Length(LinkList L) {
    int len = 0;
    LNode *p = L;              // p 从头结点出发
    while (p->next != NULL) {  // 后面还有点就走
        p = p->next; len++;    // 走一步，len 即当前位序
    }
    return len;                // 头结点未计入
}
```
**时间 O(n)**；**空间 O(1)**。空表返回 0。

**14.2 按位插入（第 i 个，先找第 i-1 个）**

```c
bool ListInsert(LinkList L, int i, ElemType e) {
    if (i < 1) return false;
    LNode *p = L; int j = 0;
    while (p != NULL && j < i - 1) { p = p->next; j++; }  // 定位第 i-1 个
    if (p == NULL) return false;
    LNode *s = (LNode *)malloc(sizeof(LNode));
    s->data = e;
    s->next = p->next;                                    // 先连后
    p->next = s;                                          // 再断前
    return true;
}
```
**时间 O(n)**（定位 O(n) + 插入 O(1)）；**空间 O(1)**。

**14.3 按位删除**

```c
bool ListDelete(LinkList L, int i, ElemType *e) {
    if (i < 1) return false;
    LNode *p = L; int j = 0;
    while (p != NULL && j < i - 1) { p = p->next; j++; }
    if (p == NULL || p->next == NULL) return false;   // 第 i 个不存在
    LNode *q = p->next;
    *e = q->data;
    p->next = q->next;
    free(q);
    return true;
}
```
**时间 O(n)**；**空间 O(1)**。

**14.4 尾插法（顺序与输入一致）**

```c
LinkList TailInsert(LinkList L) {
    L = (LNode *)malloc(sizeof(LNode));   // 建头结点
    L->next = NULL;
    LNode *s, *r = L;                     // r 为尾指针，始终指向最后一个结点
    int x; scanf("%d", &x);
    while (x != 9999) {
        s = (LNode *)malloc(sizeof(LNode));
        s->data = x;
        r->next = s;                      // 挂到尾部
        r = s;                            // 尾指针后移
        scanf("%d", &x);
    }
    r->next = NULL;                       // 尾结点 next 置空
    return L;
}
```
输入 `10 20 30` → `10→20→30`，**顺序一致**。**时间 O(n)**；**空间 O(n)**。

**14.5 头插法（顺序与输入相反）**

```c
LinkList HeadInsert(LinkList L) {
    L = (LNode *)malloc(sizeof(LNode));
    L->next = NULL;
    LNode *s; int x; scanf("%d", &x);
    while (x != 9999) {
        s = (LNode *)malloc(sizeof(LNode));
        s->data = x;
        s->next = L->next;   // 新结点接上当前第一个
        L->next = s;         // 头结点指向新结点，s 成为首元
        scanf("%d", &x);
    }
    return L;
}
```
输入 `10 20 30` → `30→20→10`，**顺序相反**。**时间 O(n)**；**空间 O(n)**。
关键认知：头插法本质就是"在头结点之后插入"，循环体就是那两行。

**14.6 就地逆置（43 页第 3 题，必背）**

思路：把结点**逐个摘下，用头插法重新插回头结点之后**。

```c
LinkList Reverse(LinkList L) {
    LNode *p = L->next, *r;   // p 是当前要处理的结点
    L->next = NULL;           // ① 头结点断开，新表初始为空
    while (p != NULL) {
        r = p->next;          // ② 暂存 p 的后继，防止断链后丢失
        p->next = L->next;    // ③ 头插第一步：p 接上新表当前首元
        L->next = p;          // ④ 头插第二步：头结点指向 p
        p = r;                // ⑤ p 走到下一个待处理结点
    }
    return L;
}
```
**时间 O(n)**；**空间 O(1)**。

三个变量要讲清：`p` 是当前处理结点；`r` **暂存 p 的后继**——③④ 会改 `p->next`，不先存就找不到下一个；`L->next = NULL` **不能漏**——原首元反转后必成尾结点。
跟踪 `1→2→3→4`：`L→1` → `L→2→1` → `L→4→3→2→1`。

**14.7 找倒数第 k 个（教材补充，双指针）**

```c
int Search_k(LinkList L, int k) {
    LNode *p = L->next, *q = L->next;   // p 先行，q 后行，间距保持 k
    int cnt = 0;
    while (p != NULL) {
        if (cnt < k) cnt++;             // 前 k 步只让 p 走
        else q = q->next;               // 之后 p、q 同步
        p = p->next;
    }
    if (cnt < k) return 0;              // 表长不足 k
    printf("%d", q->data);
    return 1;
}
```
**时间 O(n)**（只扫一遍）；**空间 O(1)**。p 到尾时二者相距 k，q 即倒数第 k 个。

**14.8 判环并找环入口（教材补充，快慢指针）**

```c
LNode *FindLoop(LNode *head) {
    LNode *slow = head->next, *fast = head->next;
    while (fast != NULL && fast->next != NULL) {
        slow = slow->next;          // 慢指针 1 步
        fast = fast->next->next;    // 快指针 2 步
        if (slow == fast) break;    // 相遇，有环
    }
    if (fast == NULL || fast->next == NULL) return NULL;  // 无环
    LNode *p1 = head->next, *p2 = slow;   // 一个从头、一个从相遇点，同速前进
    while (p1 != p2) { p1 = p1->next; p2 = p2->next; }
    return p1;                      // 相遇处即环入口
}
```
**时间 O(n)**；**空间 O(1)**。依据：设头到入口长 a、入口到相遇点长 b、环长 r，则 `a = r - b`，故同速必在入口相遇。

**14.9 两链表的第一个公共结点（教材补充）**

```c
LNode *Search_Common(LinkList L1, LinkList L2) {
    int len1 = Length(L1), len2 = Length(L2);
    LNode *p = L1->next, *q = L2->next;
    int d = len1 - len2;
    if (d > 0) while (d--) p = p->next;   // 长的先走 |d| 步
    else       while (d++) q = q->next;
    while (p != NULL && p != q) {         // 同步走，比地址不比值
        p = p->next; q = q->next;
    }
    return p;                             // NULL 表示无公共结点
}
```
**时间 O(m+n)**；**空间 O(1)**。前提：两链"Y 形"共享尾部。

**14.10 双指针技巧一览**

| 场景 | 指针设置 | 关键点 |
|---|---|---|
| 找倒数第 k 个 | 快指针先走 k 步，再同步 | 只扫一遍，O(1) 空间 |
| 判环 / 找入口 | 快 2 慢 1；相遇后一头一相遇点同速 | 有环必相遇 |
| 找公共结点 | 长的先走长度差，再同步 | 比较**指针**不是 data |
| 找中间结点 | 快 2 慢 1，快到头慢在中点 | 与判环同一骨架 |
| 就地逆置 | 头插法 + 暂存后继 r | 别忘 `L->next = NULL` |
| 合并两有序链表 | p、q 各指一表，尾插建新表 | 与顺序表归并同构 |

## 快速技巧与口诀

**1. 顺序表 vs 链表 选择题口诀**
> **顺序表：随机存取快，插删要搬家，空间要连续，长度得先定。**
> **链表：插删只改针，找位要走路，空间碎片化，指针占密度。**

配套判定：
- 出现"**平均**"→ 顺序表插删一律 O(n)（最好 O(1)、最坏 O(n)，平均 n/2 仍记 O(n)）；
- 出现"**第 i 个**"→ 顺序表 O(1)，链表 O(n)；
- 出现"**给定指针 p**"→ 链表插删 O(1)（不用定位）；
- 只写"**线性表**"三字 → 顺序、链式都要考虑（第 12 题：删 a50 要不要移动，答"不一定"）。

**2. 插入"先连后断"**
> 先用 `p->next` 把新结点接上，最后再改 `p->next` 指向新结点。
> 记法：**"先给新结点找好退路，再动老指针。"** 只要先 `q = p->next;` 暂存，顺序随便写。

**3. 双链表插入四步口诀**
> **"后连后、后回指、前指 p、p 指 s"**
> `s->next=p->next; p->next->prior=s; s->prior=p; p->next=s;`
> 最后一步永远是改 `p->next`，所以必须排最后。

**4. 删除三件套**
> **"存 q → 跨过 q → free(q)"**，一句不能少：忘了存 q 就 free 错对象，忘了 free 就内存泄漏。

**5. 判空条件速查**

| 结构 | 带头结点 | 不带头结点 |
|---|---|---|
| 单链表 | `L->next == NULL` | `L == NULL` |
| 循环单链表 | `L->next == L` | `L == NULL` |
| 双链表 | `L->next == NULL` | `L == NULL` |
| 循环双链表 | `L->next == L && L->prior == L` | `L == NULL` |

**6. 头结点存在性判断**
> 说"带头结点"→ 遍历从 `p = L->next` 开始；没说或说不带头 → 从 `p = L` 开始，插删首元要特判。真题基本都带头结点，图里有空白结点就是带头结点。

**7. 定位循环"计数器即位置"**
> `j` 从 0 起，每 `p = p->next` 一次 `j++`，**循环结束时 j 就是 p 所在的位序**（头结点为 0）。定位第 i-1 个 → 条件 `j < i-1`；求表长 → 条件 `p->next != NULL`。两段代码骨架相同。

**8. 选链表类型的判定法**
> 问两句：**"删 x 能 O(1) 拿到 x 的前驱吗？在 x 后插能 O(1) 拿到 x 吗？"** 循环双链表 + 头指针四项全 O(1)；循环单链表**删尾永远 O(n)**，是最快的排除依据。

**9. 代码题答题模板**
```
① 算法思想：申请……；从头遍历……；用头插法/尾插法……；返回……
② 代码：（核心函数，for/while 关键行加 // 注释）
③ 复杂度：时间复杂度 O(?), 空间复杂度 O(?)
```

## 易错点与坑

1. **头指针 ≠ 头结点**：前者是指针（必有），后者是结点（可无）；且**求表长时头结点不计入**，`h→A→B→C→D` 长度 4 不是 5。
2. **插入顺序写反导致断链**：先 `p->next = s` 再写 `s->next = p->next`，`s->next` 会指向自己，B 及其后全部丢失。
3. **删除时 free 错对象**：`p->next = p->next->next; free(p->next);` 释放的是后继的后继，要删的结点泄漏。
4. **循环单链表仍用 `L == NULL` 判空**：带头结点时必须 `L->next == L`。
5. **把静态链表当成支持随机访问**（31 题第一个说法就错）：它靠下标跳转，访问第 i 个仍需从头走。
6. **"线性表"不等于"顺序表"**：第 12 题只给"长度 100 的线性表，删 a50 移动多少"，须分顺序存储（50 个）与链式存储（0 个）。
7. **笼统说"链表插删 O(1)"**：正确说法是已知前驱时改指针 O(1)，按位序插删总时间 O(n)，这是命题人最爱设的陷阱。
8. **数组大小是变量时写 `int a[n];`**：C 不支持，必须 `malloc` 或 `new`。
9. **33 题读题顺序错**：问的是"A、E、F 的链接地址依次"，看成 A、F、E 就会误选 C；正确为 A=1014、E=1004、F=1010。
10. **27 题漏掉"长度 0"**：`head->next->next == head` 既可能是 1 个结点，也可能是空表。
11. **双链表插入只背顺序不记原因**：死记"①②在④前"，换到前插场景就套错——前插是"①② 在改 `p->prior` 之前"。
12. **循环双链表删除画蛇添足加特判**：两句本身对首、尾、唯一结点都成立，加 `if` 反而易错（32 题 D 选项就没加）。

## 本章例题

### 例 1（课后 13 题·选择）平均 O(1) 的操作

**题干**：顺序存储的有序表中，平均时间复杂度为 O(1) 的是？
A. 查找指定值　B. 插入指定值　C. 删除第 i 个　D. 获取第 i 个

**分步**：① A 按值查找最好第 1 个命中、最坏末尾，平均 n/2 → O(n)；② B 插入最好表尾不移动、最坏表头全后移，平均 n/2 → O(n)；③ C 删除同理，平均 n/2 → O(n)；④ D 按首地址一步算出 `A+i*L` → **O(1)**。

**答案 D**。要点：常数系数 1/2 在复杂度中忽略，"平均 n/2"仍是 O(n)。

### 例 2（课后第 10 题·2010 真题·算法大题）循环左移 p 位

**题干**：n 个整数存于数组 `R`，设计时空尽可能高效的算法，将序列循环左移 p 位（0<p<n）。要求：① 算法思想；② C/C++ 实现；③ 时空复杂度。

**数据**：`R=[6,1,5,9,8,4,7]`，n=7，p=3，目标 `[9,8,4,7,6,1,5]`。

**解法一（暴力，考场首选）**：① 申请长 p 的 temp，存 `6,1,5`；② `R[p..n-1]` 前移 p 位，即 `R[i]=R[p+i]`；③ temp 放回 `R[n-p..n-1]`；④ 释放。
- 时间：p+(n-p)+p = **O(n+p)**，p<n 故也是 **O(n)**；空间：**O(p)**。

**解法二（三次反转，最优）**：① 反转前 p 个 `615→516`；② 反转后 n-p 个 `9847→7489`；③ 整体反转 `5167489→9847615` ✓。
- 时间：**O(n)**（精确 2n，忽略系数）；空间：**O(1)**。

**评分**：最优解 15 分，暴力解约 11～12 分。"三次反转"不具普适性，不做原题想不到，不必强求。

### 例 3（课后第 6 题·选择）Q 与 P 之间插入 S

Q 是 P 的前驱，插入 S。三地址全已知，**不需定位**；两句互不依赖，**顺序任意**：
`S->next = P; Q->next = S;` **答案 C**。

### 例 4（43 页 36 题·选择）四行代码的作用

`q=P->next; P->next=q->next; q->next=h->next; h->next=q;`，P 指向非首非尾结点。
原链 `h→A→B→C→D`，P 指 B：① q 指 C；② B 改指 D；③ C 指 A；④ h 指 C → `h→C→A→B→D`。
**答案 D：把 q 所指结点移到头结点之后（成为首元）**。方法：链表选择题一律先画图、逐行改图。

### 例 5（课后 17 题·选择）双链表插入的合法顺序

在 P 之后插入 Q，四句为 ①`Q->next=P->next` ②`Q->prior=P` ③`P->next=Q` ④`P->next->prior=Q`。
①④ 都要靠 `P->next` 找原后继 C，③ 会把 `P->next` 改成 Q 使 C 地址丢失 → **①④ 必须在 ③ 之前**，② 位置任意。
**答案 A**。

### 例 6（35 题·选择）双链表插入的补全

已执行 `S->next=P->next; P->next=S;`，此时 S 已在 P 之后，但 C 的 prior 仍指 P、S 的 prior 未赋值。
需补 `S->next->prior = S;` 与 `S->prior = P;`。**答案 C**。
要点：选项写法不唯一（把 S 写成 `P->next`、把 P 写成 `S->next->prior` 的等价形式都可能），自己推的式子找不到选项时，应逐项代图验证。

### 例 7（22、32 题·选择）循环双链表的判空与删除

**22 题**：空表只有头结点，next 与 prior 都指自己 → `L->next == L && L->prior == L`，**答案 D**。

**32 题**：链 `h→A→P→C→h`，① `P->prior->next = P->next`（A 跳过 P 指 C）；② `P->next->prior = P->prior`（C 跳过 P 指 A）；③ free(P)。两句无顺序要求，对首/尾/唯一结点均成立，**答案 D**。A 选项第二句写成 `P->prior->next = P->prior`（A 指自己），B 选项第一句写成 `P->next->prior = P->next`（C 指自己），均错。

### 例 8（26 题·选择）删除首元为 O(n) 的循环单链表

删首元要让首元的**前驱（尾结点）**跳过它。有尾指针 → O(1)（排除 B、D）；有头指针+头结点 → 头结点就是前驱，O(1)（排除 C）；只有头指针且不带头结点 → 须遍历到尾，**O(n)**。**答案 A**。

### 例 9（27 题·选择）`head->next->next == head` 时表长

表长 1：唯一数据结点的 next 指回头结点，成立；表长 0：`head->next` 就是 head，再取 next 仍是 head，也成立。**答案 0 或 1**。

### 例 10（34 题·选择）带头结点循环单链表删首元

常规：`Q=H->next; H->next=Q->next;`。若表只有一个结点，Q 同时是尾结点 P，删除后**尾指针必须改指头结点**：`if (P==Q) P=H;`，最后 `free(Q);`。**答案 D**。这是"删首元时唯一需要特判尾指针"的陷阱。

### 例 11（33 题·2016 真题·选择）静态链表插入

| 下标 | data | next |
|---|---|---|
| 1000 | A | 1010 |
| 1004 | B | 100c |
| 1008 | D | 0 |
| 1010 | E | 1004 |
| 100c | C | 1000 |

链序：C(100c)→A(1000)→E(1010)→B(1004)→D(1008)→0。将 F(1014) 插在 A 与 E 之间：F 的 next 指 E(1010)，A 的 next 改 F(1014)，E 的 next 不变仍为 B(1004)。
故 **A=1014、E=1004、F=1010，答案 D**。年年有人把"AEF"读成"AFE"误选 C。
