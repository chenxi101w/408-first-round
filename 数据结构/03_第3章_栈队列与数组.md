## 知识点详解

### 一、栈的基本概念与顺序/链式存储（3.1.1）

**定义**：只允许在**一端**（栈顶）进行插入和删除的线性表，是操作受限的线性表。特性 **后进先出 LIFO**。术语：栈顶（top，最后进入的元素）、栈底（bottom，最先进入的元素）；基本运算只有入栈 Push、出栈 Pop、取栈顶 GetTop。

**关键结论（卡特兰数）**：n 个**互不相同**的元素按**固定次序**入栈（可边进边出，栈容量不限），得到的出栈序列总数为

$$C_n=\frac{1}{n+1}\binom{2n}{n}=\frac{(2n)!}{n!\,n!\,(n+1)}$$

老师要求"专门记一下"，因为去年大题用过。n=3 时：$\binom{6}{3}=20$，$20/4=5$ 种，即 123 入栈的全部合法出栈序列为 123、132、213、231、321（共 5 种，**312 不合法**）。

**顺序栈（C 实现要点）**。`top` 是"指针"（其实是下标），初值不同，四条语句全变：

| 约定 | 初始化 | 判空 | 判满 | 入栈 | 出栈 | 栈顶元素 |
|---|---|---|---|---|---|---|
| A：先移再存 | `top = -1` | `top == -1` | `top == MaxSize-1` | `data[++top] = x` | `x = data[top--]` | `data[top]` |
| B：先存再移 | `top = 0` | `top == 0` | `top == MaxSize` | `data[top++] = x` | `x = data[--top]` | `data[top-1]` |

- 约定 A：`top` 指向**栈顶元素本身**（先加指针再存）。
- 约定 B：`top` 指向**栈顶元素的下一个位置**（先存再移动指针）。

老师还强调题干可能把数组写成 `data[1..N]`（下标 1~N）：

| 题干写法 | 初始 top | 必先做 | 入栈写法 | 判空 |
|---|---|---|---|---|
| `data[1..N]` | `top = 0` | 先移 | `data[++top] = x` | `top == 0` |
| `data[1..N]` | `top = 1` | 先存 | `data[top++] = x` | `top == 1` |
| `data[1..N]` | `top = N+1` | 指针往下走 | `data[--top] = x` | `top == N+1` |

```c
#define MaxSize 50
typedef struct { ElemType data[MaxSize]; int top; } SqStack;
void InitStack(SqStack *S){ S->top = -1; }              // 约定A
bool StackEmpty(SqStack S){ return S.top == -1; }
bool Push(SqStack *S, ElemType x){
    if (S->top == MaxSize - 1) return false;            // 上溢
    S->data[++S->top] = x; return true;
}
bool Pop(SqStack *S, ElemType *x){
    if (S->top == -1) return false;                     // 下溢
    *x = S->data[S->top--]; return true;
}
```

**链栈**：本质就是单链表，**所有操作都在表头**（表尾入栈还行、出栈要删尾结点却找不到前驱，所以不用表尾）。带头结点不带头结点都行，看书上约定（王道约定不带头结点），**最终看题目要求**。

```c
typedef struct LNode { ElemType data; struct LNode *next; } LNode, *LiStack;
// 不带头结点：栈顶指针 top 就是链表头指针
// 入栈（头插）：s->next = top; top = s;
// 出栈：x = top->data; p = top; top = top->next; free(p);
// 判空：top == NULL
```

### 二、共享栈（3.1.2）

两个顺序栈**共用一个数组**，栈底分别固定在数组两端，栈顶向中间生长。

```
下标:   0    1    2    3    4    5    6
        |    |    |    |    |    |    |
            ↑top0            top1↑
        ← 0号栈生长      1号栈生长 →
```

- 初始化：`top0 = -1`，`top1 = MaxSize`（本题 MaxSize=7）。
- 0 号栈入栈：`data[++top0] = x`（先加再存）；1 号栈入栈：`data[--top1] = x`（先减再存）。
- **栈满条件：`top1 - top0 == 1`**（两个栈顶相邻，中间没有空位）。
- 元素总数：`top1 - top0 - 1`。

若把初值改成 `top0 = 0, top1 = n-1`（都指向"下一个可存位置"的另一种约定，先存再移），则**栈满条件变成 `top0 - top1 == 1`**。老师反复强调：**这种题不要背结论，画图模拟**。

**共享栈的两个好处（24 题答案）**：① 节省存储空间（一个数组给两个栈用，某栈小则空间被另一栈"吃掉"）；② **降低发生上溢的可能**（单栈指针一路增长容易越过数组上界）。

### 三、栈的入栈出栈分析（3.1.3）

**判定流程（模拟法）**：

```
目标出栈序列 p1 p2 ... pn，入栈序列 1..n，当前待入栈元素 next=1
for k = 1..n:
    ① 若栈顶 == pk           → 弹栈，k++
    ② 否则若 next <= n       → 把 next 压栈，next++
    ③ 否则（栈顶≠pk 且已无元素可入）→ 该序列非法，结束
全部匹配 → 合法
```

**合法性必要条件（速判，教材补充）**：出栈序列中若存在 i<j<k 且 $p_i < p_k < p_j$，则非法（即"大、小、中"模式不合法）。例如 3 1 2：3 已出栈说明 1、2 都在栈内且 1 在下、2 在上，只能先出 2，故 312 非法。

**带限制的变式**（真题 27、29、31 都是这一类）：允许入出交替但**不允许连续三次出栈**、指定第 k 个出栈元素、判断一个序列能否由另一序列得到——全部用上面的模拟流程逐个试。

### 四、队列的基本概念（3.2.1）

**定义**：只允许在**一端插入（队尾 rear）、另一端删除（队头 front）**的受限线性表，特性 **先进先出 FIFO**，"先到先服务"。基本运算：入队 EnQueue、出队 DeQueue、取队头 GetHead。

### 五、顺序队列与循环队列（3.2.2）

**假溢出**：顺序队列用 `front`、`rear` 两个下标，入队 `rear++`、出队 `front++`，两个指针只增不减。当 `rear` 越过数组上界时，数组前部因出队留下的空位无法再用——**明明有空位却放不进去**，这就是假溢出。解决办法：把数组**逻辑上看成一个环**，指针加一后对容量取模。

```c
#define MaxSize 6                       // 数组 0..5，共 6 个单元
typedef struct { ElemType data[MaxSize]; int front, rear; } SqQueue;
```

**两种 front/rear 约定（必须分清，真题考过两次）**：

| 约定 | 初始值 | front 指向 | rear 指向 | 入队 | 出队 | 判空 | 判满（牺牲一个单元） | 长度 |
|---|---|---|---|---|---|---|---|---|
| ① 常用 | `front = rear = 0` | 队头元素 | **队尾元素的下一个位置** | `data[rear]=x; rear=(rear+1)%M` | `x=data[front]; front=(front+1)%M` | `front==rear` | `(rear+1)%M == front` | `(rear-front+M)%M` |
| ② 变式 | `front = rear = M-1` | 队头元素的**前一个** | **队尾元素** | `rear=(rear+1)%M; data[rear]=x` | `front=(front+1)%M; x=data[front]` | `front==rear` | `(rear+1)%M == front` | `(rear-front+M)%M` |

**四种"初值 → 指向"组合（老师重点，真题原题）**：

| 初始化 | 第一个元素放在 0 号 | 于是 rear 指向 | front 指向 |
|---|---|---|---|
| `front=0, rear=0` | 先存再移 | 队尾的**后一个** | 队头 |
| `front=N-1, rear=N-1` | 先移再存 | 队尾 | 队头的**前一个** |
| `front=N-1, rear=0` | 先存再移 | 队尾的**后一个** | 队头的**前一个** |
| `front=0, rear=N-1` | 先移再存 | 队尾 | 队头 |

反向也要会：题目说"rear 指向队尾的后一个位置"，就要立刻反推出 `rear` 初值必是 0（先存再移）；说"front 指向队头的前一个位置"，初值必是 N-1。

**判空/判满冲突与三种解法**：空时 `front==rear`，装满一圈后也 `front==rear`，无法区分。

1. **牺牲一个存储单元**（最常用）：认为 `(rear+1)%M == front` 即满，实际最多存 M-1 个。
2. 增设 `size` 计数器：`size==0` 空，`size==M` 满。
3. 增设 `tag`：最近一次操作是入队则 `front==rear` 为满，是出队则为空。（教材补充）

**长度公式推导（老师要求会推，不背）**：

- 若 `rear >= front`：元素个数 = `rear - front`（如 front=0、rear=5，共 5 个）。
- 若 `rear < front`（指针绕过一圈）：`rear - front` 为负，加一个 M 补回来，`rear - front + M`（如 M=6、front=2、rear=0，得 4，正好 CDEF 四个）。
- 合并成一个式子：**(rear - front + M) % M**。rear≥front 时加 M 再取模等于没加；rear<front 时取模不生效，正好补上 M。

> 注意：公式里的 M 是**数组总容量**（含被牺牲的那个单元），不是"实际可存元素个数 M-1"。这是最高频的错点。

```c
void InitQueue(SqQueue *Q){ Q->front = Q->rear = 0; }
bool QueueEmpty(SqQueue Q){ return Q.front == Q.rear; }
bool QueueFull(SqQueue Q){ return (Q.rear + 1) % MaxSize == Q.front; }
bool EnQueue(SqQueue *Q, ElemType x){
    if ((Q->rear + 1) % MaxSize == Q->front) return false;
    Q->data[Q->rear] = x;  Q->rear = (Q->rear + 1) % MaxSize;  return true;
}
bool DeQueue(SqQueue *Q, ElemType *x){
    if (Q->front == Q->rear) return false;
    *x = Q->data[Q->front]; Q->front = (Q->front + 1) % MaxSize; return true;
}
int QueueLength(SqQueue Q){ return (Q.rear - Q.front + MaxSize) % MaxSize; }
```

**开闭区间速判（老师讲的通用技巧）**：指针指向"元素本身"相当于**闭**，指向"前一个/后一个"相当于**开**。两端都是开区间时，长度 = `rear - front - 1`；一端开一端闭时，直接 `rear - front`；两端都闭时，`rear - front + 1`。所以**不要死套 (rear-front+M)%M**，先看指向再定式。

### 六、链队与双端队列（3.2.3）

**链队**：同时带 `front`、`rear` 两个指针的单链表，队头在表头出队、队尾在表尾入队。

```c
typedef struct LNode { ElemType data; struct LNode *next; } LNode;
typedef struct { LNode *front, *rear; } LiQueue;   // 带头结点
// 初始化：front = rear = (LNode*)malloc(sizeof(LNode)); front->next = NULL;
// 判空：front == rear
// 入队：s->next = NULL; rear->next = s; rear = s;
// 出队：p = front->next; x = p->data; front->next = p->next;
//       if (rear == p) rear = front;   // 删的是最后一个结点，必须重置 rear
//       free(p);
```

不带头结点时：判空 `front == NULL && rear == NULL`；出队后若 `front == NULL` 要置 `rear = NULL`（否则 rear 变野指针）。

**双端队列 Deque**：两端都能插入、都能删除。

- **输出受限**：一端可插可删，**另一端只允许插入**（出口只有一个）。
- **输入受限**：一端可插可删，**另一端只允许删除**（入口只有一个）。

**判定套路（19、20、24 题通用）**：
- 输出受限 → 把**选项给的输出序列**倒着填进队列（因为只能一端出，出队顺序的逆序就是队列从出口到另一端的排列），再看能否用"两边插入"拼出来。
- 输入受限 → 把**入队序列**按顺序填，再看能否从两端出成选项。

### 七、栈在括号匹配中的应用（3.3.1）

**算法流程（流程图式步骤）**：

```
初始化空栈 S
for 每个字符 c in 表达式:
    │
    ├─ c 是左括号 ( [ {  ──────────→ 压栈，继续
    │
    └─ c 是右括号 ) ] } :
           ├─ 栈空？ ──── 是 ──→ 右括号多余，非法，结束
           ├─ 栈顶与 c 匹配？ ── 否 ──→ 类型交叉，非法，结束
           └─ 是 ──→ 弹出栈顶，继续
扫描结束:
    ├─ 栈空 ──→ 合法
    └─ 栈非空 ──→ 左括号多余，非法
```

**老师走的两个例子**：

| 序列 | 过程 | 结论 |
|---|---|---|
| `[ ( [ ] ) ]` 型合法序列 | 依次压 `[` `(` `[`；遇 `]` 弹 `[`；遇 `)` 弹 `(`；遇 `]` 弹 `[`；扫描完栈空 | 合法 |
| `( ( )` | 压 `(`、压 `(`、遇 `)` 弹一个；扫描完栈里还剩一个 `(` | **栈非空 → 非法** |
| `[ ( ] )` | 压 `[`、压 `(`、遇 `]` 时栈顶是 `(`，**类型不匹配** | **提前终止 → 非法** |

**记忆**：只有**左括号入栈**，字母、数字、运算符一律跳过；右括号不入栈。

### 八、中缀转后缀（3.3.2）

**三种表达式**：`3+4`（中缀，运算符在中间）、`34+`（后缀，运算符在后）、`+34`（前缀）。中缀**依赖括号**确定顺序，后缀**无需括号**，计算机主要用后缀。

**方法一：手算加括号法**（人脑最快）
按运算优先级从内到外给每个"二元运算"加一对括号，然后把每个运算符移到它那对括号的**右括号后面**，最后删掉所有括号。

以 `A + B*(C-D) - E/F` 为例：

```
原式      A + B * (C - D) - E / F
加括号    ((A + (B * (C - D))) - (E / F))
移符号    ((A (B (C D)-)*)+ (E F)/)-
去括号    A B C D - * + E F / -
```

**方法二：运算符栈（计算机做法）**。规则（老师强调这是**纯记规则**，没有推理）：

1. **操作数**：直接输出到后缀表达式。
2. **左括号 `(`**：直接入栈（它起"隔断"作用，挡住下面的运算符）。
3. **右括号 `)`**：不入栈，**连续弹栈并输出**，直到弹出左括号为止，左括号**弹出后丢弃**。
4. **运算符 op**：与栈顶比较优先级，**栈外优先级 > 栈内优先级才入栈**；否则（低于**或等于**）反复弹栈输出，直到满足条件再入栈。
5. 扫描结束后，把栈中剩余运算符**依次弹出输出**。

**优先级表（isp=栈内，icp=栈外，教材补充的量化形式）**：

| 运算符 | isp（栈内） | icp（栈外） | 说明 |
|---|---|---|---|
| `+` `-` | 3 | 2 | 左结合，相等时**栈外不占优 → 弹出** |
| `*` `/` | 5 | 4 | 高于加减 |
| `(` | 1 | 6 | 栈内最低（永不被弹出），栈外最高（必入栈） |
| `)` | — | 1 | 不入栈，触发弹栈 |

**逐步演示：`A + B*(C-D) - E/F`**

| 步 | 扫描 | 动作 | 运算符栈（底→顶） | 后缀表达式 |
|---|---|---|---|---|
| 1 | A | 操作数，输出 | 空 | A |
| 2 | + | 栈空，入栈 | `+` | A |
| 3 | B | 输出 | `+` | A B |
| 4 | * | icp(*) > isp(+) → 入栈 | `+ *` | A B |
| 5 | ( | 左括号直接入栈 | `+ * (` | A B |
| 6 | C | 输出 | `+ * (` | A B C |
| 7 | - | 栈顶是 `(`，隔断，直接入栈 | `+ * ( -` | A B C |
| 8 | D | 输出 | `+ * ( -` | A B C D |
| 9 | ) | 弹到 `(`：弹出 `-` 输出，丢弃 `(` | `+ *` | A B C D - |
| 10 | - | `*` 优先高 → 弹出；`+` 同级 → 弹出；栈空 → 入栈 | `-` | A B C D - * + |
| 11 | E | 输出 | `-` | A B C D - * + E |
| 12 | / | 高于 `-` → 入栈 | `- /` | A B C D - * + E |
| 13 | F | 输出 | `- /` | A B C D - * + E F |
| 14 | 结束 | 弹出 `/`、`-` | 空 | **A B C D - * + E F / -** |

栈最深时 3 个（`+ * (`）。**验证**：中缀先算 C-D，再 B×，再 +A，再 E/F，最后相减，与后缀顺序完全一致。

**真题 13 题的"栈中最多几个运算符"**：题给中缀表达式（字幕识别不清，按流程复盘为 `A+B-C*((C+D)/E-F)+G`），规则同上——注意两点：① 连续两个左括号会**叠加两层**；② 遇到 `)` 弹出的运算符要计数后再减。全程栈内最多同时有 **5** 个运算符（`- * ( ( +`）。这类题必须动手模拟，光看表达式看不出来。

### 九、后缀表达式求值 / 双栈直接求中缀值（3.3.3）

**后缀求值规则**：只需**一个操作数栈**。遇操作数压栈；遇运算符**弹出两个数**：**先弹出的放运算符右边，后弹出的放左边**（减法除法不可交换，这是最容易错的地方），运算结果再压栈。最后栈中唯一元素即结果。

**逐步演示：`A B C D - * + E F / -`**

| 步 | 扫描 | 动作 | 操作数栈（底→顶） |
|---|---|---|---|
| 1 | A | 压栈 | A |
| 2 | B | 压栈 | A B |
| 3 | C | 压栈 | A B C |
| 4 | D | 压栈 | A B C D |
| 5 | `-` | 弹 D（右）、弹 C（左）→ C-D，压回 | A B (C-D) |
| 6 | `*` | 弹 (C-D)（右）、弹 B（左）→ B*(C-D) | A B*(C-D) |
| 7 | `+` | 弹 B*(C-D)、弹 A → A+B*(C-D) | A+B*(C-D) |
| 8 | E | 压栈 | … E |
| 9 | F | 压栈 | … E F |
| 10 | `/` | 弹 F、弹 E → E/F | … E/F |
| 11 | `-` | 弹 E/F（右）、弹左边 → (A+B*(C-D)) - E/F | 结果 |

**双栈法直接求中缀值（课后第 4 题）**：一个**操作数栈** + 一个**运算符栈**，把"中缀转后缀"和"后缀求值"两个流程**合起来跑**：扫描到运算符时按中缀转后缀规则处理运算符栈；**每当弹出一个运算符，就立刻从操作数栈弹两个数运算，结果压回操作数栈**；扫描结束后把运算符栈清空（每弹一个就算一次）。等价于"边转后缀边求值"。

例：`A - B*(C-D)`，操作数栈容量只有 2 时**不会溢出**（A、B 弹出后把 A-B 压回，栈内始终 ≤2），而 `A - B*(C-D) ...` 若括号位置使得 C、D 与已有操作数同时存在，就会超容量——这就是第 4 题 A 溢出、B 不溢出的判断依据。

**18 题（两栈模拟）**：S1 存数据 `5 8 3 2`，S2 存运算符 `* - +`，共执行 3 次：

| 次 | 弹出数据（先→后） | 弹出运算符 | 运算 | 结果压回 S1 |
|---|---|---|---|---|
| 1 | 2、3 | `+` | 3+2 | 5 |
| 2 | 5、8 | `-` | 8-5 | 3 |
| 3 | 3、5 | `*` | 5×3 | **15** |

答案 15（B）。

### 十、栈在递归与函数调用中的应用（3.3.4）

**函数调用链**：`F` 调用 `G`，`G` 调用 `H`。

```
时间轴：  F 开始 ──→ G 开始 ──→ H 开始 ──→ H 结束 ──→ G 结束 ──→ F 结束
栈变化：  [F]        [F G]       [F G H]     [F G]       [F]        空
```

**开始顺序 = 入栈顺序（F→G→H）；结束顺序 = 出栈顺序（H→G→F）**，正好是后进先出。空间开销取决于**栈的最大深度**。

**递归三要素**：① 递归出口（如 `n==0` 返回 0）；② 递归体（自己调用自己）；③ 每层参数向出口收敛。

**递归树分析法（老师强调的做题方法）**：把每次调用的参数画成树的结点。以 `F(n) = (n<=3) ? 1 : F(n-2)+F(n-4)` 求 F(8) 为例：

```
                F(8)
              /      \
          F(6)        F(4)
        /     \      /    \
     F(4)    F(2)  F(2)  F(0)
    /    \
 F(2)   F(0)
```

- **时间复杂度 = 结点个数**（每层 O(1)）：F8、F6、F4、F2、F0、F2、F4、F2、F0 共 **9 次**。
- **空间复杂度 = 树的高度**：F8→F6→F4→F2，共 **4** 层，即栈中同时最多 4 个栈帧（不是 9 个——左子树算完就出栈，才会去算右子树）。

**15 题（真题）**：`S(n) = (n<=0) ? 0 : S(n-1)+n`，`main` 中调用 `S(1)`。执行时栈**从栈底到栈顶**依次是 `main → S(1) → S(0)`（选这个顺序）。随后 S(0)=0 出栈，S(1)=0+1=1，main 最后出栈。

### 十一、队列的应用（3.3.5）

- **二叉树层次遍历**：根入队，出队时把左右孩子入队（第五章详讲）。
- **打印缓冲区/主机与打印机速度不匹配**：发送方快、接收方慢，用一个队列按到达顺序缓存，避免数据丢失。
- **操作系统**：先来先服务（FCFS）、FIFO 页面置换、磁盘调度，本质都是队列。

### 十二、一维/二维数组的地址计算（3.4.1）

设每个元素占 L 个存储单元，`LOC(a[0])` 为首地址（数组地址取**元素起始字节**）。

- **一维**：`LOC(a[i]) = LOC(a[0]) + i*L`。例：首地址 100、L=4，则 `LOC(a[6]) = 100 + 6*4 = 124`。
- **二维（m 行 n 列，行优先）**：`LOC(a[i][j]) = LOC(a[0][0]) + (i*n + j)*L`
- **二维（列优先）**：`LOC(a[i][j]) = LOC(a[0][0]) + (j*m + i)*L`

符号含义：i 行标、j 列标、**n 是列数（每行元素个数）**、**m 是行数（每列元素个数）**、L 元素大小。

**记忆法**：行优先 → "行标 × **列数** + 列标"；列优先 → "列标 × **行数** + 行标"。因为走完 i 整行/整列，跨过的元素个数由"另一维的长度"决定。

例：4 行 5 列、首地址 100、L=4，求 `A[2][3]`（行优先）：
`100 + (2*5 + 3)*4 = 100 + 52 = 152`。含义：前面 2 整行共 10 个元素，本行前面还有 3 个，共 13 个元素。

**易混提醒**：下标从 0 开始时，`i=2` 表示**前面有 2 整行**（0、1 行），所以直接乘 5，**不要乘 3**；同理 `j=3` 表示本行前面有 3 个元素，直接加 3，**不要再加 1**。

### 十三、特殊矩阵的压缩存储（3.4.2）

**压缩存储**：多个值相同的元素只分配一个存储空间，零元素不分配。常见三类：对称矩阵、三角矩阵、三对角（带状）矩阵。

**做题总原则（老师反复强调）**：**不要背任何公式**，全部现场数。步骤固定为：
1. 看清**存上三角还是下三角**、**行优先还是列优先**；
2. 看清**二维下标从 0 还是从 1 开始**、**一维数组下标从 0 还是从 1 开始**；
3. 数出目标元素**前面有多少个元素**；
4. `一维下标 = 个数 - 1`（一维从 0 开始时）；若一维从 1 开始，`下标 = 个数`。

**（1）对称矩阵** $a_{ij}=a_{ji}$（n×n，只存一半）

存**下三角**（含主对角线，i≥j），**行优先**，二维下标从 1 开始、一维下标从 0 开始：

$$k = \frac{i(i-1)}{2} + (j-1)$$

推导：第 1~i-1 行共 $1+2+\cdots+(i-1)=\frac{i(i-1)}{2}$ 个，本行第 j 个再往前 j-1 个。

存**上三角**（i≤j），**行优先**，1 基：

$$k = (i-1)n - \frac{(i-1)i}{2} + (j-i)$$

（第 1~i-1 行依次有 n、n-1、…、n-i+1 个元素）

若 $i>j$（目标在下三角而只存了上三角），**必须先转置**：用 $a_{ji}$ 的位置。

存**上三角**、**列优先**（1 基）：第 j 列有 j 个元素，前 j-1 列共 $\frac{j(j-1)}{2}$ 个，本列再数到第 i 行：

$$k = \frac{j(j-1)}{2} + (i-1)$$

**（2）三角矩阵**

- **下三角矩阵**：上三角区全为同一常数 C。存储 = 下三角元素 + **1 个常数 C**，总长 $\frac{n(n+1)}{2}+1$。下三角元素用上面的对称矩阵公式；若目标在上三角（i<j），下标 = **最后一个位置** $\frac{n(n+1)}{2}$。
- **上三角矩阵**：下三角区全为常数 C，同理，公式换用上三角公式，常数 C 放在末尾。

**（3）三对角矩阵**（带状，仅 `|i-j| ≤ 1` 非零）

行优先、1 基、每行最多 3 个：

$$k = 2i + j - 3 \quad(\text{一维下标从 }0\text{ 开始})$$

推导：第 1 行 2 个，第 2~i-1 行各 3 个 → 之前共 $2+3(i-2)=3i-4$ 个；本行内 `a[i][j]` 是第 $j-i+2$ 个 → 个数 $=3i-4+j-i+2=2i+j-2$，减 1 得下标。

（教材补充）反之，已知一维下标 k 求行列：$i=\lfloor k/3 \rfloor+1$，$j=k-2i+3$。

**（4）稀疏矩阵**（3.4.3）

非零元素极少（如 100×100 只有不到 100 个非零元）。**三元组** = `(行标, 列标, 值)`，按行优先顺序存进**一维数组**（不是二维数组！），称为**三元组表**；另有**十字链表**（行链表 + 列链表交叉，只需存非零结点）。

**关键结论（真题考过）**：只有三元组表**无法唯一还原**矩阵——同一个三元组表既可以还原成 4×4，也可以还原成 6×6、8×4。所以**必须额外存储原矩阵的行数和列数**。非零元素个数**不必**单独存（三元组表长度 ÷ 3 即得）。

## 快速技巧与口诀

- **栈**："后进先出，一端进出"；**队列**："先进先出，一端进另一端出"。
- **顺序栈判空判满**：`top=-1` 起 → 空 -1、满 MaxSize-1；`top=0` 起 → 空 0、满 MaxSize。**先移再存指向栈顶，先存再移指向栈顶之上**。
- **共享栈满**：`top1 - top0 == 1`（top0 从 -1、top1 从 n 起）；换初值就换符号，**画图最稳**。
- **循环队列三句**：入队动 rear、出队动 front、都要 `% M`；**空看相等，满看"rear 追上一格就撞 front"**。
- **长度公式**：`(rear - front + M) % M`，M 是**容量**；两端都开区间时再减 1。
- **中缀转后缀口诀**：**"数直接出，左括号进，右括号弹到左括号，运算符外面大才进、否则一直弹"**；相等也弹（左结合）。
- **后缀求值口诀**：**"先弹的当右边"**（减法、除法别写反）。
- **卡特兰数速算**：n=3→5，n=4→14，n=5→42（记这三个数足够应付选择）。
- **矩阵压缩四问**：存哪一半？行优先还是列优先？下标 0 起还是 1 起？最后一行/列单独看了吗？
- **数组地址一句话**：**行优先乘列数，列优先乘行数**。
- **递归树**：结点数 = 时间，高度 = 空间。

## 易错点与坑

1. **长度公式里的 M**：题目给 `0..M-1` 共 M 个单元、实际只存 M-1 个，取模仍用 **M**，用 M-1 就全错（第 5、9 题专治这个）。
2. **判满公式与初始化绑定**：`(rear+1)%M == front` 只在"front 指队头、rear 指队尾后一个"时成立；换约定必须重推，不能照抄。
3. **共享栈满条件随初值变化**：`top0=-1/top1=n` 时是 `top1-top0==1`；改成 `top0=0/top1=n-1` 就变成 `top0-top1==1`。老师原话："不要去记结论，模拟一下。"
4. **对称矩阵只存上三角时忘转置**：14 题问 `M[7][2]`，必须转成 `M[2][7]` 再算，否则正好命中干扰项（22 vs 错误答案）。
5. **下标基准差一**：二维从 0 起时 `a[i][i]` 实际是第 i+1 行第 i+1 列（第 3 题就靠这个）；一维数组写成 `B[1..298]` 时下标 = 个数，**不用减 1**（第 6 题）。
6. **三角矩阵/三对角矩阵的最后一行（列）**：`M[6][6]` 在 12×12 上三角里只存 **1** 个，若按 12、11、10…一路加到 7 就多算。
7. **后缀求值弹出顺序反了**：`C D -` 弹栈得 D 先、C 后，结果必须是 **C-D**，写 D-C 直接错。
8. **中缀转后缀遇右括号**：右括号**不入栈**；弹出的左括号**丢弃**（后缀里没有括号）。另外栈内 `(` 优先级最低、栈外最高，别记反。
9. **链队出队删到最后一个结点**：必须 `rear = front`，否则 rear 悬空，下次入队写非法地址。
10. **卡特兰数的前提**：入栈顺序固定、元素互异、栈容量不限；若题目允许"任意入栈顺序"或元素有重复，不能直接套。
11. **只用 front==rear 判满**：没有牺牲单元/没有 size/tag 时，装满一圈与空无法区分，必须靠"牺牲一个单元"。
12. **栈的链式存储别在表尾操作**：单链表删尾结点找不到前驱，出栈代价 O(n)，所以链栈一律在表头。

## 本章例题

**例 1（课后 4、5、6：由 top 初值判断入栈语句）**
- 第 4 题：数组 `data[0..N-1]`，`top` 初始化为 **1**。1 号位置本来不能直接存，必须**先移再存** → `data[++top] = x`（选 C）。
- 第 5 题：数组写成 `data[1..N]`，`top` 初始化为 **1**。1 号位置本来就能存 → **先存再移** → `data[top++] = x`（选 B）。若把初值改成 0，就变成先移再存（选 D）。
- 第 6 题：`data[1..N]`，`top` 初始化为 **N+1**（在数组外面），指针必须**往下走** → `data[--top] = x`（选 A）。

**例 2（课后 10、11：链栈）**
- 10 题：不带头结点，在栈顶插入 x → `x->next = top; top = x;`（选 C，先接后改头）。
- 11 题：出栈并取值 → `x = top->data; top = top->next;`（选 D，**先取值再移指针**，顺序反了数据就丢）。

**例 3（课后 24、25：共享栈）** 24 题问共享栈好处 → **节省空间、降低上溢可能**。25 题给 `top1=0`（左）、`top2=N`（右），满条件 `top2 - top1 == 1`；若改为 `top1=0, top2=N-1`，则满条件变 `top1 - top2 == 1`（选 B）。

**例 4（真题 27：不允许连续三次出栈）** 入栈序列 A…F，找不可能的出栈序列，答案 **D**。验证 D：要第一个出 A，A 进即出；要第二个出 F，必须把 B、C、D、E、F 依次压入；然后连续弹出 F、E、D —— 已连续三次出栈，违反条件。其余选项均可做到"最多连出两次"。**做法：对每个选项走一遍模拟流程，统计连续出栈次数。**

**例 5（真题 29：P2=3 求 P3）** 入栈 1..n，第二个出栈的必须是 3，问第三个出栈可能是几。分情况枚举第一个出栈元素 P1：
- P1=1：1 进即出 → 压 2、3，出 3（P2）→ 此时栈内 2，第三个可出 **2**；也可继续压 4、5…，第三个出 4…n。
- P1=2：压 1、2，出 2 → 压 3，出 3（P2）→ 栈内 1，第三个可出 **1**；也可继续压 4…，第三个出 4…n。
- P1=3：不行（3 已经是 P2）。
- P1=4：压 1..4，出 4 → 出 3（P2）→ 栈内 1、2，第三个可出 **2**；也可继续压 5…，出 5…n。
- P1≥5：不可能（若 P1=5，则 3 被 4 压住，P2 无法是 3）。
取**并集**：P3 ∈ {1, 2, 4, 5, …, n}，即除 3 以外全部，共 **n-1** 种。

**例 6（真题 31：由入栈序列判定出栈序列）** 入栈 ABCD，判断 out 是否可能。做法：第一个要出 C → 压到 C，弹出 C；看栈顶是否为下一个目标，是则弹，否则继续压；若元素压完仍不匹配 → 非法。
- `CBDA`：压 A B C，出 C；栈顶 B = 目标 → 出 B；目标 D，栈顶 A ≠ D → 压 D，出 D；剩 A，出 A → **合法**。
- `CABD`：出 C 后目标 A、栈顶 B ≠ A，继续压 D，全部压完仍不等 → **非法**。
- 结论：A、B 都能用同一套流程判定；C 项"入栈与出栈顺序一定不同"错（可进一个出一个）；D 项"可能互为倒序"对（ABCD 全进再全出得 DCBA）。答案 **D**。

**例 7（真题 20：输出受限双端队列）** 入队 ABCD E 顺序，只有一端能出，问不可能的出队序列，答案 **C（DBCAE）**。判定：只有一端出队时，**出队序列就是队列自出口端向另一端的排列**，而队列只能从两端插入 → **A 先入、B 紧接着入（只能贴在 A 的左边或右边），此后 C、D、E 只能加在两端，永远无法把 A、B 分开**。C 项 D B C A E 中 A、B 之间夹了 C，故不可能。其余选项（如 E C B A D）都可由"两边交替插入 + 全部从左端出"拼出。24 题（21 年真题）同一模型同一做法。

**例 8（真题 20：括号匹配的栈容量）** 题给表达式（只统计括号，字母运算符忽略），栈容量只有 3，问哪个不能处理，答案 **D**。D 中某处**同时存在 4 个左括号**（如 `[ ( [ ( `），超过容量 3 → 溢出。A 项模拟后栈内最多同时 3 个（中途遇右括号陆续弹出），故可处理。**要点：这类题必须逐字符模拟并记录栈的峰值。**

**例 9（中缀转后缀 2 题、19 题）**
- 2 题：`A*(B+C)-D` → 手算：B+C 是整体 → `BC+`；A 与它相乘 → `ABC+*`；再减 D → **`ABC+*-D`**（选 B）。
- 19 题：`X + Y*(Z-U)/V` → 先 Z-U 得 `ZU-`，乘 Y 得 `YZU-*`，除 V 得 `YZU-*V/`，最后加 X → **`XYZU-*V/+`**（选 A）。

**例 10（括号匹配过程题）** 见"知识点详解·七"的三行表：合法、右括号多余、类型交叉、左括号多余四种结局必须都能背出判定位置。

**例 11（18 题：双栈模拟）** 见上表，答案 15（B）。

**例 12（第 4 题：双栈直接求中缀）** `A - B*(C-D)` 用两个栈（操作数栈容量 2），B 项不溢出（选 B）；A 项在某时刻操作数栈需同时容纳 3 个数据 → 溢出。

**例 13（递归 15 题、第 6 题）** 15 题：栈底到栈顶 `main, S(1), S(0)`。第 6 题：F(8) 共执行 **9** 次，空间（栈深）**4**。

**例 14（循环队列真题 21、22）**
- 21 题：题干说"rear 指向队尾元素"，则入队是**先移指针再存** → rear 初值 = N-1；"front 指向队头元素"，第一个元素放 A[0] → front 初值 = 0。选 "front=0, rear=N-1"（B）。
- 22 题：front 指向队头 → 初值 0；rear 指向队尾的**后一个** → 初值 0。数组 `0..M-1` 共 M 格并牺牲一个 → 空 `front==rear`，满 `(rear+1)%M == front`（A）。

**例 15（循环队列非真题 5~10 的关键点）**
- 5 题：数组 `0..N` 共 **N+1** 格，入队取模用 **N+1**（虽然只存 N 个）→ `rear=(rear+1)%(N+1)`。
- 7 题：front=5（最大下标 5）再出队两次：`(5+1)%6=0`，再 `(0+1)%6=1`；rear=1 再入队两次 → 3。结果 front=1、rear=3。
- 8、10 题：front 指队头前一个、rear 指队尾 → 两者初值均为 N-1，满条件仍是 `(rear+1)%(N+1)==front`，最多存 N 个。
- 6 题：front 指队头**前一个**（开区间，该格不算元素）、rear 指队尾**元素本身**（闭区间）→ 一端开一端闭，长度直接 `R - F`（绕圈时 `+N`）；题中 R=3、F=8、N=21 → `3-8+21 = 16`。验证：队头在 9 号，元素为 9,10,…,20,0,1,2,3，正好 16 个。

**例 16（数组地址 4、5、15 题）**
- 4 题：`A[8][5]`，列 0..9（10 列），元素 3 字节 → `SA + (8*10+5)*3 = SA + 255`（选 D，按行优先）。
- 5 题：行优先，元素 1 字节，由 `A[3][3]-A[1][1] = 2N+2 = 26` 得 **N=12**；`A[5][5] = 407 + 5*12 + 5 = 472`（选 A，首地址按 `A[0][0]` 计）。若严格以 `A[1][1]=407` 为基准则为 `407+4*12+4=459`，题干口播基准不严谨，**考试认准"首地址 = A[0][0]"**。
- 15 题（真题）：行优先、元素 1 字节、首地址 100、`A[3][3]=220` → `3N+3=120`… 即 `100+3N+3=220` → **N=39**；`A[5][5] = 100+(5*39+5) = 300`。

**例 17（矩阵 13 题：12×12 对称、存上三角、行优先、1 基）** 求 `M[6][6]`（在对角线上）。前 5 行元素数：12+11+10+9+8 = **50**；`M[6][6]` 是本行第 1 个 → 共 51 个元素 → 一维下标 = 51-1 = **50**。答案 A。**最后一行只存 1 个**，千万别按 +7 算。

**例 18（矩阵 14 题：10×10 对称、存上三角、列优先、1 基）** 求 `M[7][2]`。先转置成 `M[2][7]`；上三角按列优先，前 6 列共 1+2+3+4+5+6 = **21** 个，第 7 列再数 2 个（行 1、行 2）→ 23 个 → 下标 = 23-1 = **22**（选 C）。不转置就会算成第 2 列，正中干扰项。

**例 19（矩阵 11 题：30×30 三对角、行优先、1 基）** 求 `M[30][30]`（对角线上）。第 1 行 2 个；第 2~29 行共 `29-2+1=28` 行、每行 3 个 = 84；第 30 行只有 2 个 → 共 `2+84+2 = 88` → 下标 **87**（选 B）。

**例 20（矩阵 3 题：对称、存下三角、行优先、二维 0 基）** 求 `a[i][i]`（0 基，即第 i+1 行第 i+1 列）。前 i 行共 `1+2+…+(i+1) = (i+1)(i+2)/2` 个元素，下标 = 个数-1 = `(i²+3i)/2`（选 A）。**关键：0 基时 `a[i][i]` 是第 i+1 行第 i+1 列。**

**例 21（矩阵 6 题：66×66 三对角、行优先、二维 1 基、一维 1 基）** 求 `A[66][65]`。第 1 行 2 个；第 2~65 行共 **64** 行 ×3 = 192；第 66 行只有 1 个（列 65 在对角线左侧）→ 共 `2+192+1 = 195`。一维数组写成 `B[1..298]`（下标从 1 开始）→ **下标 = 个数 = 195**（选 B），不用减 1。

**例 22（稀疏矩阵 16、12 题）** 16 题：三元组表除自身外还需存 **原矩阵的行数和列数**（选 C）。12 题：稀疏矩阵的两种存储结构是 **三元组表** 和 **十字链表**。

**例 23（栈和队列应用概念 17 题）** 关于栈的说法错误的是 **"非递归方式改写递归程序必须使用栈"**。反例：求 n! 的递归可改成 `for(i=2;i<=n;i++) a*=i;`，**完全不用栈**。其余选项：函数调用需要栈（对）、入栈顺序确定则出栈顺序不确定（对，卡特兰数）、栈是受限线性表且只允许一端操作（对）。答案 **C（含 1、3、4 三项）**。

**例 24（队列应用 16 题：火车轨道）** 列车按 `8 4 2 5 3 9 1 6 7` 进轨道，要求按 `1..9` 顺序出，每条轨道可停多列且先进先出，问最少几条轨道。做法：把序列切成尽量少的**递增子序列**（同一条轨道内必须递增，否则后进的小编号永远出不来）：
`8 9`｜`4 5 6 7`｜`2 3`｜`1` → 共 **4** 条（答案 4）。切法不唯一，但最少就是 4。
