# 第4章 串（4.1 串的定义与 KMP 算法）

> 408 中本章只考选择题（老师统计 KMP 至今考过三道），考点几乎全部集中在 **next / nextval 数组的求法、失配后指针的走向、子串向右滑动的距离、匹配过程中的比较次数**。KMP 理解不难但规则繁琐，属于"必须动手写三四遍"的知识点。覆盖分P：4.1.1。

## 知识框架

```

│  ├─ 基本概念：串、串长、空串、空格串、子串、主串、位置、串相等
│  └─ 存储结构：定长顺序存储、堆分配存储、块链存储
└─ 4.2 串的模式匹配
```

## 知识点详解

### 一、串的基本概念与存储（4.1.1 前半）

- **串**：由零个或多个字符组成的有限序列，记 S = "a₁a₂…aₙ"。
- **串长**：字符个数。**空串**：长度 0，记 ""；**空格串**：由一个或多个空格组成，长度不为 0（易错）。
- **子串 / 主串**：串中任意个连续字符组成的子序列叫子串，包含子串的串叫主串。子串在主串中的**位置**用子串第一个字符在主串中的序号表示。
- **串相等**：长度相同且对应位置字符全部相同（"abc" ≠ "abc "）。
- **存储结构**：

| 方式 | 特点 |
|---|---|
| 定长顺序存储 | 用定长数组，可在 0 号单元存长度，或用 '\0' 结尾；超长会截断 |
| 堆分配存储 | malloc 申请，长度可变，最常用 |
| 块链存储 | 每个结点存多个字符，存储密度高但插入删除麻烦 |

### 二、朴素模式匹配（BF）

从主串 T 的第 1 个位置起，与模式串 P 逐位比较；失配则**主串指针回退到本趟起点的下一位、模式串指针归零**，重新开始。

- 最好情况：每趟首字符就失配，共比较 n−m+1 次 → **O(n)**。
- 最坏情况：如 T = "000…001"、P = "000…001"，每趟都比到最后一个字符 → **O(nm)**。

> 暴力法的两个"浪费"：①主串指针会回退（已经比过的字符又比一遍）；②子串每次从头开始（已经匹配成功的前缀信息被丢弃）。KMP 就是同时解决这两点。

### 三、next 数组的手算（核心）

**定义（本笔记采用的口径，与课程板书一致，下标从 0 开始）**

> `next[j]` = 模式串 P[0..j−1] 这段前缀中，**最长的"既等于真前缀、又等于真后缀"的串的长度**。
> 规定：`next[0] = 1`（哨兵，0 号位失配只能让主串前进）、`next[1] = 0`。

含义：j 处失配时，P[0..next[j]−1] 已经和主串对应段相等，可直接从 P[next[j]] 继续比较，主串指针 i 不回退。

**手算方法（错位对齐法）**：求 next[j] 时，只看 j **前面**那段，把它自己错开一位上下对齐，找"同一条竖直线上完全相等"的最长长度；不相等就继续右移，直到只剩一个字符或完全无重叠，则为 0。

> 关键：必须是**完全相等**，不能只看"有一个字母相同"。老师特别指出这是最常见的错法。

**例：P = "abaabc"（下标 0～5，2015、2019 年真题用的就是它）**

| j | P[j] | 前面这段 P[0..j−1] | 最长相等真前后缀 | 长度 | next[j] |
|---|---|---|---|---|---|
| 0 | a | —（无前面） | — | 规定 | **1** |
| 1 | b | "a" | 无（真前后缀为空） | 规定 | **0** |
| 2 | a | "ab" | 前缀{a,ab}、后缀{b,ab}，无相等 | 0 | **0** |
| 3 | a | "aba" | "a" = "a" | 1 | **1** |
| 4 | b | "abaa" | 后缀{a,aa,baa} 与前缀{a,ab,aba}，只有 "a" | 1 | **1** |
| 5 | c | "abaab" | "ab" = "ab"（后缀 ab,aab,baab） | 2 | **2** |

即 **next = [1, 0, 0, 1, 1, 2]**（与老师板书的"一零、零、一、一、二"完全一致）。

**逐位推导细节（考场上照这个顺序写）**

- j=3：写 `a b a`，错开一位对齐 → 上行 `a b`、下行 `a`；先试长度 2（"ab" vs "ba"）不等；退到长度 1（"a" vs "a"）相等 → 1。
- j=4：`a b a a`，先试长度 3（"aba" vs "baa"）不等；长度 2（"ab" vs "aa"）不等；长度 1（"a" vs "a"）相等 → 1。
- j=5：`a b a a b`，长度 4（"abaa" vs "baab"）不等；长度 3（"aba" vs "aab"）不等；长度 2（"ab" vs "ab"）相等 → 2。

**再练一个（老师课堂练习，P = "ababaaa"）**

| j | P[j] | next[j] | 理由 |
|---|---|---|---|
| 0 | a | 1 | 规定 |
| 1 | b | 0 | 规定 |
| 2 | a | 0 | "ab" 无相等前后缀 |
| 3 | b | 1 | "aba" → "a" |
| 4 | a | 2 | "abab" → "ab" |
| 5 | a | 3 | "ababa" → "aba" |
| 6 | a | 1 | "ababaa" → 只有 "a" |

**下标口径的换算（必看）**：王道教材用 1 开始的下标，规定 next[1]=0、next[2]=1，其值 = 相等前后缀长度 + 1。同一模式串 "abaabc" 在王道口径下为 **[0,1,1,2,2,3]**，与上表**整体相差 1**。

- 老师原话意思：上下两行同时加 1，对应关系不变，退到的还是同一个字符；滑动距离 j−next[j] 也不变（j 和 next[j] 同时加 1，差不变）。
- 答题时**看清题目用哪套**：题目给 1 开始的下标就必须写 0,1,1,2,2,3；给 0 开始就写 1,0,0,1,1,2。

### 四、失配后的移动规则与滑动距离

**规则**

1. 若 next[j] ≠ 1：**主串指针 i 不动**，令 j = next[j]，从 P[j] 处与 T[i] 重新比较。
2. 若 next[j] = 1：说明 j 前面没有任何可用的相等前后缀，**i 前进一位、j 归零**（等价于整个模式串右移一位后从首字符重比）。
3. **滑动距离 = j − next[j]**（0 开始下标；1 开始下标同样是 j − next[j]）。回退后 P[0..next[j]−1] 与 T[i−next[j]..i−1] 必然相等，这段不必再比。

**例（真题 2015 / 2019，T = "abaabaabcabaabc"，P = "abaabc"）**

- 前 5 个字符 a b a a b 全部匹配，第 6 次比较 T[5]='a' 与 P[5]='c' 失配，此时 i = 5、j = 5。
- next[5] = 2 ≠ 1 → i 保持 5，j 回到 2，子串右移 5−2 = **3** 位。
- 答案：**i = 5，j = 2**；若问滑动距离则为 **3**（校验：右移 3 位后 P 对齐到 T[3..8] = "abaabc"，确实完全匹配）。

**例（next[j] = 1 的情形）**：若在 P 的 0 号位就失配，next[0] = 1 → i++、j=0，相当于模式串整体右移一位。

### 五、nextval 数组（KMP 优化）

**动机**：若 P[j] 失配后回退到的 P[next[j]] **与 P[j] 是同一个字符**，那么这次比较必然再次失配，纯属白比。优化就是**继续往前跳，一步到位**。

**规则**

- nextval[0] = 1，nextval[1] = 0；
- 对 j ≥ 2：若 **P[j] == P[next[j]]**，则 `nextval[j] = nextval[next[j]]`（沿用前面已算好的值，注意用**更新后**的值）；
- 否则 `nextval[j] = next[j]`（保持原值）。

**对 P = "abaabc" 逐位推**

| j | P[j] | next[j] | P[next[j]] | 是否同字符 | nextval[j] |
|---|---|---|---|---|---|
| 0 | a | 1 | — | — | **1**（规定） |
| 1 | b | 0 | — | — | **0**（规定） |
| 2 | a | 0 | P[0]=a | 相同 | nextval[0] = **1** |
| 3 | a | 1 | P[1]=b | 不同 | **1** |
| 4 | b | 1 | P[1]=b | 相同 | nextval[1] = **0** |
| 5 | c | 2 | P[2]=a | 不同 | **2** |

即 **nextval = [1, 0, 1, 1, 0, 2]**。

**对 P = "ababaaa"**

next = [1,0,0,1,2,3,1] →

| j | P[j] | next[j] | P[next[j]] | nextval[j] |
|---|---|---|---|---|
| 0 | a | 1 | — | 1 |
| 1 | b | 0 | — | 0 |
| 2 | a | 0 | a（同） | 1 |
| 3 | b | 1 | b（同） | 0 |
| 4 | a | 2 | a（同） | 1 |
| 5 | a | 3 | b（不同） | 3 |
| 6 | a | 1 | b（不同） | 1 |

nextval = [1,0,1,0,1,3,1]。

**用 nextval 的收益**：同一失配位置上，普通 KMP 可能需要连续回退两次（滑 3 再滑 1），用 nextval 一次滑到位（滑 4）。滑动距离仍按 **j − nextval[j]** 计算。

**注意**：nextval[j]=1 的含义与 next[j]=1 完全相同——**i++、j 归零**。这是 2013 年那道"最长滑动距离"题设的陷阱：并不是所有失配都"主串不动"。

### 六、KMP 的时间复杂度 O(n+m)

- **匹配阶段**：i 单调不减，最多自增 n 次；j 每次失配**至少减 1**，而 j 的自增只能伴随 i 自增发生（每轮循环 i、j 同增 1），所以 j 自增总次数 ≤ n，从而**回退总次数 ≤ n**。整个 while 循环的迭代次数 ≤ 2n → **O(n)**。
- **求 next 阶段**：j 从 1 走到 m−1，回退同样单调，总代价 **O(m)**；求 nextval 只需再扫一遍，O(m)。
- 合计 **O(n+m)**，比朴素的 O(nm) 好在"主串指针永不回退"。

> 注意：KMP 的优势体现在"主串很长、模式串有很多自重复"的场合；平均而言常数因子比 BF 大，考试只考复杂度结论与手算。

## 老师强调的考点

1. **next 数组的求法是"整个 KMP 里最重要的一步"**，"其他东西理不理解也没关系，但这一步一定要会算"——选择题必考，且是后续题目的前提。
2. **next 与 nextval 两套表都要会手算**，且要能对同一模式串同时写出两行。
3. **失配后 i、j 的取值**（2015、2019 都考同一模式串）：考"下一次比较时 i 和 j 分别是多少"。
4. **匹配到成功为止的比较次数**（2019 真题）：答案为 6+4=10，老师强调"千万不要写成 6+3"，因为回退后**当前位置还要再比一次**。
5. **子串向右滑动的距离**（2013 真题）：用 j − next[j]（或 j − nextval[j]），要会求"最长滑动距离"及对应的失配下标。
6. 目前 KMP 考过 **三道选择题**，老师建议一定要学，"后面做真题卷、模拟卷大概率会遇到"。
7. 出题会用 1 开始或 0 开始两种下标，**两种都要能对上答案**。

## 快速技巧与口诀

- **"第一个 1、第二个 0"**：next[0]=1、next[1]=0，先把这两个写死，再从左往右推。
- **"只看前面、不看自己；错开一位、完全相等"**：求 next[j] 的铁律。
- **"同字符就继承，不同字符就保留"**：nextval 一句话规则；继承时用**已更新**的 nextval 值。
- **"非 1 主串不动，是 1 主串加一"**：判断 i 是否前进只看 next（或 nextval）是否为 1。
- **滑动距离 = j − next[j]**；若问"最长滑动距离"，把所有 j 的 j−nextval[j] 都算出来取最大。
- **比较次数不要用"滑了几位"去减**：回退后当前位置要重新比，逐次累加最稳。
- 熟练后可"心中默念前缀"而不写全表：从最长的可能长度往下试，第一个对上的就是答案。

## 易错点与坑

1. **把"有重叠字符"当成"完全相等"**：如 "AAB" 与自身错位后重叠两个字母但内容不同，必须继续右移，不能记 2。
2. **next 与 nextval 混用下标口径**：题目 1 开始却写 0,1,1,2,2,3 之外的答案，整题作废。
3. **nextval 继承时用了旧的 next 值**：必须用 `nextval[next[j]]`（已经优化过的），不是 `next[next[j]]`。
4. **以为失配后主串一定不动**：next[j]=1（或 nextval[j]=1）时要 i++、j 归零。
5. **比较次数按"位移"算**：2019 题若答 6+3=9 就错，正确是 6+4=10。
6. **滑动距离用 next 却写成 nextval 的值**（或反之）：题目说"修正后的 next"就用 nextval。
7. **忘记 next[0] 是哨兵**：它不是"长度 0"，而是"无法回退"的标志，参与 1 开始口径换算时会变成王道表的 next[1]=0。
8. **空串与空格串混淆**："" 长度为 0；" " 长度为 1。

## 本章例题

**例1（2015 真题）**：P = "abaabc"，T 中前 5 个字符匹配，第 6 次比较失配（i=j=5），问下次比较的 i、j。
① 求 next = [1,0,0,1,1,2]；② next[5]=2≠1；③ i 不动 = 5，j = 2；④ 滑动距离 5−2=3。**答：i=5，j=2（滑动 3 位）**。

**例2（2019 真题）**：T = "abaabaabcabaabc"，P = "abaabc"，求匹配成功时的比较次数。
① 逐位比 a-b-a-a-b 五次成功，第 6 次 T[5]='a' 与 P[5]='c' 失配 → 已比较 **6** 次；② next[5]=2，j 回 2、i 仍为 5；③ 再比 T[5]/P[2]、T[6]/P[3]、T[7]/P[4]、T[8]/P[5]，四次全中 → **4** 次；④ 合计 6+4=**10 次**，匹配位置为 T 的第 4 个字符起。

**例3（2013 真题改编）**：P = "abaabc" 的 nextval = [1,0,1,1,0,2]，求"子串向右滑动的最大距离"及对应失配下标。
① 逐位算 j − nextval[j]：j=0→−1，j=1→1，j=2→1，j=3→2，j=4→4，j=5→3；② 最大值 **4**；③ 对应失配下标 **j=4**（第 5 个字符 'b'）。**答：最大滑动距离 4，失配下标 4**。

**例4（课堂练习，next 表）**：P = "ababaaa"，求 next 与 nextval。
next = [1,0,0,1,2,3,1]；nextval = [1,0,1,0,1,3,1]。要点：j=6 时前缀 "ababaa" 只有 "a" 相等，故 next=1；j=5 时 P[5]='a' 与 P[next[5]]=P[3]='b' 不同，nextval 保持 3。
