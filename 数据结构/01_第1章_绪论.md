## 知识点详解

### 一、数据结构的三要素（1.1.1）

**逻辑结构**：数据元素之间的逻辑关系，与存储无关。

| 类别 | 含义 | 课程中出现的例子 | 对应章节 |
|---|---|---|---|
| 线性结构 | 元素之间"一对一"，有前后次序 | A→B→C→D 四个字母排成一列 | 第2章线性表、第3章栈/队列/数组、第4章串 |
| 非线性-集合 | 元素之间无其他关系，只有"同属一个集合" | 并查集 | 5.5.2（边角知识，一轮后再学） |
| 非线性-树 | 一对多 | A 下面挂 B、C，C 下面挂 D、E | 第5章 |
| 非线性-图 | 多对多 | — | 第6章 |

**存储结构（物理结构）**：逻辑结构在内存中的实现方式，四种。

- **顺序存储**：逻辑上相邻的元素物理位置也相邻，且所有元素占**一整块连续空间**（相当于编程语言里的数组）。
- **链式存储**：不要求逻辑相邻的元素物理相邻，用**指针（地址）**表示元素之间的关系，空间可分散。
- **索引存储**：存元素的同时建索引表（关键字 + 地址），第7章分块查找、操作系统文件的物理结构会用到。
- **散列存储**：由关键字直接计算存储地址，7.5 散列表学完才真正理解。

**老师举的例子（线性结构 ABCD 的两种存法）**

| 逻辑结构 | 顺序存储 | 链式存储 |
|---|---|---|
| A→B→C→D | 内存中连续放 A、B、C、D，次序与逻辑完全一致 | A 中存"后继地址=1"（1 号单元是 B），B 存 11（C），C 存 4（D），D 存 −1 或空指针表示结束 |

结论：**同一个逻辑结构可以用不同物理结构实现**；两种存法最终反映的都是 ABCD 这一串。

**"唯一性"要求（本小节唯一值得记的推理）**：由物理结构还原逻辑结构必须唯一，否则存法无效。

- 反例：一棵二叉树 A(B, C)，C 的左/右孩子是 D、E。若"一行一行"存成 `A B C D E`，还原时既可能是 C 的左孩子 D、右孩子 E，也可能被理解成另一种形状（D、E 挂在 B 下），出现歧义。
- 正解：**补成完全二叉树再顺序存**，空缺位置填特殊标记，如 `A B C ∧ ∧ D E`，这样还原唯一。这正是第5章"二叉树的顺序存储"为什么必须按完全二叉树编号。

**数据的运算**：给一个数据结构后对它做的操作，如求长度（ABCD 的长度为 4）、在 B、C 之间插入 E、删除 C。运算**定义在逻辑结构上，实现在存储结构上**——所以同一运算在顺序表和链表上的写法与效率不同（第2章展开）。

### 二、算法的基本概念与效率度量（1.2.1）

算法的五个特性（有穷性、确定性、可行性、输入、输出）**408 从来不考**，读一遍即可，不背。

**时间复杂度**：算法执行时间随问题规模 n 增长的数量级，记 O(...)。

- 只看**数量级**：执行 10000 次与 10050 次同级，都是 O(1) 之外的同一量级；n 一律当成很大的数，n+1 与 n 视为相同。
- **加法规则**：T(n)=5n²+6n → 只留高阶、丢常数 → O(n²)。
- **乘法规则**：嵌套相乘。若外层执行 n 次、内层每次代价 O(n²)，则该段为 O(n³)；与之并列的 O(1) 部分直接丢弃，总和仍是 O(n³)。
- **最好 / 最坏 / 平均**：在 n 个元素中找一个元素，最好第 1 个位置就中（O(1)），最坏在最后一个位置（O(n)），平均约一半（O(n)）。第8章每个排序算法都要同时记这三个值。
- 常见量级：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ)，另外还有 O(√n)（根号 n）。老师明确说"大小顺序不用背，知道常见形式即可"。

**空间复杂度**：算法消耗的**额外**存储空间。

| 额外空间 | 复杂度 | 典型情形 |
|---|---|---|
| 若干个变量（哪怕 100 个） | O(1)，称为**原地工作** | 交换、插入排序、堆排序 |
| 长度 n 的一维辅助数组 | O(n) | 归并排序、计数 |
| n×n 的二维数组 | O(n²) | 矩阵类算法 |
| 递归工作栈深 h | O(h) | 阶乘递归 O(n)、二分递归 O(log n) |

### 三、while 循环的时间复杂度（1.2.2）

**通用套路（老师反复强调的"写过程"方法）**

1. 设循环执行 **t** 次；
2. 写出第 t 次结束后关键变量的表达式（多为等比/等差）；
3. 用"再执行一次就会退出"的**边界条件**列等式；
4. 解出 t，只保留数量级（常数、加减项全丢）。

> 边界取等号时多算一次少算一次不影响量级，直接令其等于边界即可。

#### 题1（真题 12 题）

```c
int x = 2;
while (x < n / 2)
    x = x * 2;
```

| 循环次数 | 循环结束后 x |
|---|---|
| 1 | 4 = 2² |
| 2 | 8 = 2³ |
| 3 | 16 = 2⁴ |
| t | 2^(t+1) |

边界条件：2^(t+1) ≈ n/2。

推导（含 log 化简）：

```
2^(t+1) = n/2
两边取以 2 为底的对数：
t + 1 = log₂(n/2)
      = log₂n − log₂2          ← 对数除法变减法
      = log₂n − 1
t = log₂n − 2
```

减 2 是常数，n 很大时忽略 → **t = O(log n)**。答案 A。

> 也可以偷懒：把 2^(t+1) 看成 2^t、把 n/2 看成 n，得 2^t = n → t = log₂n，量级不变。

#### 题2（真题 15 题）

```c
int i = 0, sum = 0;
while (sum < n) {
    i++;
    sum += i;
}
```

| 循环次数 | i | sum |
|---|---|---|
| 1 | 1 | 0+1 = 1 |
| 2 | 2 | 1+2 = 3 |
| 3 | 3 | 1+2+3 = 6 |
| t | t | 1+2+…+t = t(t+1)/2 |

边界：t(t+1)/2 ≈ n。t 很大时 t+1 ≈ t，故 t²/2 ≈ n → t² ≈ 2n → t ≈ √(2n)。

常数 2 丢弃 → **t = O(√n)**，即 O(n^(1/2))。答案 B。

> 这题靠"观察法"看不出来，必须列式；等差数列、等比数列求和公式必须复习。

#### 题3（补充，练 log 底数无关）

```c
int i = 1;
while (i <= n)
    i = i * 3;
```

3^t ≈ n → t = log₃n = log₂n / log₂3。分母 log₂3 是常数，故 **O(log n)**。

> 结论：**对数的底数不影响大 O**。log₂n、log₃n、ln n 只差常数倍，一律写 O(log n)。

#### 题4（补充，练"每次减半"）

```c
int i = n * n;
while (i != 1)
    i = i / 2;
```

从 n² 除到 1 需 t 次：n²/2^t = 1 → 2^t = n² → t = log₂(n²) = 2log₂n → **O(log n)**。

> 易错：把 n² 直接当成规模，误答 O(log n²) 后不肯化简。log(n²)=2log n，仍是 O(log n)。

### 四、双层 for 循环的时间复杂度（1.2.3）

**通用套路**：画一张三列表——"外层第几次 | 外层变量值 | 内层执行次数"，把**所有内层的执行次数加起来**（不是相乘！只有内层次数与外层变量无关时，求和才恰好等于相乘）。

#### 题1（真题 14 题）

```c
for (k = 1; k < n; k = k * 2)
    for (j = 1; j <= n; j++)
        ;
```

| 外层第几次 | k | 内层执行次数 |
|---|---|---|
| 1 | 1 | n |
| 2 | 2 | n |
| 3 | 4 | n |
| t | 2^(t−1) | n |

外层共 t 次，边界 2^(t−1) = n → t = log₂n + 1 → 只留 log₂n。总次数 = t·n = n·log₂n → **O(n log n)**。答案 C。

#### 题2（真题 17 题）

```c
for (i = 1; i <= n; i = i * 2)
    for (j = 0; j < i; j++)
        ;
```

| 外层第几次 | i | 内层执行次数 |
|---|---|---|
| 1 | 1 | 1 |
| 2 | 2 | 2 |
| 3 | 4 | 4 |
| t | 2^(t−1) | 2^(t−1) |

内层次数构成等比数列，公比 2、首项 1、共 t 项：

```
1 + 2 + 4 + … + 2^(t−1) = (1·(2^t − 1)) / (2 − 1) = 2^t − 1
```

由 2^(t−1) ≈ n 得 2^t ≈ 2n，代入：总次数 ≈ 2n − 1 → **O(n)**。答案 B。

> 两种代入顺序都对：先解 t = log₂n + 1 再代入得 n−1，或先乘 2 得 2^t = 2n 再代入得 2n−1；两者都是 O(n)。

#### 题3（补充，对比：内层次数与 n 同阶时才是 n²）

```c
for (i = 1; i <= n; i++)
    for (j = i; j <= n; j++)
        ;
```

内层次数 = n−i+1，求和 = n + (n−1) + … + 1 = n(n+1)/2 → **O(n²)**。

#### 题4（补充，调和级数型，常考干扰项）

```c
for (i = 1; i <= n; i++)
    for (j = 1; j <= n; j += i)
        ;
```

内层次数 = ⌊n/i⌋，总和 = n(1 + 1/2 + 1/3 + … + 1/n) = n·H(n) ≈ n·ln n → **O(n log n)**。

> 判别口诀：**外层变量出现在内层的"上界/步长"里 → 求和；内层次数与外层变量无关 → 直接相乘。**

### 五、递归函数的时间复杂度（1.2.4）

**通用套路**：先求"函数被调用多少次"，再乘"每次调用的开销"（每次内部无循环即 O(1)）。

#### 题1（真题 13 题）

```c
int f(int n) {
    if (n <= 1) return 1;
    return n * f(n - 1);
}
```

执行 f(4) 的调用链：f(4) → f(3) → f(2) → f(1)，共 4 层；f(n) 共调用 n 次，每次只做一次乘法（O(1)）。

T(n) = T(n−1) + O(1) → T(n) = O(n)。答案 B。

空间复杂度：递归栈深 n → **O(n)**（这是本题容易漏的第二问）。

#### 题2（真题 11 题）

```c
int f(int n) {
    if (n <= 1) return 1;
    return f(n / 2) + 1;
}
```

| 第几次调用 | 参数 |
|---|---|
| 1 | n |
| 2 | n/2 |
| 3 | n/4 |
| t | n / 2^(t−1) |

最后一次参数为 1：n / 2^(t−1) = 1 → 2^(t−1) = n → t−1 = log₂n → t = log₂n + 1 → **O(log n)**。答案 C。

每次调用 O(1)，总时间 = 调用次数 × 每次开销 = log n × 1 = **O(log n)**；空间 = 栈深 = O(log n)。

> 若递归体内含一个执行 n 次的循环，则总时间为 log n × n = O(n log n)——"次数 × 每次开销"这一步不能漏。

#### 题3（补充，递归树：归并排序型）

```
T(n) = 2T(n/2) + O(n)
```

递归树：

```
第0层:            n                 代价 n
第1层:        n/2     n/2           代价 n
第2层:     n/4 n/4  n/4 n/4         代价 n
 ...                                ...
第k层:  共 2^k 个结点，每个 n/2^k    代价 n
```

层数：n/2^k = 1 → k = log₂n，共 **log₂n + 1 层**。
总代价 = 每层 n × 层数 (log₂n + 1) = n log₂n + n → 取高阶 → **O(n log n)**。

（这是第8章归并排序 O(n log n) 的来源，也是快排/堆排序平均情况的分析模板。）

#### 题4（补充，主定理）

对 T(n) = aT(n/b) + f(n)，令 c = log_b a，比较 f(n) 与 n^c：

| 情形 | 条件 | 结果 |
|---|---|---|
| 1 | f(n) = O(n^(c−ε))，即递归"叶子"更贵 | T(n) = Θ(n^c) |
| 2 | f(n) = Θ(n^c)，即各层代价相当 | T(n) = Θ(n^c · log n) |
| 3 | f(n) = Ω(n^(c+ε))，即"根"更贵 | T(n) = Θ(f(n)) |

代入验证：

- 归并：a=2, b=2 → c = log₂2 = 1，f(n)=n = Θ(n¹) → 情形 2 → **Θ(n log n)**。
- 折半查找：a=1, b=2 → c = log₂1 = 0，f(n)=1 = Θ(n⁰) → 情形 2 → **Θ(log n)**。
- T(n)=2T(n/2)+n²：c=1，f(n)=n² = Ω(n^(1+1)) → 情形 3 → **Θ(n²)**。

> 考场上递归题优先用"设 t 次 + 边界等式"（老师的方法），递归树用于解释为什么是 n log n，主定理用于快速核对。

### 六、空间复杂度小结

| 代码特征 | 空间 |
|---|---|
| 只有若干普通变量 | O(1)（原地工作） |
| 开辟长度 n 的辅助数组 | O(n) |
| 开辟 n×n 二维数组 | O(n²) |
| 递归深度 n（阶乘、快排最坏） | O(n) |
| 递归深度 log n（二分、快排平均） | O(log n) |

## 快速技巧与口诀

- **while 三步**：设 t 次 → 写变量通式 → 用边界列等式 → 解出 t 只留量级。
- **等比求和**：首项 a、公比 q（q≠1）、n 项 → a(qⁿ−1)/(q−1)。**等差求和**：n(a₁+aₙ)/2。
- **双层 for 先标"外层第几次"**：因为外层变量常是 1、2、4、8 跳变，只看变量本身会数错次数。
- **近似原则**：2^(t+1)→2^t，n/2→n，t+1→t，t²+t→t²，2n−1→n；做完近似再看量级，答案不会错。
- **看到每次乘 2 / 除 2 → log**；**看到累加 1+2+…+t → 平方根**；**看到内层次数成等比 → 总和由末项决定 → 一次方**。
- **空间复杂度只看额外空间**：辅助数组、递归栈；输入本身不计。

## 易错点与坑

1. **把双层 for 直接相乘**：`for(i=1;i<=n;i*=2) for(j=0;j<i;j++)` 若写成 n×n 就错了，正确答案是 O(n)（等比求和后由末项主导）。
2. **忘记丢常数导致答案不匹配选项**：算出 log₂n−2、n/2、2n−1 时不要慌，选项只给量级。
3. **对数底数纠结**：log₂n 与 log₃n 是同一量级，选项里通常只写 log n。
4. **while 循环里有多行代码就以为要乘**：循环体内常数行数一律忽略，只看循环次数。
5. **递归只数"层数"忘记乘每次开销**：递归体内有 O(n) 循环时必须相乘。
6. **空间复杂度漏掉递归栈**：阶乘递归空间是 O(n) 不是 O(1)；快排最坏空间是 O(n) 不是 O(1)。
7. **"原地工作"误解**：定义是辅助空间为常量级 O(1)，用 100 个变量仍是 O(1)。
8. **二叉树顺序存储按层"一行存下来"**：必须补成完全二叉树，否则物理结构还原逻辑结构不唯一。

## 本章例题

**例1（真题 12 题，while）**：`x=2; while(x<n/2) x*=2;` 求时间复杂度。
① 设执行 t 次；② 第 t 次后 x = 2^(t+1)；③ 边界 2^(t+1) = n/2；④ t = log₂n−2 → **O(log n)**，选 A。

**例2（真题 15 题，while）**：`i=0,s=0; while(s<n){i++; s+=i;}`。
① 第 t 次后 s = t(t+1)/2；② 令 t(t+1)/2 = n；③ t² ≈ 2n；④ t ≈ √(2n) → **O(√n)**，选 B。

**例3（真题 14 题，双层 for）**：`for(k=1;k<n;k*=2) for(j=1;j<=n;j++)`。
外层 t 次（2^(t−1)=n → t=log₂n），内层每次 n 次，总 n log n → **O(n log n)**，选 C。

**例4（真题 17 题，双层 for）**：`for(i=1;i<=n;i*=2) for(j=0;j<i;j++)`。
内层次数 1+2+4+…+2^(t−1) = 2^t−1，由 2^(t−1)=n 得 2^t=2n，总 ≈ 2n−1 → **O(n)**，选 B。

**例5（真题 13 题，递归）**：`f(n)=n*f(n-1)`，f(1)=1。调用 n 次（f(4)→f(3)→f(2)→f(1)），每次 O(1) → **O(n)**，选 B；空间 O(n)。

**例6（真题 11 题，递归）**：`f(n)=f(n/2)+1`。参数序列 n, n/2, n/4, …, 1，共 log₂n+1 次，每次 O(1) → **O(log n)**，选 C；空间 O(log n)。
